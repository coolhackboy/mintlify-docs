上线前你需要了解的一切。

<AccordionGroup>

<Accordion title="什么是 Vidgo API？">
Vidgo API 是一个 AI 基础设施平台。只需一个 Key，即可统一调用顶尖 AI 模型，价格透明可预期，稳定可靠，可直接用于生产环境。
</Accordion>

<Accordion title="如何获取 API Key？">
注册账户后，即可在仪表盘中立即生成 API Key。
</Accordion>

<Accordion title="有免费额度吗？">
新账户会获得免费积分，方便你在扩大规模前先测试模型。
</Accordion>

<Accordion title="支持哪些模型？">
我们支持主流的图像、视频和音乐模型，每周都会上新。
</Accordion>

<Accordion title="是否提供企业支持？">
提供。请联系我们的团队，洽谈定制价格、SLA 和专属支持。
</Accordion>

<Accordion title="在哪里查看当前价格？">
请查看[价格页面](https://vidgo.ai/apis/api-pricing)或你的 Vidgo 仪表盘，了解当前各模型的价格。
</Accordion>

<Accordion title="哪些因素会影响生成费用？">
费用取决于所选模型及其支持的计费选项。图像生成费用可能与质量、分辨率、输出数量和参考图数量有关。视频生成费用可能与时长、分辨率、是否生成音频以及参考视频时长有关。各工作流适用的计费因素请查看对应的模型页面。
</Accordion>

<Accordion title="你们使用哪个音乐模型？">
我们使用 Suno 官方模型，包括最新的 v5 模型。我们的音乐 API 支持生成最长 8 分钟、专业品质的音乐。
</Accordion>

<Accordion title="请求失败会扣费吗？">
不会。我们的定价透明，只对成功的生成收费。请求失败时积分会自动退还。
</Accordion>

<Accordion title="支持哪些支付方式？">
我们支持多种支付方式，包括 Stripe（信用卡/借记卡）、微信支付和加密货币支付，灵活便捷。
</Accordion>

<Accordion title="遇到问题时如何联系支持？">
你可以通过 support@vidgo.ai 联系我们。我们也在逐步推出 Discord 等更多支持渠道，敬请关注官网公告。
</Accordion>

</AccordionGroup>

## 欢迎使用 Vidgo API

Vidgo API 提供强大的图像和视频生成 API。本指南将帮助你在几分钟内完成第一次 API 调用。

## 第 1 步：获取 API Key

1. 访问 [Vidgo API 控制台](https://vidgo.ai/apis/dashboard/api-key)
2. 登录或创建账户
3. 生成新的 API Key
4. **重要**：复制并妥善保存你的 API Key，它只会显示一次

## 第 2 步：生成第一张图片

所有 API 请求都需要在 `Authorization` 请求头中携带 API Key。完整示例如下：

```python
import requests

url = "https://api.vidgo.ai/api/generate/submit"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}

payload = {
    "model": "gpt-4o-image",
    "callback_url": "https://your-domain.com/callback",
    "input": {
        "prompt": "A serene mountain landscape at sunset with vibrant colors",
        "size": "1:1",
        "n": 1
    }
}

response = requests.post(url, json=payload, headers=headers)
result = response.json()
task_id = result["data"]["task_id"]
print(f"Task ID: {task_id}")
```

```javascript
const response = await fetch('https://api.vidgo.ai/api/generate/submit', {

```

## 第 3 步：查询任务状态

Vidgo API 采用异步处理。轮询状态接口即可获取结果：

```python
import requests
import time

task_id = "task-unified-1757165031-uyujaw3d"
url = f"https://api.vidgo.ai/api/generate/status/{task_id}"
headers = {
    "Authorization": "Bearer YOUR_API_KEY"
}

# Poll until complete
while True:
    response = requests.get(url, headers=headers)
    result = response.json()
    task = result["data"]

    status = task['status']
    progress = task.get('progress', 0)

    print(f"Status: {status}, Progress: {progress}%")

    if status == 'finished':
        print(f"Image URL: {task['files'][0]['file_url']}")
        break
    elif status == 'failed':
        print(f"Error: {task['error_message']}")
        break

    time.sleep(2)  # Wait 2 seconds before next check
```

```javascript
const taskId = 'task-unified-1757165031-uyujaw3d';

async function checkStatus() {
  while (true) {
    const response = await fetch(
      `https://api.vidgo.ai/api/generate/status/${taskId}`,
      {
        headers: {
          'Authorization': 'Bearer YOUR_API_KEY'
        }
      }
    );

    const result = await response.json();
    const task = result.data;
    const { status, progress, files, error_message } = task;

    console.log(`Status: ${status}, Progress: ${progress}%`);

    if (status === 'finished') {
      console.log('Image URL:', files[0].file_url);
      break;
    } else if (status === 'failed') {
      console.log('Error:', error_message);
      break;
    }

    await new Promise(resolve => setTimeout(resolve, 2000));
  }
}

checkStatus();
```

```bash
curl -X GET https://api.vidgo.ai/api/generate/status/task-unified-1757165031-uyujaw3d \
  -H "Authorization: Bearer YOUR_API_KEY"
```

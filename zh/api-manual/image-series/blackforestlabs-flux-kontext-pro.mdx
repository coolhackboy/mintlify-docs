使用 FLUX Kontext Pro 通过文字指令编辑图像，支持角色一致性和对特定视觉细节的修改。

## 模型

- **blackforestlabs/flux-kontext-pro** - 使用文本提示词编辑一张源图。

## 功能

- 使用文本提示词编辑一张源图。
- 在 `image_urls` 中以单个项目提供源图。

## 输出选项

### 图像尺寸

- `size`：可选。输出宽高比。可选值：`1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`21:9`、`9:21`。默认：`1:1`。

### 输出格式

- `output_format`：可选。输出图像文件格式。可选值：`png`、`jpg`。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

输入图像 URL 使用 HTTP(S)，并指向公开可访问的图像文件。

### 提示词

- `prompt`：必填。描述要做的修改。长度：**1-2,000 个字符**。
- 至少包含一个非空白字符。

### 图像 URL

- `image_urls`：必填。只提供 1 个公开可访问的 HTTP(S) 图像 URL 作为源图。

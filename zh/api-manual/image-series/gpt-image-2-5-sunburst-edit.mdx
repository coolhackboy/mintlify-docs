GPT Image 2.5 Sunburst 图像编辑根据文字指令编辑图像：传入 1–16 张参考图，可以重新调整风格、替换背景、把产品合成到新场景，或只修改蒙版区域。Sunburst 是 GPT Image 2.5 中面向精细视觉创作、对编辑精度要求高的选项。

如只需根据提示词生成，请使用[GPT Image 2.5 Sunburst 文生图](/zh/api-manual/image-series/gpt-image-2-5-sunburst-text-to-image)（`openai/gpt-image-2.5-sunburst/text-to-image`）。

## 模型

- **openai/gpt-image-2.5-sunburst/edit** — GPT Image 2.5 Sunburst 图像编辑，1–16 张参考图，每次请求生成一张图像。

## 功能

- 基于文字指令编辑，最多 16 张参考图，在提示词中按顺序引用。
- 可选蒙版，只编辑指定区域。
- 三档分辨率（`1K`、`2K`、`4K`），支持宽高比预设、`auto` 或自定义 `WIDTHxHEIGHT` 尺寸。
- 五档质量：`low`、`medium`、`high`、`xhigh`、`max`。
- 透明或不透明背景；输出 PNG、JPEG 或 WebP。

## 必填参数

- `prompt` (string)：描述编辑内容的文字指令。最多 32,000 个字符，不能为空白。
- `image_urls` (string[])：1–16 张参考图，使用公开可访问的 HTTP(S) URL，顺序与提示词中引用的顺序一致。

## 可选参数

- `size` (string)：宽高比预设、`auto` 或自定义 `WIDTHxHEIGHT`。省略时输出跟随第一张参考图的宽高比。参见[尺寸](#尺寸)。
- `resolution` (string)：`1K`、`2K` 或 `4K`。默认 `1K`。
- `quality` (string)：`low`、`medium`、`high`、`xhigh` 或 `max`。默认 `high`。
- `background` (string)：`auto`、`transparent` 或 `opaque`。默认 `auto`。透明背景需要输出 `png` 或 `webp`。
- `output_format` (string)：`png`、`jpeg` 或 `webp`。默认 `png`。
- `mask_url` (string)：选定编辑区域的蒙版图像，使用公开可访问的 HTTP(S) URL。需要同时传入 `image_urls`。

## 尺寸

- 预设：`1:1`、`2:3`、`3:2`、`4:3`、`3:4`、`4:5`、`5:4`、`16:9`、`9:16`、`21:9`。省略 `size` 时，输出跟随第一张参考图的宽高比，在所选 `resolution` 档位下取最接近的支持比例。传入 `size` 可覆盖。
- 预设保持所选 `resolution` 档位；实际像素尺寸可能因每次生成而不同。需要精确像素时请使用自定义尺寸。
- `auto` 由模型决定图像尺寸（约 150 万像素），可与任意 `resolution` 搭配，按 `1K` 档计费。
- 自定义 `WIDTHxHEIGHT`（用 `x` 或 `X` 分隔，例如 `2304x1536`）可与任意 `resolution` 搭配。两条边都必须是 16 的倍数，最长边不超过 3,840 像素，宽高比不超过 3:1，总像素数在 655,360 到 8,294,400 之间。
- 自定义尺寸按总像素数对应的档位计费；所选 `resolution` 更高时按所选档位：

| 总像素数（自定义尺寸） | 计费档位 |
| --- | --- |
| 不超过 1,572,864 | `1K` |
| 1,572,865–4,194,304 | `2K` |
| 超过 4,194,304 | `4K` |

## 示例

- **使用参考图编辑**：在 `2K` 下替换背景，不传 `size`，输出保持参考图的宽高比。
- **蒙版编辑**：只修改蒙版区域，`size: auto`。
- **透明背景**：去除背景，WebP、`4K`、`xhigh` 质量。
- **自定义尺寸**：把产品放入 `2304x1536` 的全景场景，`2K`、`medium` 质量。

## 注意事项

- 每次请求只返回一张图像；`n` 不为 `1` 时返回 400。未列出的字段返回 400。`model` 和 `callback_url` 放在请求根级，不放在 `input` 内。
- 透明背景搭配 `output_format: jpeg` 返回 400。
- `image_urls` 为空数组、超过 16 张，或 URL 不是有效的 HTTP(S) URL 时返回 400。
- 积分取决于 `quality`、计费档位（`resolution`，或[尺寸](#尺寸)中所述的自定义尺寸档位）和参考图数量。提交时预扣单张图像的封顶积分；任务完成后按实际 token 用量计费（不超过封顶），差额退还。任务失败全额退还。当前价格见[定价页](https://vidgo.ai/apis/api-pricing)。

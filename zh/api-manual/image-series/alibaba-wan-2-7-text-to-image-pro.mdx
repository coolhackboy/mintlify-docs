使用 Wan 2.7 Pro 创作图像变体，通过详细的提示词引导主体、风格和构图。

## 模型

- **alibaba/wan-2.7/text-to-image-pro** - 根据文本提示词生成图像。

## 功能

- 根据文本提示词生成图像。
- 通过 `n` 控制输出图像数量。

需要参考图时，请使用对应的图像编辑接口。

## 输出选项

### 图像尺寸

- `size`：可选。默认：`1024x1024`。
- 预设：`512x512`、`1024x1024`、`768x1024`、`1024x768`、`576x1024`、`1024x576`。
- 自定义尺寸时，提供包含整数 `width` 和 `height` 的对象，两者都必须为正数。

### 图像数量

- `n`：可选。要生成的图像数量。`1` 到 `4` 的整数。默认：`1`。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

只发送本工作流支持的 input 字段。不支持的 `input` 字段会在扣除积分前被拒绝。

### 提示词

- `prompt`：必填。描述期望的图像。长度：**1-5,000 个字符**。
- 提供时不能为空。

### 种子

- `seed`：可选。设置生成种子。整数。

## 计费因素

计费取决于所选模型版本和输出图像数量（`n`）。输出尺寸不会额外计费。

积分在提交时扣除，任务失败会退还。

Ideogram 4.5 文生图根据提示词生成海报、Logo、包装样稿、社交媒体配图等需要清晰文字的图片。一次最多可生成八张，并可按草稿或成品选择合适的质量档位。

Ideogram 4.5 是 Ideogram 面向文字密集型画面和精确编辑的图像模型。Vidgo 提供两个 model ID：[文生图](/zh/api-manual/image-series/ideogram-v4-5-text-to-image)和[图像编辑](/zh/api-manual/image-series/ideogram-v4-5-edit)。

## 模型

- **ideogram/v4.5/text-to-image** — Ideogram 4.5 文生图，每次请求 1–8 张。

## 功能

- 文生图，擅长准确渲染画面中的文字（标题、标语、标签）。
- 通过 `n` 每次生成 1–8 张。
- 三档质量：`low`、`medium`、`high`。
- 六种宽高比预设，外加 36 种精确像素尺寸，从 720x1280 到 3328x1248，以及 2048x2048。

## 必填参数

- `prompt`（string）：想要的画面，1–10,000 个字符。需要出现的文字请用引号标出，例如 `"GRAND OPENING"`。不能为空白。

## 可选参数

- `n`（integer）：图片张数，`1`–`8`。默认 `1`。
- `quality`（string）：`low`、`medium` 或 `high`。默认 `medium`。
- `size`（string）：输出尺寸。默认 `1:1 HD`。见[尺寸](#尺寸)。

## 尺寸

- 预设：`1:1`、`1:1 HD`、`4:3`、`3:4`、`16:9`、`9:16`。`1:1 HD` 为更高分辨率的方形。
- 精确像素尺寸：`720x1280`、`720x1440`、`800x1280`、`832x1248`、`864x1152`、`896x1120`、`1024x1024`、`1024x3072`、`1120x896`、`1152x864`、`1152x2944`、`1248x832`、`1248x3328`、`1280x720`、`1280x800`、`1280x3072`、`1296x3168`、`1440x720`、`1440x2560`、`1440x2880`、`1600x2560`、`1664x2496`、`1728x2304`、`1792x2240`、`2048x2048`、`2240x1792`、`2304x1728`、`2496x1664`、`2560x1440`、`2560x1600`、`2880x1440`、`2944x1152`、`3072x1024`、`3072x1280`、`3168x1296`、`3328x1248`。
- 其他取值会返回 400。

## 输出

任务完成后，[查询任务状态](/zh/api-manual/task-management/status)和回调内容的 `files` 数组中会按请求的张数（`n`）返回对应数量的图片文件。

## 示例

- **带文字的海报**：旅行海报，标题文字在提示词中用引号标出，`3:4`，`medium` 质量。
- **四个高质量 Logo 方案，带回调**：`n: 4`，`quality: high`，`1024x1024`，并提供 `callback_url`。

## 注意事项

- 本 ID 只接受文本。要修改已有图片，请用 [Ideogram 4.5 图像编辑](/zh/api-manual/image-series/ideogram-v4-5-edit)。
- 上文未列出的字段会返回 400。`model` 和 `callback_url` 放在请求根级，不要放进 `input`。
- 积分在提交时预扣，只取决于 `quality` 和 `n`，`size` 不影响价格。任务失败会全额退还。当前费率见[定价页](https://vidgo.ai/apis/api-pricing)。

1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询任务状态](/zh/api-manual/task-management/status)接口获取结果。

使用 OpenAI 的 GPT-4o 模型生成高质量图像。支持文生图、图生图以及高级图像编辑。

## 模型

- **gpt-4o-image** - 文生图和图生图
- **gpt-4o-image-edit** - 支持蒙版的高级图像编辑

使用 `gpt-4o-image` 生成时，通过 `n` 选择图像数量并按该数量计费。使用 `gpt-4o-image-edit` 编辑时，每次请求生成并计费一张图像；`n` 不会增加编辑输出的数量。

使用 Grok Imagine 重新演绎已有图像，通过文字引导对主体、场景或视觉风格的修改。

## 模型

- **xai/grok-imagine-image/edit** - 使用提示词和参考图编辑图像。

## 功能

- 使用提示词和参考图编辑图像。
- `image_urls` 只接受 1 张图像。

## 输出选项

### 图像尺寸

- `size`：可选。可选值：`1:1`、`2:3`、`3:2`、`9:16`、`16:9`。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

使用下面列出的 input 字段。参考图请提供公开可访问的 HTTP(S) URL。

### 提示词

- `prompt`：必填。描述要做的修改。长度：**1-5,000 个字符**。

### 图像 URL

- `image_urls`：必填。提供公开可访问的图像 URL。只提供 1 项。使用 JPEG、PNG 或 WebP，最大 10 MB。

使用 FLUX.2 Flex 改造图像或组合参考图，通过文字引导主体、风格和构图。

## 模型

- **blackforestlabs/flux-2-flex/edit** - 使用提示词和参考图编辑图像。

## 功能

- 使用提示词和参考图编辑图像。
- `image_urls` 接受 1-8 张图像。
- 可选 `1K`、`2K` 输出分辨率。

## 输出选项

### 图像尺寸

- `size`：必填。可选值：`1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`3:2`、`2:3`、`auto`。`auto` 使用 `image_urls` 中第一张图像的宽高比。

### 分辨率

- `resolution`：必填。可选值：`1K`、`2K`。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

发送本页列出的 input 字段。每个输入 URL 都是公开的 HTTP(S) URL。

### 提示词

- `prompt`：必填。描述要做的修改。长度：**3-5,000 个字符**。

### 图像 URL

- `image_urls`：必填。提供公开可访问的图像 URL。1-8 项。每项都必须是 HTTP(S) URL。

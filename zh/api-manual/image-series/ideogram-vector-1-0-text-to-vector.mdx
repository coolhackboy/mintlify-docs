Ideogram Vector 1.0 文本生成 SVG 根据提示词生成可缩放的 SVG 作品：Logo、图标、贴纸、徽章和扁平插画，任意尺寸下都保持清晰。提示词中的文字会以矢量图形绘制。可以加入最多五张参考图来引导风格或构图。

Ideogram Vector 1.0 是 Ideogram 第一个输出矢量图而不是像素图的模型。Vidgo 提供两个 model ID：[文本生成 SVG](/zh/api-manual/image-series/ideogram-vector-1-0-text-to-vector)和[图片转 SVG](/zh/api-manual/image-series/ideogram-vector-1-0-image-to-vector)。

## 模型

- **ideogram/vector-1.0/text-to-vector** — Ideogram Vector 1.0 文本生成 SVG，每次请求 1–8 个文件。

## 功能

- 文本生成 SVG：原生矢量输出（`image/svg+xml`），不是对位图的描摹。
- 可选 1–5 张参考图，第一张为主要参考。
- 18 种宽高比选项，从竖长的 `1:4` 到横宽的 `4:1`，另有 `auto`。
- 三档质量，每次请求 1–8 个 SVG 文件。

## 必填参数

- `prompt`（string）：想要的作品，1–9,500 个字符。需要的文字请用引号标出，例如 `"TRAILHEAD"`。不能为空白。

## 可选参数

- `image_urls`（string[]）：1–5 张参考图（公开 HTTP(S) URL 或图片 data URI）。没有参考图时不要传该字段。
- `quality`（string）：`low`、`medium` 或 `high`。默认 `medium`。
- `n`（integer）：SVG 文件数量，`1`–`8`。默认 `1`。
- `size`（string）：宽高比。默认 `auto`。见[尺寸](#尺寸)。

## 尺寸

`size` 设置的是宽高比而不是像素尺寸：`auto`、`1:1`、`1:4`、`1:3`、`1:2`、`9:16`、`10:16`、`2:3`、`3:4`、`4:5`、`5:4`、`4:3`、`3:2`、`16:10`、`16:9`、`2:1`、`3:1`、`4:1`。

## 输出

任务完成后，[查询任务状态](/zh/api-manual/task-management/status)和回调内容的 `files` 数组中会返回 SVG 文件（`image/svg+xml`），可直接在矢量编辑软件中打开，或嵌入网页使用。

## 示例

- **仅提示词生成 SVG 图标**：两套方形图标，`medium` 质量。
- **带风格参考图的横幅，带回调**：`3:1` 横幅，文字用引号标出，一张品牌参考图，`quality: high`，并提供 `callback_url`。

## 注意事项

- 要把已有的位图（PNG、JPG）转换为 SVG，请用 [Ideogram Vector 1.0 图片转 SVG](/zh/api-manual/image-series/ideogram-vector-1-0-image-to-vector)。
- `image_urls` 为空数组或超过五张会返回 400。上文未列出的字段会返回 400。`model` 和 `callback_url` 放在请求根级，不要放进 `input`。
- 积分在提交时预扣，取决于 `quality` 和 `n`。`quality: high` 且传入 `image_urls` 时按更高的单文件费率计费；`low` 和 `medium` 有无参考图价格相同。任务失败会全额退还。当前费率见[定价页](https://vidgo.ai/apis/api-pricing)。

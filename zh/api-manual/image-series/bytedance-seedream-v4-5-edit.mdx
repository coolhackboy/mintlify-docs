<Tip>
1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询任务状态](/zh/api-manual/task-management/status)接口获取结果。
</Tip>

使用 Seedream 4.5，通过文本提示词和 1-10 张参考图编辑图像，每次请求生成 1-15 张编辑后的图像。

## 模型

- **bytedance/seedream/v4.5/edit** - 使用提示词和参考图编辑图像。

## 功能

- 使用提示词和参考图编辑图像。
- `image_urls` 接受 1-10 张图像。
- 通过 `n` 控制输出图像数量。

## 输出选项

### 图像尺寸

- `size`：可选。默认：`1:1`。
- 预设：`2K`、`4K`、`1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`3:2`、`2:3`、`21:9`。
- 自定义尺寸时，提供包含整数 `width` 和 `height` 的对象，两者都必须为正数。
- 自定义尺寸也可以使用 `WIDTHxHEIGHT` 字符串，两个正数之间用 `x` 或 `X` 分隔。

### 图像数量

- `n`：可选。要生成的图像数量。`1` 到 `15` 的整数。默认：`1`。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

输入图像 URL 使用 HTTP(S)，并指向公开可访问的 JPEG 或 PNG 文件。

### 提示词

- `prompt`：必填。描述要做的修改。长度：**1-3,000 个字符**。
- 至少包含一个非空白字符。

### 图像 URL

- `image_urls`：必填。提供公开可访问的图像 URL。1-10 项。每项都必须是指向 JPEG 或 PNG 图像的 HTTP(S) URL。

### 安全检查

- `enable_safety_checker`：可选。设为 `true` 开启内容安全检查，设为 `false` 关闭。默认：`true`。

使用 Grok Imagine 将文本提示词生成为图像，以方形、竖版和横版格式探索视觉创意。

## 模型

- **xai/grok-imagine-image/text-to-image** - 根据文本提示词生成图像。

## 功能

- 根据文本提示词生成图像。

## 输出选项

### 图像尺寸

- `size`：可选。可选值：`1:1`、`2:3`、`3:2`、`9:16`、`16:9`。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

使用下面列出的 input 字段。

### 提示词

- `prompt`：必填。描述期望的图像。长度：**1-5,000 个字符**。

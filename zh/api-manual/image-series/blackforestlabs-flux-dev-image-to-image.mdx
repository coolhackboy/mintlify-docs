<Tip>
1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询任务状态](/zh/api-manual/task-management/status)接口获取结果。
</Tip>

## 提交任务

向 `POST /api/generate/submit` 发送 `model: "blackforestlabs/flux/dev/image-to-image"` 和一个 `input` 对象。使用 `Authorization: Bearer VIDGO_API_KEY` 认证。

- `prompt`：必填字符串。描述图像或编辑指令，去除首尾空白后至少一个字符。
- `image_urls`：必填数组，包含一个公开的 HTTP(S) 源图 URL。源图会引导编辑后的输出。
- `n`：正整数，指定输出图像数量，默认 `1`。
- `output_format`：`png` 或 `jpeg`，默认 `png`。

### 画布参数

`size` 定义文生图的画布，默认 `1:1`。图生图会以源图引导输出。请求示例提供了源图、提示词、图像数量和输出格式。

## 获取图像

提交响应会返回 `data.task_id`。使用[查询任务状态](/zh/api-manual/task-management/status)跟踪任务经过 `not_started`、`running`、`finished` 或 `failed` 等状态。

状态为 `finished` 时，从 `data.files[].file_url` 读取图像 URL。状态为 `failed` 时，读取 `data.error_message`。

可以在顶层提供 `callback_url`，通过 [Webhook](/zh/api-manual/task-management/webhooks) 接收最终结果。

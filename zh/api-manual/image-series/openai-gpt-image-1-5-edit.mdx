使用 GPT Image 1.5，通过文字指令、参考图和可选蒙版对选定区域进行有针对性的图像修改。

## 模型

- **openai/gpt-image-1.5/edit** - 使用提示词和参考图编辑图像。

## 功能

- 使用提示词和参考图编辑图像。
- `image_urls` 至少接受 1 张图像。
- 每次编辑请求生成一张图像，并按一张计费。

## 输出选项

### 图像尺寸

- `size`：可选。可选值：`1024x1024`、`1024x1536`、`1536x1024`。默认：`1024x1024`。

### 图像数量

- `n`：可选的兼容参数。可选值：`1`、`2`、`3`、`4`。默认：`1`。每次编辑请求只生成一张图像并按一张计费；更大的值不会增加输出数量。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

### 提示词

- `prompt`：必填。描述要做的修改。长度：**1-1,000 个字符**。
- 至少包含一个非空白字符。

### 图像 URL

- `image_urls`：必填。提供公开可访问的图像 URL。至少 1 项。每项都必须是 HTTP(S) URL。

### 蒙版 URL

- `mask_url`：可选。蒙版图的公开可访问 HTTP(S) URL，用于选定要编辑的区域。

使用 Kling O3 生成最高 4K 的图像，以多种构图和输出格式创作多个变体。

## 模型

- **kwaivgi/kling-image-o3/text-to-image** - 根据文本提示词生成图像。

## 功能

- 根据文本提示词生成图像。
- 可选 `1K`、`2K`、`4K` 输出分辨率。
- 通过 `n` 控制输出图像数量。

## 输出选项

### 图像尺寸

- `size`：可选。可选值：`16:9`、`9:16`、`1:1`、`4:3`、`3:4`、`3:2`、`2:3`、`21:9`。默认：`16:9`。

### 分辨率

- `resolution`：可选。可选值：`1K`、`2K`、`4K`。默认：`1K`。

### 图像数量

- `n`：可选。要生成的图像数量。`1` 到 `9` 的整数。默认：`1`。小数、字符串和布尔值会被拒绝。

### 输出格式

- `output_format`：可选。可选值：`jpeg`、`png`、`webp`。默认：`png`。

## 高级参数

只有省略可选 input 字段时才使用默认值。显式传入 `null` 或空字符串会被拒绝。可以传入空的 `elements` 数组。

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

只发送本工作流支持的 input 字段。不支持的 `input` 字段会在扣除积分前被拒绝。输入 URL 必须使用 HTTP(S)、包含主机名，且不含内嵌凭证。

### 提示词

- `prompt`：必填。描述期望的图像。长度：**1-2,000 个字符**。
- 提供时不能为空。

### 主体元素

- `elements`：可选，主体参考对象数组。在提示词中以 `@Element1`、`@Element2` 等引用。
- `elements[].frontal_image_url`：可选，主体正面视图的公开 HTTP(S) URL。
- `elements[].reference_image_urls`：可选，其他公开 HTTP(S) 图像 URL 组成的数组。
- 元素对象可以包含其他字段。未规定元素数量上限。

## 计费因素

计费取决于输出分辨率（`resolution`）和输出图像数量（`n`）。文生图和图像编辑使用相同的计费标准。参考图和主体元素不会额外计费。

积分在提交时扣除，任务失败会退还。

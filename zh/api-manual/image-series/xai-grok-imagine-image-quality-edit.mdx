使用 Grok Imagine Image Quality 结合文字指令和视觉参考开发新的图像变体，输出最高 2K。

## 模型

- **xai/grok-imagine-image-quality/edit** - 使用提示词和参考图编辑图像。

## 功能

- 使用提示词和参考图编辑图像。
- `image_urls` 接受 1-3 张图像。
- 可选 `1K`、`2K` 输出分辨率。
- 通过 `n` 控制输出图像数量。

## 输出选项

### 宽高比

- `aspect_ratio`：可选。可选值：`1:1`、`2:3`、`3:2`、`9:16`、`16:9`。默认：`1:1`。

### 分辨率

- `resolution`：可选。可选值：`1K`、`2K`。默认：`1K`。

### 图像数量

- `n`：可选。要生成的图像数量。整数，至少为 `1`。默认：`1`。未规定最大值；小数、字符串和布尔值会被拒绝。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

只发送本工作流支持的 input 字段。不支持的 `input` 字段会在扣除积分前被拒绝。输入 URL 必须使用 HTTP(S)、包含主机名，且不含内嵌凭证。

### 提示词

- `prompt`：必填。描述要做的修改。最小长度：**1 个字符**。
- 值必须是字符串且不能为空。未规定提示词最大长度。

### 图像 URL

- `image_urls`：必填。提供公开可访问的图像 URL。1-3 项。每项都必须是 HTTP(S) URL。

## 计费因素

计费取决于输出分辨率（`resolution`）和输出图像数量（`n`）。参考图数量（`image_urls`）按请求单独计输入费用一次，不乘以 `n`。

积分在提交时扣除，任务失败会退还。

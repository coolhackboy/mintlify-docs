<Tip>
1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询任务状态](/zh/api-manual/task-management/status)接口获取结果。
</Tip>

使用 FLUX.2 Pro 创作细节丰富的图像，用自然语言控制主体、构图和画面中的文字，最高 2K。

## 模型

- **blackforestlabs/flux-2-pro/text-to-image** - 根据文本提示词生成图像。

## 功能

- 根据文本提示词生成图像。
- 可选 `1K`、`2K` 输出分辨率。

## 输出选项

### 图像尺寸

- `size`：必填。可选值：`1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`3:2`、`2:3`、`auto`。

### 分辨率

- `resolution`：必填。可选值：`1K`、`2K`。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

发送本页列出的 input 字段。

### 提示词

- `prompt`：必填。描述期望的图像。长度：**3-5,000 个字符**。

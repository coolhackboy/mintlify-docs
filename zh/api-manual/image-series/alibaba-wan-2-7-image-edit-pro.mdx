使用文字和多张参考图引导 Wan 2.7 Pro 编辑，为已有视觉概念打造新的外观。

## 模型

- **alibaba/wan-2.7/image-edit-pro** - 使用提示词和参考图编辑图像。

## 功能

- 使用提示词和参考图编辑图像。
- `image_urls` 接受 1-4 张图像。
- 通过 `n` 控制输出图像数量。

## 输出选项

### 图像尺寸

- `size`：可选。默认：`1024x1024`。
- 预设：`512x512`、`1024x1024`、`768x1024`、`1024x768`、`576x1024`、`1024x576`。
- 自定义尺寸时，提供包含整数 `width` 和 `height` 的对象，两者都必须为正数。

### 图像数量

- `n`：可选。要生成的图像数量。`1` 到 `4` 的整数。默认：`1`。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

只发送本工作流支持的 input 字段。不支持的 `input` 字段会在扣除积分前被拒绝。输入 URL 必须使用 HTTP(S)、包含主机名，且不含内嵌凭证。

### 提示词

- `prompt`：必填。描述要做的修改。长度：**1-5,000 个字符**。
- 提供时不能为空。

### 图像 URL

- `image_urls`：必填。提供公开可访问的图像 URL。1-4 项。每项都必须是 HTTP(S) URL。顺序有意义：在提示词中以 image 1、image 2、image 3、image 4 引用。不接受单个字符串或 Base64 图像。

### 种子

- `seed`：可选。设置生成种子。整数。

## 计费因素

计费取决于所选模型版本和输出图像数量（`n`）。输出尺寸不会额外计费。参考图不会额外加价。

积分在提交时扣除，任务失败会退还。

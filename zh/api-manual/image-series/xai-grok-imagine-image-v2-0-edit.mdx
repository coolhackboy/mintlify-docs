使用 Grok Imagine Image 2.0 细化图像，结合参考图和精确指令，在修改视觉细节的同时保留主体。

## 模型

- **xai/grok-imagine-image-v2.0/edit** - 使用提示词和参考图编辑图像。

## 功能

- 使用提示词和参考图编辑图像。
- `image_urls` 接受 1-3 张图像。
- 可选 `1K`、`2K` 输出分辨率。
- 通过 `n` 控制输出图像数量。

## 输出选项

### 宽高比

- `aspect_ratio`：可选。可选值：`1:1`、`2:3`、`3:2`、`9:16`、`16:9`。默认：`1:1`。

### 分辨率

- `resolution`：可选。可选值：`1K`、`2K`。默认：`1K`。

### 质量

- `quality`：可选。可选值：`low`、`medium`。默认：`medium`。

### 图像数量

- `n`：可选。要生成的图像数量。`1` 到 `4` 的整数。默认：`1`。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

只发送本工作流支持的 input 字段。不支持的 `input` 字段会在扣除积分前被拒绝。输入 URL 必须使用 HTTP(S)、包含主机名，且不含内嵌凭证。

### 提示词

- `prompt`：必填。描述要做的修改。长度：**1-8,000 个字符**。
- 提供时不能为空。

### 图像 URL

- `image_urls`：必填。提供公开可访问的图像 URL。1-3 项。每项都必须是 HTTP(S) URL。

## 计费因素

计费取决于输出质量（`quality`）、输出分辨率（`resolution`）和输出图像数量（`n`）。输入图像数量（`image_urls`）按请求单独计费一次，不乘以 `n`。

积分在提交时扣除，任务失败会退还。

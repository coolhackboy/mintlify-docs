使用 Kling O1 结合视觉参考和主体元素编辑图像，支持批量输出，分辨率最高 2K。

## 模型

- **kwaivgi/kling-image-o1** - 使用提示词和参考图编辑图像。

## 功能

- 使用提示词和参考图编辑图像。
- `image_urls` 接受 1-10 张图像。
- 可选 `1K`、`2K` 输出分辨率。
- 通过 `elements` 提供额外的主体参考。
- 通过 `n` 控制输出图像数量。

## 输出选项

### 图像尺寸

- `size`：可选。可选值：`auto`、`16:9`、`9:16`、`1:1`、`4:3`、`3:4`、`3:2`、`2:3`、`21:9`。默认：`auto`。

### 分辨率

- `resolution`：可选。可选值：`1K`、`2K`。默认：`1K`。

### 图像数量

- `n`：可选。要生成的图像数量。`1` 到 `9` 的整数。默认：`1`。

### 输出格式

- `output_format`：可选。可选值：`jpeg`、`png`、`webp`。默认：`png`。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

只发送本工作流支持的 input 字段。不支持的 `input` 字段会在扣除积分前被拒绝。输入 URL 必须使用 HTTP(S)、包含主机名，且不含内嵌凭证。

### 提示词

- `prompt`：必填。描述期望的图像。长度：**1-2,000 个字符**。
- 提供时不能为空。

### 图像 URL

- `image_urls`：必填。提供公开可访问的图像 URL。1-10 项。每项都必须是 HTTP(S) URL。不接受单个 URL 字符串或 Base64 输入。

### 主体元素

- `elements`：可选，主体参考对象数组。在提示词中按数组顺序以 `@Element1`、`@Element2` 等引用。对象中的其他属性会被保留。未规定元素数量或额外视图数量上限。

- `elements[].frontal_image_url`：可选。使用公开可访问的 HTTP(S) URL。
- `elements[].reference_image_urls`：可选。提供数组。每项都必须是 HTTP(S) URL。

## 计费因素

计费取决于输出图像数量（`n`）。两种支持的分辨率计费标准相同。参考图和主体元素不会额外计费。

积分在提交时扣除，任务失败会退还。

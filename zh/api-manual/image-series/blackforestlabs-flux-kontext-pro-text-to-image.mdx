使用 FLUX Kontext Pro 将自然语言描述生成为图像，从插画到构图完整的场景和设计概念。

## 模型

- **blackforestlabs/flux-kontext-pro/text-to-image** - 根据文本提示词生成图像。

## 功能

- 根据文本提示词生成图像。

## 输出选项

### 图像尺寸

- `size`：可选。输出宽高比。可选值：`1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`21:9`、`9:21`。默认：`1:1`。

### 输出格式

- `output_format`：可选。输出图像文件格式。可选值：`png`、`jpg`。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

### 提示词

- `prompt`：必填。描述期望的图像。长度：**1-2,000 个字符**。
- 至少包含一个非空白字符。

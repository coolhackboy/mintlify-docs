使用 GPT Image 1.5 将文字描述的图像构思生成方形、竖版或横版画面，每次请求最多生成四个变体。

## 模型

- **openai/gpt-image-1.5/text-to-image** - 根据文本提示词生成图像。

## 功能

- 根据文本提示词生成图像。
- 通过 `n` 控制输出图像数量。

## 输出选项

### 图像尺寸

- `size`：可选。可选值：`1024x1024`、`1024x1536`、`1536x1024`。默认：`1024x1024`。

### 图像数量

- `n`：可选。要生成的图像数量。可选值：`1`、`2`、`3`、`4`。默认：`1`。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

### 提示词

- `prompt`：必填。描述期望的图像。长度：**1-1,000 个字符**。
- 至少包含一个非空白字符。

使用 Grok Imagine Image Quality 创作 1K 或 2K 图像变体，提供竖版、横版和方形设计的画幅选项。

## 模型

- **xai/grok-imagine-image-quality/text-to-image** - 根据文本提示词生成图像。

## 功能

- 根据文本提示词生成图像。
- 可选 `1K`、`2K` 输出分辨率。
- 通过 `n` 控制输出图像数量。

## 输出选项

### 宽高比

- `aspect_ratio`：可选。可选值：`1:1`、`2:3`、`3:2`、`9:16`、`16:9`。默认：`1:1`。

### 分辨率

- `resolution`：可选。可选值：`1K`、`2K`。默认：`1K`。

### 图像数量

- `n`：可选。要生成的图像数量。整数，至少为 `1`。默认：`1`。未规定最大值；小数、字符串和布尔值会被拒绝。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

只发送本工作流支持的 input 字段。不支持的 `input` 字段会在扣除积分前被拒绝。

### 提示词

- `prompt`：必填。描述期望的图像。最小长度：**1 个字符**。
- 值必须是字符串且不能为空。未规定提示词最大长度。

## 计费因素

计费取决于输出分辨率（`resolution`）和输出图像数量（`n`）。

积分在提交时扣除，任务失败会退还。

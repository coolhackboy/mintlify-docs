使用 Seedream 5.0 Lite 探索图像创意，根据文字描述批量生成视觉变体。

## 模型

- **bytedance/seedream/v5/lite/text-to-image** - 根据文本提示词生成图像。

## 功能

- 根据文本提示词生成图像。
- 通过 `n` 控制输出图像数量。

## 输出选项

### 图像尺寸

- `size`：可选。默认：`1:1`。
- 预设：`2K`、`3K`、`1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`3:2`、`2:3`、`21:9`。
- 自定义尺寸时，提供包含整数 `width` 和 `height` 的对象，两者都必须为正数。
- 自定义尺寸也可以使用 `WIDTHxHEIGHT` 字符串，两个正数之间用 `x` 或 `X` 分隔。

### 图像数量

- `n`：可选。要生成的图像数量。`1` 到 `15` 的整数。默认：`1`。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

### 提示词

- `prompt`：必填。描述期望的图像。长度：**3-3,000 个字符**。
- 长度按去除首尾空白后计算。

### 安全检查

- `enable_safety_checker`：可选。设为 `true` 开启内容安全检查，设为 `false` 关闭。默认：`true`。

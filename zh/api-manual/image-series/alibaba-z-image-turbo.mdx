## 模型

`alibaba/z-image/turbo` 根据文本生成图像，也可编辑单张参考图。

## 输入参数

- `prompt`：必填字符串，1 到 1000 个字符。描述要生成的图像或要做的编辑。
- `image_urls`：可选数组，只包含一个 HTTP(S) 图像 URL。提供此字段即选择图像编辑。
- `size`：文生图必填，图像编辑可选。取值：`1:1`、`4:3`、`3:4`、`16:9`、`9:16`。
- `enable_safety_checker`：可选布尔值。默认 `true`。

## 文生图

```json
{
  "model": "alibaba/z-image/turbo",
  "input": {
    "prompt": "A ceramic vase on a wooden table in soft daylight.",
    "size": "1:1",
    "enable_safety_checker": true
  }
}
```

## 图像编辑

```json
{
  "model": "alibaba/z-image/turbo",
  "input": {
    "prompt": "Add soft studio lighting to this product photo.",
    "image_urls": ["https://example.com/reference.png"],
    "enable_safety_checker": true
  }
}
```

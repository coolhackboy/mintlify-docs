使用 xAI TTS 将文本转换为语音，可从五种音色和多种语言中选择，适用于旁白、对话和口播内容。

## 模型

- **xai/tts/v1** - 将文本转换为语音。

## 功能

- 将文本转换为语音。
- 使用 `voice` 选择音色，使用 `language_code` 指定朗读语言。
- 通过 `text` 中的标签控制停顿、笑声、叹息、耳语和放慢语速。

## 输出选项

### 输出格式

- `output_format`：可选。传入包含以下字段的对象。

- `output_format.codec`：可选。可选值：`mp3`、`wav`、`pcm`、`mulaw`、`alaw`。默认：`mp3`。
- `output_format.sample_rate`：可选。采样率（Hz）。可选值：`8000`、`16000`、`22050`、`24000`、`44100`、`48000`。默认：`24000`。
- `output_format.bit_rate`：可选。MP3 比特率（bit/s）。可选值：`32000`、`64000`、`96000`、`128000`、`192000`、`null`。MP3 默认：`128000`。
- `mp3` 使用 `output_format.bit_rate` 选择比特率。`wav`、`pcm`、`mulaw` 和 `alaw` 请省略 `bit_rate` 或设为 `null`。

## 高级参数

在请求根级设置 `model` 和可选的 `callback_url`。所有工作流程参数（包括输出选项）都放在 `input` 中。

### 文本

- `text`：必填。要朗读的文本。长度：**1-15,000 个字符**。
- 长度按去除首尾空白后的文本计算。文本中的标签、标点和空格都计入长度。
- 在需要的位置加入 `[laugh]`、`[pause]` 或 `[sigh]`。耳语段落使用 `<whisper>text</whisper>`，放慢语速使用 `<slow>text</slow>`。

### 音色

- `voice`：可选。选择音色。可选值：`eve`、`ara`、`rex`、`sal`、`leo`。默认：`eve`。

### 语言代码

- `language_code`：可选。字符串。默认：`auto`。

## 输出文件

- 读取返回的 `files` 数组中的每一项。
- 生成的音频 `file_type` 为 `"audio"`。
- 使用 `file_url` 下载生成的语音。

## 请求示例

```json
{
  "model": "xai/tts/v1",
  "input": {
    "text": "Welcome to our story. [pause] <whisper>Listen closely.</whisper> [laugh] Let us begin.",
    "voice": "eve",
    "language_code": "auto",
    "output_format": {
      "codec": "mp3",
      "sample_rate": 24000,
      "bit_rate": 128000
    }
  }
}
```

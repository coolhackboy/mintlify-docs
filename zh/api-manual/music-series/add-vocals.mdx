## 使用指南

- 此接口为现有伴奏音轨添加 AI 生成的人声
- 上传伴奏文件，并提供人声的歌词或描述
- 适合将伴奏音轨变成完整歌曲

## 参数详情

- 必填参数：

  - `upload_url`：伴奏音频文件 URL

  - `prompt`：人声的歌词或描述

  - `title`：生成曲目的名称

  - `style`：引导人声演绎的音乐风格

  - `negative_tags`：生成时要排除的风格

- 模型选择：

  - **V5**：音乐表现力更出色，生成更快

  - **V4_5PLUS**：音色更丰富（默认）

## 使用说明

- `prompt` 参数既是歌词，也是人声的创作方向
- 使用 `style` 指定人声演绎风格（例如 "Pop Ballad"、"Rock"、"R&B"）
- 结合 `vocal_gender` 可以更好地控制人声输出

## 可选参数

- `model` (string)：AI 模型版本。可选值：`V4_5PLUS`（默认）、`V5`。

- `vocal_gender` (string)：人声性别偏好。`m` 为男声，`f` 为女声。注意：此参数只能提高概率，无法保证生成指定性别的人声。

- `style_weight` (number)：遵循风格的强度。取值 0-1，最多 2 位小数。

- `weirdness_constraint` (number)：控制创意偏离程度。取值 0-1，最多 2 位小数。

- `audio_weight` (number)：音频特征的平衡权重。取值 0-1，最多 2 位小数。

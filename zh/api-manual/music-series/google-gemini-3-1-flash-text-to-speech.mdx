使用 Gemini 3.1 Flash TTS 生成语音，支持风格指令和可选音色，适用于旁白或双人对话。

## 模型

- **google/gemini-3.1-flash/text-to-speech** - 将文本转换为语音。

## 功能

- 将文本转换为语音。
- 使用单一音色，或两个说话人别名。
- 使用 `style_instructions` 和 `temperature` 控制演绎方式。
- 使用 `voice` 选择音色，使用 `language_code` 指定朗读语言。

## 输出选项

### 输出格式

- `output_format`：可选。可选值：`mp3`、`wav`、`ogg_opus`。默认：`mp3`。

## 高级参数

在请求根级设置 `model` 和可选的 `callback_url`。所有工作流程参数（包括输出选项）都放在 `input` 中。

使用参数参考中的字段配置语音生成。

- 提供 `speakers` 时，必须恰好包含两个不同的 `speaker_id` 别名，只能使用字母、数字和下划线。语音使用为每位说话人指定的音色。

### 文本

- `text`：必填。要朗读的文本。长度：**1-50,000 个字符**。
- 填写要朗读的内容，可加入 `[short pause]`、`[whispering]`、`[laughing]` 等音频标签。对话中每一轮都以对应的 `speaker_id` 加冒号开头。

### 风格指令

- `style_instructions`：可选。描述语音应如何演绎。

### 音色

### 温度

- `temperature`：可选。控制语音生成的随机性。数值 `0` 到 `2`。默认：`1`。

## 输出文件

- 读取返回的 `files` 数组中的每一项。
- 生成的音频 `file_type` 为 `"audio"`。
- 从 `files[].file_url` 读取音频 URL。

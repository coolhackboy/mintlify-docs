1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。

使用 ElevenLabs V3 将文本转为语音，可选择音色、控制语言，并可返回时间戳，适用于旁白和对话。

## 模型

- **elevenlabs/tts/eleven-v3** - 将文本转换为语音。

## 功能

- 将文本转换为语音。
- 可在生成音频的同时请求时间戳。
- 使用 `voice` 选择音色，使用 `language_code` 指定朗读语言。

## 高级参数

在请求根级设置 `model` 和可选的 `callback_url`。所有工作流程参数（包括输出选项）都放在 `input` 中。

### 文本

- `text`：必填。要朗读的文本。长度：**1-5,000 个字符**。
- 检查字符上限前会先去除首尾空白。

### 音色

- `voice`：可选。选择音色。字符串。默认：`Rachel`。
- 可选值：`Aria`、`Roger`、`Sarah`、`Laura`、`Charlie`、`George`、`Callum`、`River`、`Liam`、`Charlotte`、`Alice`、`Matilda`、`Will`、`Jessica`、`Eric`、`Chris`、`Brian`、`Daniel`、`Lily`、`Bill`、`Rachel`。

### 稳定性

- `stability`：可选。控制音色稳定性。数值 `0` 到 `1`。默认：`0.5`。

### 时间戳

- `timestamps`：可选。在返回音频的同时请求时间戳信息。使用 `true` 或 `false`。默认：`false`。

### 语言代码

- `language_code`：可选。ISO 639-1 语言代码，例如英语为 `en`，中文为 `zh`。

### 文本规范化

- `apply_text_normalization`：可选。选择文本规范化行为。可选值：`auto`、`on`、`off`。默认：`auto`。

## 输出文件

- 读取返回的 `files` 数组中的每一项。
- 生成的音频 `file_type` 为 `"audio"`。
- 返回的 `timestamps.json` 是单独的一项，`file_type` 为 `"other"`。如有可选的文件元数据，请一并保留。

## 示例

每个示例都包含请求、对应的已完成任务响应和生成的音频。将请求提交到 `POST https://api.vidgo.ai/api/generate/submit`，然后使用提交返回的任务 ID 查询 `GET https://api.vidgo.ai/api/generate/status/{task_id}`。

使用 ElevenLabs Turbo v2.5 生成语音旁白，可调节语速、演绎风格和音色相似度，并可选返回文本对齐数据。

## 模型

- **elevenlabs/tts/turbo-v2.5** - 将文本转换为语音。

## 功能

- 将文本转换为语音。
- 可在生成音频的同时请求时间戳。
- 使用 `voice` 选择音色，使用 `language_code` 指定朗读语言。

## 高级参数

在请求根级设置 `model` 和可选的 `callback_url`。所有工作流程参数（包括输出选项）都放在 `input` 中。

以下参数定义该模型的 `input` 对象。

### 音色

- `voice`：可选。选择音色名称或兼容的音色 ID。字符串。默认：`Rachel`。

### 稳定性

- `stability`：可选。控制音色稳定性。数值 `0` 到 `1`。默认：`0.5`。

### 相似度增强

- `similarity_boost`：可选。控制音色相似度。数值 `0` 到 `1`。默认：`0.75`。

### 风格

- `style`：可选。设置音色风格强度。数值 `0` 到 `1`。默认：`0`。

### 语速

- `speed`：可选。设置语速。数值 `0.7` 到 `1.2`。默认：`1`。

### 时间戳

- `timestamps`：可选。在返回音频的同时请求时间戳信息。使用 `true` 或 `false`。默认：`false`。

### 前文

- `previous_text`：可选。提供前文作为语音上下文。字符串，也可为 `null`。

### 后文

- `next_text`：可选。提供后文作为语音上下文。字符串，也可为 `null`。

### 语言代码

- `language_code`：可选。使用 ISO 639-1 代码设置朗读语言，例如 `en`、`fr`、`de`、`ja`、`vi`、`hu` 或 `no`。也可为 `null`。

### 文本规范化

- `apply_text_normalization`：可选。控制朗读前如何处理数字、日期和货币：`auto` 自动选择是否规范化，`on` 启用规范化，`off` 直接朗读所给文本。默认：`auto`。

### 文本

- `text`：必填。要朗读的文本。去除首尾空白后长度为 **1-40,000 个 Unicode 字符**，且至少包含一个可见字符。

## 输出文件

- 读取返回的 `files` 数组中的每一项。
- 生成的音频 `file_type` 为 `"audio"`。
- 时间戳和对齐文件可能使用 `file_type: "other"`。如有可选的文件元数据，请一并保留。

## 示例

每个示例都包含请求、对应的已完成任务响应和生成的音频。将请求提交到 `POST https://api.vidgo.ai/api/generate/submit`，然后使用提交返回的任务 ID 查询 `GET https://api.vidgo.ai/api/generate/status/{task_id}`。

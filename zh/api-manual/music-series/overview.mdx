音乐模型都通过 `POST /api/generate/submit` 调用。在 `model` 中传入 model ID，在 `input` 中传入参数，并可选传入 `callback_url`。请求会立即返回 `task_id`，任务异步执行。

## 工作流程

Suno 与其他厂商使用不同的结果接口：

- **Suno**：轮询[查询音乐详情](/zh/api-manual/music-series/query-music-detail)，或在 `callback_url` 接收结果（参见[音乐 Webhook](/zh/api-manual/music-series/music-webhook)）。
- **MiniMax、ElevenLabs**：轮询统一的[获取任务状态](/zh/api-manual/task-management/status)接口，或在 `callback_url` 接收结果（参见 [Webhook 回调](/zh/api-manual/task-management/webhooks)）。

## 注意事项

- 每个模型页面列出了其 model ID 的参数、限制和模式。各模型之间的参数不通用。
- 生成的文件在创建后 24 小时内有效，请及时下载并保存。
- URL 输入必须是可公开访问的 HTTP(S) URL。如需使用本地文件，请先通过[文件管理](/zh/api-manual/file-series/upload-url)上传。

使用 Happy Horse 参考生视频，以参考图片塑造新的视频场景，将视觉方向与文字描述结合，最高 1080p。

## 模型

- **alibaba/happyhorse-1.0/reference-to-video** - 在参考素材和提示词的引导下生成新视频。

## 功能

- 使用 1 到 9 张参考图片引导视频生成。
- 输出分辨率可选 `720p`、`1080p`。

## 时长选项

- **3-15 秒** - 以整数设置 `duration`。默认：**5 秒**。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级，下列参数放在 `input` 内。

只发送本工作流支持的 input 字段。不支持的 `input` 字段会在扣除积分前被拒绝。输入 URL 必须使用 HTTP(S)，带主机名，且不含内嵌凭证。

### 提示词

- `prompt`：必填。描述场景和期望的运动。
- 提供时提示词不能为空。最大长度：**2,500 个字符**。

### 参考输入

- `reference_image_urls`：必填；最多 9 张图片。
- 在提示词中描述所引用的主体；无需使用 `character1` 和 `character2` 标记。

### 分辨率

- `resolution`：`720p`、`1080p`。默认：`1080p`。

### 宽高比

- `aspect_ratio`：`16:9`、`9:16`、`1:1`、`4:3`、`3:4`。默认：`16:9`。

### 种子

- `seed` 可选。传入 `0` 到 `2147483647` 的整数。

### 安全检查

- `enable_safety_checker` 可选。设为 `true` 或 `false` 控制安全检查。

## 定价

价格取决于所选模型和适用的输出设置。当前价格请在 Vidgo 仪表盘查看。

提交时扣除积分，任务失败后退还。

<Tip>
1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询任务状态](/zh/api-manual/task-management/status)接口获取结果。

## 输入路由

提供的图像字段决定生成工作流程。
所有 Kling 1.6 请求都需要 `prompt` 和 `duration`。

- 不提供任何图像字段时生成文生视频。
- 提供 `start_image_url` 时生成图生视频。
- 使用 `kling-1.6/pro` 并提供 `start_image_url` 和 `end_image_url`，可同时控制首帧和尾帧。
- 提供包含 1 到 4 张参考图的 `image_urls` 时生成 Elements。

`image_urls` 不能与 `start_image_url`、`end_image_url` 或 `cfg_scale` 同时使用。

## 参数兼容性

| 模型与工作流程 | Vidgo 的识别方式 | 支持的参数 |
| --- | --- | --- |
| 文生视频（`standard` 或 `pro`） | 无图像字段 | `prompt`、`duration`、`aspect_ratio`、`negative_prompt`、`cfg_scale` |
| Standard 图生视频 | `kling-1.6/standard` 且提供 `start_image_url` | `prompt`、`duration`、`start_image_url`、`negative_prompt`、`cfg_scale` |
| Pro 图生视频 | `kling-1.6/pro` 且提供 `start_image_url`，可选 `end_image_url` | `prompt`、`duration`、`aspect_ratio`、`start_image_url`、`end_image_url`、`negative_prompt`、`cfg_scale` |
| Elements（`standard` 或 `pro`） | `image_urls` | `prompt`、`duration`、`aspect_ratio`、`negative_prompt`、`image_urls` |

注意事项：

- `end_image_url` 需要同时提供 `start_image_url`，且仅 `kling-1.6/pro` 支持。
- `kling-1.6/standard` 图生视频不支持 `aspect_ratio`。
- Elements 支持 1 到 4 个 `image_urls`，不支持 `cfg_scale`。
- `prompt` 和 `negative_prompt` 最多 2500 个字符。
- 提供 `cfg_scale` 时，取值必须在 0 到 1 之间。

## 响应与状态

提交接口返回 Vidgo 的 `task_id`。使用它调用统一的查询任务状态接口获取最终视频 URL。

首次提交的响应包含 `status`，上游视频任务创建后通常为 `running`。如果在创建上游任务时提交失败，状态可能为 `failed`，可通过状态接口查看该任务。

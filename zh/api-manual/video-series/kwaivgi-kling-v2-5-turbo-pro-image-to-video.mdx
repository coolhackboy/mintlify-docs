使用 Kling 2.5 Turbo Pro，以首帧、尾帧或两者加上文本提示词生成视频。

## 模型

- **kwaivgi/kling-v2.5-turbo-pro/image-to-video** - 根据图像输入生成视频。

## 功能

- 根据图像输入生成视频。
- 用 `start_image_url`、`end_image_url` 或两者引导生成。

## 时长选项

- **5、10 秒** - `duration` 设为整数。可选。默认值：**5 秒**。字符串、布尔值、小数时长和 `null` 会被拒绝。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流程参数（包括输出选项）都放在 `input` 中。

只发送该工作流程支持的 input 字段。不支持的 `input` 字段会在扣除积分前被拒绝。输入 URL 必须使用 HTTP(S)、包含主机名，且不含内嵌凭据或空白字符。图像字段不接受数组或 Base64。

### 提示词

- `prompt`：必填。描述场景和期望的动作。长度：**1-2,500 个字符**。
- 请提供字符串，不能是数字、布尔值、数组或对象。检查 2,500 个 Unicode 字符上限之前会先去除首尾空白。

### 首帧图像 URL

- `start_image_url`：首帧的公开 HTTP(S) URL。仅在省略 `end_image_url` 时必填。

### 尾帧图像 URL

- `end_image_url`：尾帧的公开 HTTP(S) URL。仅在省略 `start_image_url` 时必填。
- 至少提供一帧：仅首帧、仅尾帧或两者都提供。不使用的 URL 字段请省略；空字符串和 `null` 会被拒绝。

### 宽高比

- `aspect_ratio`：可选字符串。未规定预设选项或默认值。不使用时省略。

### 负面提示词

- `negative_prompt`：可选。描述需要避免的内容。

## 计费因素

计费取决于视频时长（`duration`）。文生视频和图生视频费率相同。

提交时扣除积分，任务失败时退还。

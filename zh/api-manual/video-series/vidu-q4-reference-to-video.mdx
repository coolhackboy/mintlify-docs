Vidu Q4 参考生视频根据最多 12 张参考图（角色、产品、服装、场景）和最多 3 段人声片段生成 3–16 秒的视频，可选原生音频，输出最高 4K。适合短剧中反复出现的角色、组合产品、模特与场景的广告，以及配音角色短片。

Vidu Q4 是生数科技（ShengShu Technology）的视频模型，上游于 2026 年 10 月以 Vidu Q4 Preview 发布。它没有文生视频模式，每个请求都从图片开始。Vidgo 提供两个 model ID：[图生视频](/zh/api-manual/video-series/vidu-q4-image-to-video)和[参考生视频](/zh/api-manual/video-series/vidu-q4-reference-to-video)。

## 模型

- **vidu/q4/reference-to-video** — Vidu Q4 参考生视频，使用 1–12 张参考图和最多 3 段音色参考，3–16 秒，540p 到 4K。

## 功能

- 一次请求支持 1–12 张参考图的参考生视频。
- 通过 `reference_audio_urls` 提供最多 3 段音色参考。
- 用提示词标签 `[@reference_image_N]` 和 `[@reference_audio_N]` 指明每个参考素材的用途。
- 通过 `generate_audio` 可选生成原生音频。
- 五种宽高比，五种分辨率（`540p` 到 `4k`）。
- 时长为 3 到 16 秒的整数。

## 必填参数

- `prompt`（string）：场景以及每个参考素材的用法。不能为空白，最多 5,000 个字符。
- `reference_image_urls`（string[]）：1–12 个公开 HTTP(S) 图片 URL。

## 可选参数

- `reference_audio_urls`（string[]）：最多 3 个公开 HTTP(S) 音频 URL，作为音色参考。简短、干净的 MP3 人声片段效果最好。
- `aspect_ratio`（string）：`16:9`、`9:16`、`4:3`、`3:4` 或 `1:1`。省略时使用上游默认值（16:9）。
- `generate_audio`（boolean）：随视频生成原生音频。省略时不生成音频。
- `duration`（integer）：输出时长，`3`–`16` 秒。默认 `5`。
- `resolution`（string）：`540p`、`720p`、`1080p`、`2k` 或 `4k`（不区分大小写）。默认 `720p`。
- `enable_safety_checker`（boolean）：开启或关闭上游安全检查。

## 分辨率

| `resolution` | 适用场景 |
| --- | --- |
| `540p` | 快速、低成本的草稿 |
| `720p` | 默认；社交平台和网页短片 |
| `1080p` | 全高清交付 |
| `2k` | 高分辨率母版 |
| `4k` | 主视觉镜头和大屏 |

分辨率决定每秒的计费档位。

## 输出

任务完成后，[查询任务状态](/zh/api-manual/task-management/status)和回调内容的 `files` 数组中会返回一个 MP4 视频。

## 示例

- **两张参考图，720p**：模特和运动鞋分别以 `[@reference_image_1]`、`[@reference_image_2]` 引用，竖屏 `9:16`。
- **角色加音色参考与音频，1080p**：一个角色和一个场景，一段人声以 `[@reference_audio_1]` 引用，带引号的对白，`generate_audio: true`，并提供 `callback_url`。

## 注意事项

- 参考素材按数组顺序编号：`reference_image_urls` 的第一个 URL 是 `[@reference_image_1]`，`reference_audio_urls` 的第一个 URL 是 `[@reference_audio_1]`。
- 本 ID 不接受 `image_urls`，传入会返回 400。要让单张起始帧动起来，请用 [Vidu Q4 图生视频](/zh/api-manual/video-series/vidu-q4-image-to-video)。Vidu Q4 没有文生视频模式。
- 参考图超过 12 张或参考音频超过 3 段会返回 400。
- `model` 和 `callback_url` 放在请求根级，不要放进 `input`。
- 积分在提交时预扣，按 `resolution` 和 `duration`（每输出秒）计算。参考图、参考音频和 `generate_audio` 不影响费率。任务失败会全额退还。当前费率见[定价页](https://vidgo.ai/apis/api-pricing)。

使用 Happy Horse 1.1 图生视频让静态图片动起来，生成最长 15 秒的视频场景，支持多种画面比例。

## 模型

- **alibaba/happyhorse-1.1/image-to-video** - 根据图片输入生成视频。

## 功能

- 根据图片输入生成视频。
- `image_urls` 只接受 1 张图片。
- 输出分辨率可选 `720p`、`1080p`。

## 时长选项

- **3-15 秒** - 以整数设置 `duration`。可选。默认：**5 秒**。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

只发送本工作流支持的 input 字段。不支持的 `input` 字段会在扣除积分前被拒绝。输入 URL 必须使用 HTTP(S)，带主机名，且不含内嵌凭证。图片输入也接受图片 Data URI 或原始 Base64。图片转换和媒体校验会在扣除积分前完成。

`duration` 和 `seed` 也接受整数字符串，如 `"5"`；小数（如 `5.0`）和小数字符串（如 `"5.0"`）会被拒绝。null 或空值会使用默认时长或省略种子。支持的布尔字段也接受 `0`/`1`，以及不区分大小写的字符串 `true`/`false`、`1`/`0`、`yes`/`no`、`y`/`n` 和 `on`/`off`；null 表示省略该字段。首尾空白会被去除，分辨率取值不区分大小写。

### 提示词

- `prompt`：可选。描述场景和期望的运动。最多：**2,500 个 Unicode 字符**。
- 首尾空白会被去除。省略、null、空字符串和仅含空白的值都视为未提供。

### 图片 URL

- `image_urls`：必填。只能提供 1 项。每项可以是公开的 HTTP(S) URL、图片 Data URI 或原始 Base64。图片顺序会保留。

### 分辨率

- `resolution`：可选。可选值：`720p`、`1080p`。默认：`1080p`。

### 种子

- `seed`：可选。设置生成种子。`0` 到 `2147483647` 的整数。

### 安全检查

- `enable_safety_checker`：可选。控制安全检查。使用 `true` 或 `false`。

## 定价

用量等于输出秒数乘以所选分辨率的费率。当前价格见[定价](https://vidgo.ai/apis/api-pricing)。

提交时扣除积分，任务失败后退还。

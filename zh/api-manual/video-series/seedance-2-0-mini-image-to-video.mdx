## 模型

- **seedance-2.0-mini/image-to-video** - 快速的 Seedance 2.0 Mini 图生视频

## 功能

- **图生视频**：最多使用两张图片作为起始帧和可选的结束帧。
- **可选音频**：可请求与视频一起生成音频。

## 注意事项

- `prompt` 和 `duration` 为必填。
- `duration` 支持 `4` 到 `15` 的整数。
- `resolution` 支持 `480p` 和 `720p`，默认 `720p`。
- `aspect_ratio` 接受 `auto`、`21:9`、`16:9`、`4:3`、`1:1`、`3:4` 或 `9:16`。
- `image_urls` 接受一张起始帧和一张可选的结束帧。
- `image_urls` 为必填。
- 按生成的视频时长和所选分辨率计费。
- 所有远程 URL 必须可公开访问且可直接下载。

Kling 4.0 文生视频根据单段提示词或多镜头脚本生成 3–30 秒、720p 或 1080p 的视频，输出带音轨。适合在没有素材图时制作一镜到底的广告、短剧场景和社交短视频。

Kling 4.0 是快手 Kling AI 的视频模型。Vidgo 提供四个 model ID：[文生视频](/zh/api-manual/video-series/kwaivgi-kling-v4-0-text-to-video)、[图生视频](/zh/api-manual/video-series/kwaivgi-kling-v4-0-image-to-video)、[参考生视频](/zh/api-manual/video-series/kwaivgi-kling-v4-0-reference-to-video)和[视频编辑](/zh/api-manual/video-series/kwaivgi-kling-v4-0-video-edit)。

## 模型

- **kwaivgi/kling-v4.0/text-to-video** — Kling 4.0 文生视频，3–30 秒，支持单段或多镜头提示词，720p 或 1080p。

## 功能

- 一次生成最长 30 秒的文生视频。
- 通过 `multi_prompt` 编写多镜头提示词，并为每个镜头设置时长。
- 输出 720p 或 1080p。
- 五种宽高比：`auto`、`16:9`、`9:16`、`1:1`、`21:9`。
- 输出带音轨，可在提示词中描述对白、音效或环境声。

## 输入模式

- **单段提示词**：传 `prompt`，可选传 `duration`。
- **多镜头**：传 `multi_prompt`，每个镜头一项。视频时长为各镜头时长之和；`duration` 可省略，或设为该总和。

## 必填参数

- `prompt`（string）**或** `multi_prompt`（object[]）：必须且只能传一个。
  - `prompt`：去除首尾空白后 1–26,000 个字符。
  - `multi_prompt`：非空的镜头列表 `{prompt, duration?}`。每个镜头的 `prompt` 为 1–512 个字符，`duration` 为 `1`–`30` 的整数（默认 `5`）。各镜头时长之和须为 3–30 秒。

## 可选参数

- `duration`（integer）：输出时长，`3`–`30` 秒。默认 `5`；使用 `multi_prompt` 时默认为各镜头时长之和，显式传入的值必须与之相等。
- `resolution`（string）：`720p` 或 `1080p`。默认 `720p`。
- `aspect_ratio`（string）：`auto`、`16:9`、`9:16`、`1:1` 或 `21:9`。默认 `auto`。

## 输出

任务完成后，[查询任务状态](/zh/api-manual/task-management/status)和回调内容的 `files` 数组中会返回一个带音轨的 MP4 视频。

## 示例

- **单段提示词，10 秒**：一段包含场景、镜头和声音描述的 `prompt`，`16:9`，720p。
- **三镜头 1080p 序列，带回调**：`multi_prompt` 中三个镜头分别为 4、6、5 秒（共 15 秒），`9:16`，并提供 `callback_url`。

## 注意事项

- 同时传 `prompt` 和 `multi_prompt`，或两者都不传，会返回 400。使用 `multi_prompt` 时，`duration` 与镜头总时长不一致会返回 400。
- 本 ID 只接受文本。要从图片开始，请用 [Kling 4.0 图生视频](/zh/api-manual/video-series/kwaivgi-kling-v4-0-image-to-video)；要用图片、视频或主体引导生成，请用 [Kling 4.0 参考生视频](/zh/api-manual/video-series/kwaivgi-kling-v4-0-reference-to-video)。
- 上文未列出的字段会返回 400。`model` 和 `callback_url` 放在请求根级，不要放进 `input`。
- 积分在提交时预扣，取决于 `resolution` 和输出 `duration`。任务失败会全额退还。当前费率见[定价页](https://vidgo.ai/apis/api-pricing)。
- 仅支持 720p 或 1080p 输出；本模型没有 4K 或 HDR 档位，没有音频开关，也不支持 `seed`。

使用 Google Veo 3.1 Quality 模型生成 8 秒视频。

## 模型

- **veo3.1/image-to-video** - Veo 3.1 Quality 图生视频

## 功能

- 在明确指定的起始帧和结束帧之间生成。
- 输出分辨率最高支持 `4k`。
- 生成的视频 URL 为临时链接，请及时下载。

## 时长选项

- **8 秒** - 该模型为固定时长。

## 高级参数

### 生成类型

- 该 model ID 将生成类型固定为 `image-to-video`。

### 图片 URL

- 按起始帧、结束帧的顺序提供恰好两张图片。
- 图片必须可公开访问且可直接下载。

### 分辨率

- `720p`（默认）、`1080p` 或 `4k`。

## 定价

价格因模型版本和分辨率而异。当前费率请查看 Vidgo 仪表盘。

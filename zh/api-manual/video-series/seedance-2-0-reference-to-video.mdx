## 模型

- **seedance-2.0/reference-to-video** - Seedance 2.0 参考生视频

## 功能

- **参考生视频**：使用参考图片、视频和可选音频引导生成。
- **可选音频**：可请求与视频一起生成音频。

## 版本说明

- 该公开 model ID 使用 `seedance-2` 服务商版本。
- 支持的分辨率为 `480p`、`720p`、`1080p` 和 `4k`。

## 积分参考

- 用量根据所选分辨率和计费时长计算。每个参考视频的时长分别向下取整后，计入输出时长。
- 提交生产流量前，请在 Vidgo 仪表盘查看该模型的当前费率。

## 注意事项

- `prompt` 为必填，最多 20,000 个字符。
- `duration` 支持 `4` 到 `15` 的整数。
- 参考输入最多支持 9 张图片、3 个视频和 3 个音频文件，合计最多 12 个文件。参考音频至少需要一张参考图或一个参考视频。
- `aspect_ratio` 接受 `auto`、`21:9`、`16:9`、`4:3`、`1:1`、`3:4` 或 `9:16`。
- 至少提供一张参考图或一个参考视频。参考音频不能单独使用。
- 所有远程 URL 必须可公开访问且可直接下载。

`kling-3.0-motion-control` 结合一张参考图和一段参考视频，将动作迁移到目标角色上。

## 模型

* **kling-3.0-motion-control** - 将参考视频中的动作迁移到参考图上

## 必填参数

* **image_urls**：恰好 `1` 张参考图
* **video_urls**：恰好 `1` 段参考视频
* **character_orientation**：`image` 或 `video`

## 可选参数

* **prompt**：可选的场景提示词
* **resolution**：`720p` 或 `1080p`。默认为 `720p`

## 注意事项

* 图片支持 `.jpg`、`.jpeg`、`.png`，最大 `10MB`
* 视频支持 `.mp4`、`.mov`，最大 `100MB`
* 参考视频至少 `3` 秒
* `character_orientation=image` 时，参考视频不得超过 `10` 秒
* `character_orientation=video` 时，参考视频不得超过 `30` 秒

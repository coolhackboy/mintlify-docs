使用 Kling 3.0 Pro 让参考图动起来，支持多镜头、分镜提示词和可选声音。

## 模型

- **kwaivgi/kling-v3.0-pro/image-to-video** - 根据图像输入生成视频。

## 功能

- 根据图像输入生成视频。
- 在 `image_urls` 中提供 1–2 张图片。
- 用 `multi_prompt` 描述各个镜头，并启用 `multi_shots`。
- 通过 `kling_elements` 提供额外的主体参考。

## 时长选项

- **3-15 秒** - `duration` 设为整数。必填。
- 使用 `multi_prompt` 时，各镜头时长之和必须等于请求的 `duration`。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流程参数（包括输出选项）都放在 `input` 中。

使用下面列出的 input 字段。时长以 JSON 整数发送，开关以 JSON 布尔值发送。媒体使用带主机名、可通过 URL 访问的公开 HTTP(S) URL。

- 每个 `multi_prompt` 镜头都需要非空的 `prompt` 和 **1 到 12 秒**的整数 `duration`。
- 各镜头时长之和必须等于请求的 `duration`。使用 `multi_prompt` 时设置 `multi_shots: true` 和 `sound: true`。
- 提供 `kling_elements` 时，需同时提供 `image_urls`，并在提示词中用 `@element_name` 引用元素。

### 图像 URL

- `image_urls`：必填。提供公开可访问的图像 URL，共 1–2 项：首帧在前，可选尾帧在后。多镜头时只提供一张首帧。每一项都必须是 HTTP(S) URL。

### 提示词

- `prompt`：`multi_shots` 为 `false` 时必填。描述场景和期望的动作。长度：**1-2,500 个字符**。
- 每个提示词都需使用非空文本。

### 多镜头提示词

- `multi_prompt`：`multi_shots` 为 `true` 时必填。提供非空数组，每一项都是对象。

- `multi_prompt[].prompt`：必填。最大长度：**2,500 个字符**。
- `multi_prompt[].duration`：必填。时长（秒），`1` 到 `12` 的整数。
- 每个镜头的时长以秒为单位。

### 多镜头生成

- `multi_shots`：可选。启用多镜头生成。使用 `true` 或 `false`。默认值：`false`。

### 声音

- `sound`：可选。设为 `true` 生成音频，设为 `false` 生成无声的单镜头。多镜头必须为 `true`。默认值：`true`。

### Kling 元素

- `kling_elements`：可选。提供元素引用对象数组，每一项都是对象。

- `kling_elements[].name`：必填。非空的元素名称，用于 `@element_name` 引用。
- `kling_elements[].description`：可选。字符串。
- `kling_elements[].element_input_urls`：用图像定义元素时，提供 2–4 个 JPG/PNG 图像 URL，每张最大 10 MB。
- `kling_elements[].element_input_video_urls`：用视频定义元素时，提供一个 MP4/MOV 视频 URL，最大 50 MB。每个元素只能选择一种媒体类型。

### 宽高比

- `aspect_ratio`：可选。可选值：`1:1`、`16:9`、`9:16`。输出宽高比由首帧决定。

使用 Kling 3.0 Standard 将参考视频中的动作迁移到图片主体上，支持朝向控制，输出 720p。

## 模型

- **kwaivgi/kling-v3.0-std/motion-control** - 将参考视频中的动作迁移到参考图中的角色上。

## 功能

- 将参考视频中的动作迁移到参考图中的角色上。
- 该 model ID 的输出分辨率固定为 `720p`。
- 使用 video 朝向时可添加一个面部元素。

## 时长选项

- **Image 朝向** - `character_orientation` 为 `image` 时，参考视频必须为 **3-10 秒**。
- **Video 朝向** - `character_orientation` 为 `video` 时，参考视频必须为 **3-30 秒**。
- 服务会检测参考视频的时长。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。下列参数放在 `input` 中。

只发送该工作流程支持的 input 字段。不支持的 `input` 字段会在扣除积分前被拒绝。输入 URL 必须使用 HTTP(S)、包含主机名，且不含内嵌凭据。

### 提示词

- `prompt` 可选。`null`、空字符串和仅含空白的值视为省略。
- 非空提示词会去除首尾空白，最多 **2,500 个字符**。

### 图像 URL

- `image_urls`：必填。恰好提供 1 个图像 URL。
- 该图片提供动作迁移的目标角色。
- 图片必须可公开访问且能直接下载。

### 源视频

- `video_urls`：必填。提供一个数组，其中恰好包含一个公开可访问的源视频 URL。
- 该视频提供要迁移的动作，时长必须符合上述朝向限制。
- 源视频必须可通过 HTTP(S) 直接下载，且不超过 **100 MiB**，以便检测时长。

### 角色朝向

- `character_orientation` 必填：选择 `image` 或 `video`。
- `image` 允许 **3 到 10 秒**的参考视频。
- `video` 允许 **3 到 30 秒**的参考视频。

### 面部元素

- `kling_elements` 可选，最多接受**一个面部元素**。
- 仅在 `character_orientation` 为 `video` 时使用。
- 该元素需要 `frontal_image_url` 和 **1-3** 个 `reference_image_urls`。

### 分辨率

- `resolution`：`720p`。默认值：`720p`。
- 该 model ID 固定了分辨率。省略该字段即使用默认值；传入另一档位的分辨率会被拒绝。

## 价格

积分按检测到的参考视频时长乘以该接口费率计算，然后向上取整为整数积分。

当前费率请查看 Vidgo 仪表盘。

提交时扣除积分，任务失败时退还。

## 模型

- **seedance-2.0-fast/text-to-video** - Seedance 2.0 Fast 文生视频

## 功能

- **文生视频**：直接根据提示词文本生成视频。
- **可选音频**：可请求与视频一起生成音频。

## 版本说明

- 该公开 model ID 使用 `seedance-2-fast` 服务商版本。
- 支持的分辨率为 `480p` 和 `720p`。

## 积分参考

- 用量根据输出时长和所选分辨率计算。
- 提交生产流量前，请在 Vidgo 仪表盘查看该模型的当前费率。

## 注意事项

- `prompt` 为必填，最多 20,000 个字符。
- `duration` 支持 `4` 到 `15` 的整数。
- `aspect_ratio` 接受 `auto`、`21:9`、`16:9`、`4:3`、`1:1`、`3:4` 或 `9:16`。
- 所有远程 URL 必须可公开访问且可直接下载。

使用 Wan 3.0 参考生视频，以图片、视频和音频参考引导视频场景，将多个素材组合成新的视觉序列。

## 模型

- **alibaba/wan-3.0/reference-to-video** - 在参考素材和提示词的引导下生成新视频。

## 功能

- 使用图片、视频、音频、文档或网页参考引导新场景。
- 输出分辨率可选 `480p`、`720p`、`1080p`。
- 通过 `audio` 控制音频生成，默认为 `true`。

## 时长选项

- **2-30 秒** - 以整数设置 `duration`。默认：**5 秒**。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级，下列参数放在 `input` 内。

只发送本工作流支持的 input 字段。不支持的 `input` 字段会在扣除积分前被拒绝。输入 URL 必须使用 HTTP(S)，带主机名，且不含内嵌凭证。

### 提示词

- `prompt`：必填。描述场景和期望的运动。
- 提供时提示词不能为空。最大长度：**20,000 个字符**。

### 参考输入

- 除 `prompt` 外，至少需要一种参考类型。音频可以是唯一的参考类型。
- 不要将 `reference_file_urls` 与 `reference_link_urls` 同时使用。
- `reference_image_urls`：可选；提供 1-10 张图片。
- `reference_video_urls`：可选；提供 1-5 个视频。
- `reference_audio_urls`：可选；提供 1-5 个音频文件。
- `reference_file_urls`：可选；只能提供 1 个文档。
- `reference_link_urls`：可选；只能提供 1 个网页。

### 分辨率

- `resolution`：`480p`、`720p`、`1080p`。默认：`720p`。

### 宽高比

- `aspect_ratio`：`adaptive`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`。默认：`adaptive`。

### 音频

- `audio`：设为 `true` 启用生成音频，设为 `false` 关闭。默认：`true`。

### 种子

- `seed` 可选。传入 `0` 到 `2147483647` 的整数。

### 安全检查

- `enable_safety_checker` 可选。设为 `true` 或 `false` 控制安全检查。默认：`true`。

## 定价

价格取决于所选模型和适用的输出设置。当前价格请在 Vidgo 仪表盘查看。

提交时扣除积分，任务失败后退还。

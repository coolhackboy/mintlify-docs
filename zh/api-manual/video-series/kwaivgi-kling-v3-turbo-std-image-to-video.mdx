使用 Kling 3.0 Turbo Standard 让参考图动起来，通过文本和分镜提示词引导视频序列。

## 模型

- **kwaivgi/kling-v3-turbo-std/image-to-video** - 根据图像输入生成视频。

## 功能

- 让单张参考图动起来。
- 用 `prompt` 编排单个场景，或用 `multi_prompt` 编排最多六个镜头。
- 输出宽高比由输入图像决定。

## 时长选项

- **3-15 秒** - 显式指定 `duration` 时的取值范围。不使用 `multi_prompt` 时，默认为 **5 秒**。
- **多镜头输出** - 每个镜头接受 `1`-`15` 秒，默认 `5` 秒。总时长不得超过 **15 秒**。
- 使用 `multi_prompt` 时，省略 `duration` 即使用镜头总时长，包括 **1 或 2 秒**的总时长。如果提供 `duration`，它必须等于镜头总时长，且在 `3`-`15` 秒之间。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。下列参数放在 `input` 中。

只发送该工作流程支持的 input 字段。不支持的 `input` 字段会在扣除积分前被拒绝。输入 URL 必须使用 HTTP(S)、包含主机名，且不含内嵌凭据。

### 提示词

- `prompt` 可选，最多 **2,500 个字符**。空白的可选提示词视为省略。
- `prompt` 和 `multi_prompt` 二选一，不要同时使用。

### 图像 URL

- `image_urls`：必填。恰好提供 1 个图像 URL。
- 图片必须可公开访问且能直接下载。

### 多镜头提示词

- `multi_prompt` 接受 **1-6 个镜头对象**，不能与 `prompt` 同时使用。
- 每个镜头都需要非空的 `prompt`，最多 **2,500 个字符**。
- 每个镜头可以包含 **1 到 15 秒**的整数 `duration`；默认为 **5 秒**。
- 各镜头的总时长不得超过 **15 秒**。顶层 `duration` 的规则见「时长选项」。

### 宽高比

- 输出宽高比跟随输入图像。
- 该接口会忽略 `aspect_ratio`，可以省略。

## 价格

使用 `multi_prompt` 时，按各镜头的总时长计费；否则按请求的 `duration` 或其默认值计费。

当前费率请查看 Vidgo 仪表盘。

提交时扣除积分，任务失败时退还。

1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询任务状态](/zh/api-manual/task-management/status)接口获取结果。
</Tip>

使用字节跳动的 Seedance 1.0 Pro 根据文本提示词或参考图生成高质量视频。时长和分辨率选项灵活，可生成流畅、专业的动画。

## 模型

- **seedance-1.0-pro** - 文生视频和图生视频，渲染速度快 3 倍

## 功能

- **灵活模式**：支持文生视频和图生视频
- **多种分辨率**：支持 720p 和 1080p
- **时长选项**：5 或 10 秒
- **快速渲染**：比标准 Pro 版本快 3 倍

使用 Wan 2.7 视频编辑，根据文本和可选的参考图片改造现有视频，引导场景变化。

## 模型

- **alibaba/wan-2.7/video-edit** - 根据文字指令编辑现有视频。

## 功能

- 根据文字指令编辑现有视频。
- 输出分辨率可选 `720p`、`1080p`。

## 时长选项

- **自动** - 默认 `duration: 0`。服务会检测源视频时长，检查其是否在 **2-10 秒**之间，然后向下取整到整秒。计费和输出生成使用相同的整秒时长。
- **指定输出时长** - 将 `duration` 设为 `2`、`3`、`4`、`5`、`6`、`7`、`8`、`9`、`10` 秒。
- 使用 `duration: 0` 时，源视频必须是可公开访问的 HTTP(S) 文件，且不超过 **100 MiB**。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流参数（包括输出选项）都放在 `input` 内。

只发送本工作流支持的 input 字段。不支持的 `input` 字段会在扣除积分前被拒绝。输入 URL 必须使用 HTTP(S)，带主机名，且不含内嵌凭证。图片输入也接受图片 Data URI 或原始 Base64。图片转换和媒体校验会在扣除积分前完成。

`duration` 和 `seed` 也接受整数字符串，如 `"5"`；小数（如 `5.0`）和小数字符串（如 `"5.0"`）会被拒绝。null 或空值会使用默认时长或省略种子。支持的布尔字段也接受 `0`/`1`，以及不区分大小写的字符串 `true`/`false`、`1`/`0`、`yes`/`no`、`y`/`n` 和 `on`/`off`；null 表示省略该字段。首尾空白会被去除，分辨率取值不区分大小写。

### 提示词

- `prompt`：必填。描述要做的修改。最多：**5,000 个 Unicode 字符**。
- 首尾空白会被去除。必须提供非空提示词。

### 参考图片 URL

- `reference_image_url`：可选。提供一张用于引导编辑的图片，可以是公开的 HTTP(S) URL、图片 Data URI 或原始 Base64。

### 源视频

- `video_url`：必填。提供源视频 URL，使用可公开访问的 HTTP(S) URL。

### 宽高比

- `aspect_ratio`：可选。可选值：`16:9`、`9:16`、`1:1`、`4:3`、`3:4`。默认：`16:9`。

### 分辨率

- `resolution`：可选。可选值：`720p`、`1080p`。默认：`720p`。

### 多镜头生成

- `multi_shots`：可选。启用多镜头生成。使用 `true` 或 `false`。

### 音频设置

- `audio_setting`：可选。以字符串形式提供音频设置。

### 种子

- `seed`：可选。设置生成种子。`0` 到 `2147483647` 的整数。

### 安全检查

- `enable_safety_checker`：可选。控制安全检查。使用 `true` 或 `false`。

## 定价

用量等于输出秒数乘以所选分辨率的费率。当前价格见[定价](https://vidgo.ai/apis/api-pricing)。

提交时扣除积分，任务失败后退还。

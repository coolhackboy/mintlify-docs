## 参数

使用模型 `kwaivgi/kling-video-o3-4k/image-to-video`。生成参数放在 `input` 中。

- **`image_urls`**：必填：包含 1–2 张图片的数组。第一张是首帧；可选的第二张是尾帧。接受公开 HTTP(S) URL、图片 Data URI 或原始 Base64 图像数据。
- **`prompt`**：multi_shots=false 时必填。描述场景、动作和运镜。使用非空文本，去除首尾空白后最多 2,500 个字符。multi_shots=true 时省略 prompt。
- **`multi_prompt`**：multi_shots=true 时必填；单镜头模式下省略。至少提供一个镜头，每个镜头包含不超过 2,500 个字符的非空 prompt 和 1–12 秒的整数 duration。各镜头时长之和必须等于顶层 duration（3–15 秒）。镜头对象中的多余字段会被忽略。
- **`duration`**：必填整数，3 到 15 秒。多镜头模式下必须等于所有镜头时长之和。积分按该值计算。
- **`multi_shots`**：必填：单镜头显式传 false，多镜头传 true。单镜头模式需要 prompt。多镜头模式需要 multi_prompt 和 sound=true，且顶层不能有非空 prompt。省略该字段会报错。
- **`sound`**：必填：显式传 true 生成音频，或传 false 生成无音频视频。单镜头模式两者均可；多镜头模式必须为 true。
- **`aspect_ratio`**：可省略。若提供，使用 16:9、9:16 或 1:1。图生视频会忽略该值；画面比例由输入图像决定。

请使用标准 JSON 数字和布尔值。为兼容起见，也接受 "5" 这样的整数字符串。布尔字符串 true/1/yes/y/on 表示 true；false/0/no/n/off 表示 false。这些字符串不区分大小写，并会去除首尾空白。布尔字段也接受数字 1 和 0。数字和布尔类型的提示词会转换为文本；0、false 和 null 视为空。提示词不接受对象和数组。不支持的 input 字段会被拒绝。HTTP(S) URL 必须包含主机名，且不含内嵌凭据。

## 计费因素

使用 4K 模型档位，按生成的秒数计费。用量由视频时长（`duration`）决定；开启或关闭音频（`sound`）不影响费率。

生成失败的任务会退款。

```json
{
  "model": "kwaivgi/kling-video-o3-4k/image-to-video",

Preserve its vein pattern, dew beads, surrounding leaves and blurred greenhouse glazing. Droplet highlights shift naturally. Fixed macro camera, realistic plant motion; no insect, animal features or new leaves. Audio: quiet greenhouse ambience and one distant drip; no music. No text, logos or watermarks.",

      "https://cdn.vidgo.ai/apis/models/kwaivgi/kling-video-o3-4k/image-to-video/v1/01/input-start.png"
    ]
  }
}
```

### 状态接口返回的完成结果

`GET /api/generate/status/{task_id}`

下面的响应记录的是这个已验证的示例。新的生成任务请查询你自己提交后返回的任务 ID。

```json
{
  "code": 200,
  "data": {
    "task_id": "MQX9Q1HSIUMLPP44",
    "status": "finished",
    "files": [
      {
        "file_type": "video",
        "file_url": "https://cdn.vidgo.ai/apis/models/kwaivgi/kling-video-o3-4k/image-to-video/v1/01/output.mp4"
      }
    ],
    "created_time": "2026-09-22T18:50:38",
    "error_message": null,
    "progress": 100
  }
}
```

<Note>
API 对提示词的校验上限为 2,500 个字符。部分多镜头生成请求在单个镜头提示词超过 512 个字符时失败。建议每个镜头提示词控制在 512 个字符以内；该建议不改变 API 的校验上限。
</Note>

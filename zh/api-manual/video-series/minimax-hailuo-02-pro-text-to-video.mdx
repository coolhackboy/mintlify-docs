使用 Hailuo 02 Pro 根据文本创建短场景，可选提示词优化来完善片段的视觉方向。

## 模型

- **minimax/hailuo-02/pro/text-to-video** - 根据文本提示词生成视频场景。

## 功能

- 根据文本提示词生成视频场景。

## 输出选项

- `resolution`：可选。可选值：`512P`、`768P`。默认值：`768P`。

## 高级参数

`model` 和可选的 `callback_url` 放在请求根级。所有工作流程参数（包括输出选项）都放在 `input` 中。

只发送该工作流程支持的 input 字段。不支持的 `input` 字段会在扣除积分前被拒绝。

### 提示词

- `prompt`：必填。描述场景和期望的动作。未规定提示词最大长度。
- 校验前会去除首尾空白；结果不能为空。

### 提示词优化

- `prompt_optimizer`：可选。控制自动提示词优化。使用 `true` 或 `false`。

## 计费因素

按次计费，使用 Pro 模型档位。两种支持的分辨率费率相同。

提交时扣除积分，任务失败时退还。

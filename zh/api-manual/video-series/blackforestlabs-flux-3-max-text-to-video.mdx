FLUX 3 Max 文生视频根据文字提示词生成 5–20 秒、720p 或 1080p 的视频，并在同一次生成中输出原生音频。适合没有素材图时制作社交短视频、产品预告、概念镜头和分镜草稿。

FLUX 3 Max 是 fal 与 Black Forest Labs 合作、在 FLUX 3 视频基座上后训练的视频模型。Vidgo 提供三个 model ID：[文生视频](/zh/api-manual/video-series/blackforestlabs-flux-3-max-text-to-video)、[图生视频](/zh/api-manual/video-series/blackforestlabs-flux-3-max-image-to-video)和[关键帧生视频](/zh/api-manual/video-series/blackforestlabs-flux-3-max-keyframes-to-video)。

## 模型

- **blackforestlabs/flux-3-max/text-to-video** — FLUX 3 Max 文生视频，5–20 秒，720p 或 1080p，可选音频。

## 功能

- 只需一段提示词即可文生视频，无需图片。
- 时长为 5 到 20 秒的整数。
- 输出 720p 或 1080p。
- 八种宽高比，包括电影感的 `21:9`、`2:1`，竖屏 `9:16` 和方形 `1:1`。
- 默认开启原生音频，可在提示词中描述环境声、音效或对白。

## 必填参数

- `prompt`（string）：场景、动作和镜头运动。开启 `sound` 时也可以描述想要的声音。不能为空白。

## 可选参数

- `duration`（integer）：输出时长，`5`–`20` 秒。默认 `5`。
- `resolution`（string）：`720p` 或 `1080p`。默认 `720p`。
- `aspect_ratio`（string）：`auto`、`21:9`、`2:1`、`16:9`、`4:3`、`1:1`、`3:4` 或 `9:16`。默认 `auto`。
- `sound`（boolean）：随视频生成原生音频。默认 `true`；设为 `false` 输出无声视频。

## 输出

任务完成后，[查询任务状态](/zh/api-manual/task-management/status)和回调内容的 `files` 数组中会返回一个 MP4 视频。

## 示例

- **5 秒 720p 带音频短片**：简短提示词中同时写明声音（雨声、车流声），`16:9`，`sound: true`。
- **15 秒竖屏 1080p 无声短片**：面向信息流的 `9:16`，`sound: false`，并提供 `callback_url` 接收完成通知。

## 注意事项

- 本 ID 只接受文本。要让起始图片动起来，请用 [FLUX 3 Max 图生视频](/zh/api-manual/video-series/blackforestlabs-flux-3-max-image-to-video)；要把图片固定在指定帧上，请用 [FLUX 3 Max 关键帧生视频](/zh/api-manual/video-series/blackforestlabs-flux-3-max-keyframes-to-video)。
- 上文未列出的字段（如 `image_urls`、`keyframes`）会返回 400。`model` 和 `callback_url` 放在请求根级，不要放进 `input`。
- 积分在提交时预扣，取决于 `resolution` 和 `duration`。文生视频、图生视频和关键帧生视频的费率相同，`sound` 不影响价格。任务失败会全额退还。当前费率见[定价页](https://vidgo.ai/apis/api-pricing)。
- 本模型没有 4K 档位、不支持 `seed`，输出最长 20 秒。

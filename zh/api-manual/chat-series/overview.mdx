所有 Chat 系列接口都使用 `https://api.vidgo.ai` 和 Vidgo API Key。以 `Authorization: Bearer VIDGO_API_KEY` 的形式发送 API Key。Claude 客户端也可以使用 `x-api-key`；Gemini 客户端也可以使用 `x-goog-api-key`。

| `gpt-5-6-terra` | 支持 | — | — | — |

上表中的旧版 ID 保留其现有的协议支持。Gemini 工作流见下文。

同时支持普通 JSON 响应和 SSE 流式响应。

使用支持 Responses 协议的模型。设置 `stream: true` 可获得 SSE 响应。

```bash
curl https://api.vidgo.ai/v1/responses \
  -H "Authorization: Bearer $VIDGO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5-6-luna","input":"Explain Decimal arithmetic briefly."}'
```

## 其他支持的模型

- `openai/gpt-6-astra`
- `xai/grok-4.6`
- `openai/gpt-5.5`
- `openai/gpt-5.4`
- `openai/gpt-5.2`
- `openai/gpt-6.1-sol`
- `openai/gpt-6.1-terra`
- `openai/gpt-6-sol`
- `openai/gpt-6-luna`
- `deepseek/deepseek-v4.1-flash`

在根级发送协议字段，不需要生成接口的 input 包装。input 不能为空。

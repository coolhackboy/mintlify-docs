Meshy 7.1 图生 3D 根据单张图片（如产品照片或角色概念图）重建 3D 模型。默认生成纹理，几何细节最高 `4k`，并可生成规整的低面数网格、PBR 贴图和带骨骼绑定的角色。

Meshy 7.1 是 Meshy 的 3D 生成模型，重点提升几何细节。Vidgo 提供三个 model ID：[文生 3D](/zh/api-manual/3d-series/meshy-v7-1-text-to-3d)、[图生 3D](/zh/api-manual/3d-series/meshy-v7-1-image-to-3d)和[多图生 3D](/zh/api-manual/3d-series/meshy-v7-1-multi-image-to-3d)。

## 模型

- **meshy/v7.1/image-to-3d** — Meshy 7.1 图生 3D，输入恰好一张图片。

## 功能

- 用一张照片或概念图图生 3D。
- 默认生成纹理；设 `should_texture: false` 只生成几何体。
- `model_type: standard` 时几何细节最高 `4k`，或用 `smart-topology` 生成低面数网格。
- 三角形或四边形拓扑，并可设置目标多边形数量。
- PBR 贴图，可用文字或图片引导纹理。
- 可选人形骨骼绑定和动画预设。

## 必填参数

- `image_urls`（string[]）：恰好一张图片，公开 HTTP(S) URL 或 `data:image/...` URI，必须是数组。清晰、光线充足、主体居中的 JPG 或 PNG 效果最好。

## 可选参数

- `should_texture`（boolean）：为模型生成纹理。默认 `true`；`false` 只返回几何体。
- `model_type`（string）：`standard` 或 `smart-topology`。默认 `standard`。
- `topology`（string）：`triangle` 或 `quad`。默认 `triangle`。
- `target_polycount`（integer）：`100`–`300000`，默认 `30000`。`model_type: smart-topology` 时范围为 `100`–`15000`，默认 `4000`。
- `should_remesh`（boolean）：对输出重新网格化。默认 `true`；`false` 保留原始三角网格。
- `symmetry_mode`（string）：`off`、`auto` 或 `on`。默认 `auto`。
- `pose_mode`（string）：`""`（不限定姿势）、`a-pose` 或 `t-pose`。默认 `""`。
- `geometry_resolution`（string）：`standard`、`2k` 或 `4k`。仅在 `model_type: standard` 时可用。
- `enable_pbr`（boolean）：在基础颜色纹理之外生成金属度、粗糙度和法线贴图。默认 `false`。
- `texture_prompt`（string）：纹理的文字引导，最多 600 个字符。
- `texture_image_url`（string）：引导纹理的图片（公开 HTTP(S) URL 或 `data:image/...` URI）。
- `enable_rigging`（boolean）：将模型自动绑定为人形角色骨骼。默认 `false`。
- `rigging_height_meters`（number）：骨骼绑定使用的角色身高（米），必须大于 0。默认 `1.7`。
- `enable_animation`（boolean）：应用动画预设。需要 `enable_rigging: true`。默认 `false`。
- `animation_action_id`（integer）：动画预设 ID，`0`–`696`。默认 `92`。
- `enable_safety_checker`（boolean）：上游安全检查。默认 `true`。

## 输出

请读取[查询任务状态](/zh/api-manual/task-management/status)或回调返回的 `files` 数组中的每一项。模型文件为 `file_type: "3d"`（通常是 GLB，可用时还有 FBX、OBJ、USDZ 或 STL），预览图和缩略图为 `file_type: "image"`，纹理、绑定或动画资源等辅助文件可能为 `file_type: "other"`。并非每个任务都会返回全部格式，不要假定文件列表固定。

## 示例

- **用产品照片生成带纹理模型**：一张图片，`geometry_resolution: 4k`，并生成 PBR 贴图。
- **低面数游戏资产**：`model_type: smart-topology`，四边形拓扑，目标 4,000 个多边形。
- **带骨骼绑定的角色**：`a-pose` 的角色概念图，开启 `enable_rigging`，并提供 `callback_url`。

## 注意事项

- `image_urls` 只能传一张图片。使用同一物体的 2–4 个视角请用 [Meshy 7.1 多图生 3D](/zh/api-manual/3d-series/meshy-v7-1-multi-image-to-3d)；从文本开始请用 [Meshy 7.1 文生 3D](/zh/api-manual/3d-series/meshy-v7-1-text-to-3d)。
- `model_type: smart-topology` 时传 `geometry_resolution` 会返回 400，`target_polycount` 超过 15,000 也会返回 400。`geometry_resolution` 控制网格细节，而非纹理图片尺寸。
- 只开 `enable_animation: true` 而不开 `enable_rigging: true` 会返回 400。骨骼绑定最适合四肢清晰、处于 `a-pose` 或 `t-pose` 的人形角色；用于生产前请检查骨骼和网格。
- 上文未列出的字段（如 `prompt`、`mode`、`seed`）会返回 400。文字引导请用 `texture_prompt`。
- 积分在提交时预扣：每个模型有基础费用，生成纹理（`should_texture: true`，即默认值）、`enable_rigging` 和 `enable_animation` 会分别增加费用。多边形数量、拓扑、`geometry_resolution` 和图片数量不影响价格。任务失败会全额退还。当前费率见[定价页](https://vidgo.ai/apis/api-pricing)。

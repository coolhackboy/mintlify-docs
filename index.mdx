## 2. Authentication

Create your API key on the [API key page](https://vidgo.ai/apis/dashboard/api-key). Every request must include:

```http
Authorization: Bearer VIDGO_API_KEY
Content-Type: application/json
```

[Claude Messages](/api-manual/chat-series/claude-messages) also accepts `x-api-key`, and [Gemini Native Format](/api-manual/chat-series/gemini-native-format) also accepts `x-goog-api-key`.

<Warning>
  **Never expose your API key** in frontend code (browser, mobile apps, public repositories). Keep it on your server.
</Warning>

## 3. Submit a generation task

Generation is asynchronous. Submit a task to `POST /api/generate/submit` and save the returned `task_id`.

```bash
curl https://api.vidgo.ai/api/generate/submit \
  -H "Authorization: Bearer $VIDGO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-image",
    "input": {
      "prompt": "A paper-cut illustration of a city at sunrise",
      "size": "1:1"
    }
  }'
```

<Info>
  A successful submit response means the task was accepted, not that generation has finished.
</Info>

## 4. Retrieve the result

```bash
curl "https://api.vidgo.ai/api/generate/status/TASK_ID" \
  -H "Authorization: Bearer $VIDGO_API_KEY"
```

<Steps>
  <Step title="Submit">
    Send the generation request and save the returned `task_id`.
  </Step>
  <Step title="Wait for the result">
    Poll [Get Task Status](/api-manual/task-management/status), or pass a `callback_url` and receive a [webhook](/api-manual/task-management/webhooks) when the task reaches `finished` or `failed`.
  </Step>
  <Step title="Store the output">
    Download the files in `files` and store them on your side.
  </Step>
</Steps>

Suno music actions use [Query Music Detail](/api-manual/music-series/query-music-detail) and the [Music Webhook](/api-manual/music-series/music-webhook) instead of the unified task status endpoint.

## 5. Data retention

<Warning>
  Generated files are valid for **24 hours**. Download and store results promptly.
</Warning>

Generate images from a text prompt with preset or custom dimensions and PNG or JPEG output.

## Models

- **blackforestlabs/flux/dev** — Generate images from a text prompt with preset or custom dimensions and PNG or JPEG output.

## Required parameters

- `prompt` (string): Required string. Describe the image or editing instructions using at least one character after trimming.

## Optional parameters

- `size` (string): Output canvas, default `1:1`. Choose `1:1`, `1:1 HD`, `4:3`, `3:4`, `16:9`, `9:16`, or a custom `WIDTHxHEIGHT` such as `1024x1536`. Custom width and height are positive integers.

- `n` (integer): Positive integer specifying the output image count, default `1`.

- `output_format` (string): `png` or `jpeg`, default `png`.

## Examples

The API playground examples demonstrate different `size` values and PNG or JPEG output through `output_format`.

## Notes

Send `model: "blackforestlabs/flux/dev"` and an `input` object to `POST /api/generate/submit`. Authenticate with `Authorization: Bearer VIDGO_API_KEY`.

The submission response returns `data.task_id`. Use [Query Task Status](/api-manual/task-management/status) to follow the task through `not_started`, `running`, `finished`, or `failed`.

Read image URLs from `data.files[].file_url` when the status is `finished`. For `failed`, read `data.error_message`.

You can provide a top-level `callback_url` to receive the terminal result through a [webhook](/api-manual/task-management/webhooks).

Next-generation AI image generation powered by Google's Gemini 3.1 Flash Image Preview. Delivers native 2K / 4K resolution images with precise multilingual text rendering, chain-of-thought understanding of physical relationships, and support for up to 14 reference images.

## Models

- **nano-banana-2-new** - Text-to-image and image-to-image generation
- **nano-banana-2-new-edit** - Advanced image editing capabilities

## Input modes

- **Generation:** select `nano-banana-2-new`. Use the input options supported by the selected model.
- **Image editing:** select `nano-banana-2-new-edit`. Supply reference images as required by the selected editing workflow.

## Required parameters

- `prompt` (string): Generation prompt describing the desired output Length: 0–20000 characters.

## Optional parameters

- `image_urls` (array): Reference image URLs (for image editing, supports up to 14 images)

- `size` (string): Image size ratio Accepted values: `1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`, `21:9`.

- `resolution` (string): Output image resolution Accepted values: `1K`, `2K`, `4K`. Default: `1K`.

- `google_search` (boolean): Use Google Web Search grounding to generate images based on real-time information

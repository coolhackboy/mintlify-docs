Generate high-quality images using GPT Image 1.5 models. Supports text-to-image, image-to-image, and advanced image editing capabilities.

## Models

- **gpt-image-1.5** - Text-to-image and image-to-image generation
- **gpt-image-1.5-edit** - Advanced image editing with mask support

### Dedicated workflows

Existing IDs remain available. New integrations can select a dedicated workflow:

- **openai/gpt-image-1.5/text-to-image** — [Workflow page](/api-manual/image-series/openai-gpt-image-1-5-text-to-image)
- **openai/gpt-image-1.5/edit** — [Workflow page](/api-manual/image-series/openai-gpt-image-1-5-edit)

## Input modes

- **Generation:** select `gpt-image-1.5`. Use the input options supported by the selected model.
- **Image editing:** select `gpt-image-1.5-edit`. Supply reference images as required by the selected editing workflow.

## Required parameters

- `prompt` (string): Generation prompt describing the desired output Length: 0–1000 characters.

## Optional parameters

- `image_urls` (array): Reference image URLs (for image editing)

- `size` (string): Image size ratio Accepted values: `1:1`, `2:3`, `3:2`.

- `n` (integer): Number of images to generate. With gpt-image-1.5-edit, each request produces one image and is billed for one image; n does not increase editing outputs. Accepted values: `1`, `2`, `3`, `4`.

- `mask_url` (string): Mask image URL for editing

## Output

With `gpt-image-1.5`, `n` selects the requested output image count. Editing with `gpt-image-1.5-edit` produces one image per request; `n` does not increase editing outputs.

Seedream 5.0 Pro Edit applies controlled changes using up to ten reference images while preserving requested visual details.

## Models

- **seedream-v5.0-pro/edit** - Image editing with multi-image reference support

## Required parameters

- `prompt` (string): Text instruction describing the image to generate or edit. Length: 0–10000 characters.

- `image_urls` (array): Reference images required by this image-edit model. Items: 1–10.

## Optional parameters

- `size` (string): See [Size](#size) for supported values and constraints.

- `resolution` (string): See [Resolution](#resolution) for supported values and constraints.

- `output_format` (string): Output image format. Accepted values: `png`, `jpeg`.

- `enable_safety_checker` (boolean): Whether to enable content safety checking.

## Size

`input.size` controls the output aspect ratio and defaults to `1:1`:

- Ratio presets: `1:1`, `4:3`, `3:4`, `16:9`, `9:16`, `2:3`, `3:2`, `21:9`

## Resolution

`input.resolution` controls output resolution and defaults to `1K`:

- Resolution presets: `1K`, `2K`

## Output

Each request generates one image.

## Examples

### How to Call

Use the unified submit endpoint: `POST /api/generate/submit`

```json
{
  "model": "seedream-v5.0-pro/edit",
  "callback_url": "https://your-domain.com/callback",
  "input": {
    "prompt": "A cinematic scene with natural lighting and coherent motion",
    "resolution": "1K",
    "size": "1:1",
    "image_urls": [
      "https://cdn.vidgo.ai/temp/reference-1.jpg"
    ]
  }
}
```

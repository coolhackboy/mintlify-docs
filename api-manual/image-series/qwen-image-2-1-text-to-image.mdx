Generate one image with Qwen Image 2.1 using a text prompt.

## Models

- **alibaba/qwen-image-2.1/text-to-image** — Generate one image with Qwen Image 2.1 using a text prompt.

## Required parameters

- `prompt` (string): Supply non-blank text of up to 5,000 characters.

## Optional parameters

- `size` (string): Output aspect ratio. Accepted values: `1:1`, `4:3`, `3:4`, `3:2`, `2:3`, `16:9`, `9:16`, `21:9`, `9:21`. Default: `1:1`.

- `resolution` (string): Output resolution tier. Accepted values: `1K`, `2K`. Default: `1K`.

- `output_format` (string): Output image format. Transparent output requires PNG or WebP. Accepted values: `png`, `jpeg`, `webp`. Default: `png`.

- `enable_safety_checker` (boolean): Enable content safety checking. Default: `true`.

- `background` (string): Background mode. Transparent output requires PNG or WebP. Accepted values: `opaque`, `transparent`. Default: `opaque`.

- `prompt_extend` (boolean): Enhance the prompt before generation. Default: `true`.

- `seed` (integer): Random seed. Omit to use a random seed.

## Notes

- Set `model` to `alibaba/qwen-image-2.1/text-to-image`.
- Place `model` and optional `callback_url` at the request root; place workflow parameters inside `input`.
- Each request produces one image.
- For reference-image editing, use [Image Edit](/api-manual/image-series/qwen-image-2-1-edit) with `model=alibaba/qwen-image-2.1/edit`.

- A transparent background requires `output_format=png` or `webp`.

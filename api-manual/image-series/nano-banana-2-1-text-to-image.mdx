Generate one image with Nano Banana 2.1 using a text prompt.

## Models

- **google/nano-banana-2.1/text-to-image** — Generate one image with Nano Banana 2.1 using a text prompt.

## Required parameters

- `prompt` (string): Supply non-blank text of up to 20,000 characters.

## Optional parameters

- `size` (string): Output aspect ratio. Accepted values: `1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`, `21:9`. Default: `1:1`.

- `resolution` (string): Output resolution tier. Accepted values: `1K`, `2K`, `4K`. Default: `1K`.

## Notes

- Set `model` to `google/nano-banana-2.1/text-to-image`.
- Place `model` and optional `callback_url` at the request root; place workflow parameters inside `input`.
- Each request produces one image.
- For reference-image editing, use [Image Edit](/api-manual/image-series/nano-banana-2-1-edit) with `model=google/nano-banana-2.1/edit`.

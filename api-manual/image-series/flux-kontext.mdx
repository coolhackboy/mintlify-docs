Flux Kontext is powered by Black Forest Labs. It supports both text-to-image generation and image editing through the same unified submit endpoint.

## Models

- **flux-kontext-pro** - Flux Kontext Pro text-to-image generation
- **flux-kontext-pro-edit** - Flux Kontext Pro image editing, `image_urls` is required
- **flux-kontext-max** - Flux Kontext Max text-to-image generation
- **flux-kontext-max-edit** - Flux Kontext Max image editing, `image_urls` is required

## Input modes

- **Generation:** select `flux-kontext-pro`, `flux-kontext-max`. Use the input options supported by the selected model.
- **Image editing:** select `flux-kontext-pro-edit`, `flux-kontext-max-edit`. Supply reference images as required by the selected editing workflow.

## Required parameters

- `prompt` (string): Generation or editing prompt describing the desired output Length: 0–2000 characters.

- `image_urls` (array): Input image URLs. Required for edit models (flux-kontext-pro-edit, flux-kontext-max-edit). Only the first image is used. Items: 1–1.

## Optional parameters

- `size` (string): Output aspect ratio. Defaults to 1:1 when omitted. Accepted values: `1:1`, `4:3`, `3:4`, `16:9`, `9:16`, `21:9`, `9:21`.

- `output_format` (string): Output image format. Accepted values: `png`, `jpg`.

## Notes

- `size` supports `1:1`, `4:3`, `3:4`, `16:9`, `9:16`, `21:9`, `9:21`
- `output_format` supports `png`, `jpg`
- `image_urls` is required for edit models
- Only `image_urls[0]` is used as the input image
- Other downstream fields are not exposed in the current API and use system defaults

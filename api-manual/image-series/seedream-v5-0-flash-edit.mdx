Edit one image with Seedream 5.0 Flash using text instructions and reference images.

## Models

- **bytedance/seedream-v5.0-flash/edit** — Edit one image with Seedream 5.0 Flash using text instructions and reference images.

## Required parameters

- `prompt` (string): Supply non-blank text of up to 5,000 characters.

- `image_urls` (array): Accepts 1 to 10 reference image URLs. Use publicly accessible HTTP(S) URLs in the same order as the references in your prompt.

## Optional parameters

- `size` (string): Output aspect ratio. Accepted values: `1:1`, `4:3`, `3:4`, `16:9`, `9:16`, `2:3`, `3:2`, `21:9`. Default: `1:1`.

- `resolution` (string): Output resolution tier. Accepted values: `1K`, `1.5K`, `2K`. Default: `1K`.

- `output_format` (string): Output image format. Accepted values: `jpeg`, `png`. If omitted, the model selects the format.

- `enable_safety_checker` (boolean): Enable content safety checking. Default: `true`.

## Notes

- Set `model` to `bytedance/seedream-v5.0-flash/edit`.
- Place `model` and optional `callback_url` at the request root; place workflow parameters inside `input`.
- Each request produces one image.
- For prompt-only generation, use [Text to Image](/api-manual/image-series/seedream-v5-0-flash) with `model=bytedance/seedream-v5.0-flash/text-to-image`.

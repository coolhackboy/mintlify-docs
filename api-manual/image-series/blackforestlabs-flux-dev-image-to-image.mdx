Edit one source image using a text prompt with PNG or JPEG output.

## Models

- **blackforestlabs/flux/dev/image-to-image** — Edit one source image using a text prompt with PNG or JPEG output.

## Required parameters

- `prompt` (string): Required string. Describe the image or editing instructions using at least one character after trimming.

- `image_urls` (array): Required array containing one public HTTP(S) source-image URL. The source image guides the edited output.

## Optional parameters

- `n` (integer): Positive integer specifying the output image count, default `1`.

- `output_format` (string): `png` or `jpeg`, default `png`.

- `size` (string): Text-to-image output canvas. Presets: 1:1 (512×512), 1:1 HD (1024×1024), 4:3 (1024×768), 3:4 (768×1024), 16:9 (1024×576), 9:16 (576×1024). Custom WIDTHxHEIGHT dimensions are positive integers. Image-to-image output is guided by the source image. Use a preset (`1:1`, `1:1 HD`, `4:3`, `3:4`, `16:9`, `9:16`) or custom `WIDTHxHEIGHT` dimensions. Default: `1:1`.

## Examples

The default API playground example edits one reference image in `image_urls` and requests PNG output. The other examples also demonstrate `output_format: "jpeg"`.

## Notes

Send `model: "blackforestlabs/flux/dev/image-to-image"` and an `input` object to `POST /api/generate/submit`. Authenticate with `Authorization: Bearer VIDGO_API_KEY`.

`size` defines the text-to-image canvas and defaults to `1:1`. Image-to-image generation uses the source image to guide the output. The request example supplies the source image, prompt, image count, and output format.

The submission response returns `data.task_id`. Use [Query Task Status](/api-manual/task-management/status) to follow the task through `not_started`, `running`, `finished`, or `failed`.

Read image URLs from `data.files[].file_url` when the status is `finished`. For `failed`, read `data.error_message`.

You can provide a top-level `callback_url` to receive the terminal result through a [webhook](/api-manual/task-management/webhooks).

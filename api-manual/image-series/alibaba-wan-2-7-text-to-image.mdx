Turn scene and design ideas into images with Wan 2.7, with custom canvas sizes and up to four variations per prompt.

## Models

- **alibaba/wan-2.7/text-to-image** - Generate images from text prompts.

## Features

- Generate images from text prompts.
- Control the number of output images with `n`.

Use the corresponding image-edit endpoint for reference images.

## Required parameters

- `prompt` (string): Describe the desired image. Length: **1-5,000 characters**.
- The value must not be blank when supplied.

## Optional parameters

- `n` (integer): Number of images to generate. Integer from `1` to `4`. Default: `1`.

- `seed` (integer): Set the generation seed. Integer.

- `size` (string | object): See [Size](#size) for supported values and constraints.

## Size

- `size`: Optional. Default: `1024x1024`.
- Presets: `512x512`, `1024x1024`, `768x1024`, `1024x768`, `576x1024`, `1024x576`.
- For custom dimensions, supply an object with integer `width` and `height`; both must be positive.

## Notes

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before credits are deducted.

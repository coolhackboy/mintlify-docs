Generate image sets with Seedream 4, with output up to 4K for illustrations, design concepts, and visual variations.

## Models

- **bytedance/seedream/v4/text-to-image** - Generate images from text prompts.

## Features

- Generate images from text prompts.
- Choose from `1K`, `2K`, `4K` output resolutions.
- Control the number of output images with `n`.

## Required parameters

- `prompt` (string): Describe the desired image. Length: **1-5,000 characters**.
- Include at least one non-whitespace character.

## Optional parameters

- `n` (integer): Number of images to generate. Integer from `1` to `15`. Default: `1`.

- `size` (string): See [Size](#size) for supported values and constraints.

- `resolution` (string): See [Resolution](#resolution) for supported values and constraints.

## Size

- `size`: Optional. Accepted values: `1:1`, `3:4`, `4:3`, `16:9`, `9:16`, `3:2`, `2:3`, `21:9`. Default: `1:1`.

## Resolution

- `resolution`: Optional. Accepted values: `1K`, `2K`, `4K`. Default: `2K`.

## Notes

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Refine images with Grok Imagine Image 2.0, combining reference images and precise instructions to preserve subjects while changing visual details.

## Models

- **xai/grok-imagine-image-v2.0/edit** - Edit images using a prompt and image references.

## Features

- Edit images using a prompt and image references.
- Accepts 1-3 images in `image_urls`.
- Choose from `1K`, `2K` output resolutions.
- Control the number of output images with `n`.

## Required parameters

- `prompt` (string): Describe the requested changes. Length: **1-8,000 characters**.
- The value must not be blank when supplied.

- `image_urls` (array): Provide publicly accessible image URLs. Supply 1-3 items. Each item must be an HTTP(S) URL.

## Optional parameters

- `n` (integer): Number of images to generate. Integer from `1` to `4`. Default: `1`.

- `aspect_ratio` (string): Output aspect ratio. Defaults to 1:1. Accepted values: `1:1`, `2:3`, `3:2`, `9:16`, `16:9`.

- `resolution` (string): See [Resolution](#resolution) for supported values and constraints.

- `quality` (string): Output quality: low or medium. Defaults to medium. Accepted values: `low`, `medium`.

## Size

- `aspect_ratio`: Optional. Accepted values: `1:1`, `2:3`, `3:2`, `9:16`, `16:9`. Default: `1:1`.

## Resolution

- `resolution`: Optional. Accepted values: `1K`, `2K`. Default: `1K`.

## Output

### Quality

- `quality`: Optional. Accepted values: `low`, `medium`. Default: `medium`.

## Notes

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before credits are deducted. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

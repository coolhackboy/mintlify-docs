# Qwen Image 2.1 Image Edit

## Usage Guide

Edit one image with Qwen Image 2.1 using text instructions and reference images.

- Set `model` to `alibaba/qwen-image-2.1/edit`.
- Place `model` and optional `callback_url` at the request root; place workflow parameters inside `input`.
- Each request produces one image.
- For prompt-only generation, use [Text to Image](/api-manual/image-series/qwen-image-2-1-text-to-image) with `model=alibaba/qwen-image-2.1/text-to-image`.

## Parameter Details

- `prompt` is required. Supply non-blank text of up to 5,000 characters.
- `image_urls` is required and accepts 1 to 10 reference image URLs. Use publicly accessible HTTP(S) URLs in the same order as the references in your prompt.
- `size` defaults to `auto`. `auto` follows the reference image aspect ratio.
- A transparent background requires `output_format=png` or `webp`.
- `mask_url` requires exactly one reference image and `background=opaque`. White areas change; black areas stay unchanged. Match the reference aspect ratio; the mask is scaled to the reference dimensions.
- With a mask, output follows the reference aspect ratio; `size` and `prompt_extend` are ignored.
- Reference images support JPEG, PNG, and WebP, up to 30 MB and 25 megapixels per image. Media limits are checked during generation.

## Developer Notes

- Submission is asynchronous. Use the task status endpoint or a completion webhook to retrieve the final image.
- Billing is per output image and depends on `resolution`. Text-to-image and editing use the same rate at each tier.
- Credits are deducted on submission and refunded if the task fails.

## Optional parameters

- `size` (string): Output aspect ratio. auto follows the reference image. Ignored when mask_url is supplied. Accepted values: `1:1`, `4:3`, `3:4`, `3:2`, `2:3`, `16:9`, `9:16`, `21:9`, `9:21`, `auto`. Default: `auto`.
- `resolution` (string): Output resolution tier. Accepted values: `1K`, `2K`. Default: `1K`.
- `output_format` (string): Output image format. Transparent output requires PNG or WebP. Accepted values: `png`, `jpeg`, `webp`. Default: `png`.
- `enable_safety_checker` (boolean): Enable content safety checking. Default: `true`.
- `background` (string): Background mode. Transparent output requires PNG or WebP. Accepted values: `opaque`, `transparent`. Default: `opaque`.
- `mask_url` (string): Optional local-edit mask. Requires exactly one reference image and an opaque background. White areas change and black areas stay unchanged. Match the reference aspect ratio; the mask is scaled to the reference. size and prompt_extend are ignored.
- `prompt_extend` (boolean): Enhance the prompt before generation. Ignored when mask_url is supplied. Default: `true`.
- `seed` (integer): Optional random seed. Omit to use a random seed.

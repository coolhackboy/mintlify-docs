Edit one image with GPT Image 2.5 Flare using text instructions and reference images.

## Models

- **openai/gpt-image-2.5-flare/edit** — Edit one image with GPT Image 2.5 Flare using text instructions and reference images.

## Required parameters

- `prompt` (string): Supply non-blank text of up to 32,000 characters.

- `image_urls` (array): Accepts 1 to 16 reference image URLs. Use publicly accessible HTTP(S) URLs in the same order as the references in your prompt.

## Optional parameters

- `quality` (string): Image quality tier. Accepted values: `low`, `medium`, `high`, `xhigh`, `max`. Default: `high`.

- `size` (string): Use `auto`, `1:1`, `2:3`, `3:2`, `4:3`, `3:4`, `4:5`, `5:4`, `16:9`, `9:16`, `21:9`, or custom `WIDTHxHEIGHT` dimensions. Default: `1:1`. `auto` is available only with `resolution=1K`.

- `mask_url` (string): Mask selecting the area to edit. Requires at least one reference image.

- `resolution` (string): Output resolution tier. Accepted values: `1K`, `2K`, `4K`. Default: `1K`.

- `output_format` (string): Output image format. Transparent output requires PNG or WebP. Accepted values: `png`, `jpeg`, `webp`. Default: `png`.

- `background` (string): Background mode. Transparent output requires PNG or WebP. Accepted values: `auto`, `transparent`, `opaque`. Default: `auto`.

## Resolution

Aspect-ratio requests keep the selected tier; actual image dimensions may vary.

## Notes

- Set `model` to `openai/gpt-image-2.5-flare/edit`.
- Place `model` and optional `callback_url` at the request root; place workflow parameters inside `input`.
- Each request produces one image.
- For prompt-only generation, use [Text to Image](/api-manual/image-series/gpt-image-2-5-flare-text-to-image) with `model=openai/gpt-image-2.5-flare/text-to-image`.

- Custom `WIDTHxHEIGHT` dimensions require `2K` or `4K`. Both edges must be positive multiples of 16, the longest edge must not exceed 3,840 pixels, the aspect ratio must not exceed 3:1, and total pixels must be between 655,360 and 8,294,400. A 3,840-pixel edge requires `4K`.

- A transparent background requires `output_format=png` or `webp`.

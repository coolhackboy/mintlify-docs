Turn written image concepts into square, portrait, or landscape visuals with GPT Image 1.5, with up to four variations per request.

## Models

- **openai/gpt-image-1.5/text-to-image** - Generate images from text prompts.

## Features

- Generate images from text prompts.
- Control the number of output images with `n`.

## Required parameters

- `prompt` (string): Describe the desired image. Length: **1-1,000 characters**.
- Include at least one non-whitespace character.

## Optional parameters

- `n` (integer): Number of images to generate. Accepted values: `1`, `2`, `3`, `4`. Default: `1`.

- `size` (string): See [Size](#size) for supported values and constraints.

## Size

- `size`: Optional. Accepted values: `1024x1024`, `1024x1536`, `1536x1024`. Default: `1024x1024`.

## Notes

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

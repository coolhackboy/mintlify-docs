Apply contextual image edits with FLUX Kontext Max, refining subjects and scenes while maintaining visual continuity.

## Models

- **blackforestlabs/flux-kontext-max** - Edit one source image with a text prompt.

## Features

- Edit one source image with a text prompt.
- Provide the source image as a single item in `image_urls`.

## Required parameters

- `prompt` (string): Describe the requested changes. Length: **1-2,000 characters**.
- Include at least one non-whitespace character.

- `image_urls` (array): Provide exactly 1 publicly accessible HTTP(S) image URL as the source image.

## Optional parameters

- `size` (string): See [Size](#size) for supported values and constraints.

- `output_format` (string): See [Output Formats](#output-formats) for supported values and constraints.

## Size

- `size`: Optional. Output aspect ratio. Accepted values: `1:1`, `4:3`, `3:4`, `16:9`, `9:16`, `21:9`, `9:21`. Default: `1:1`.

## Output Formats

- `output_format`: Optional. Output image file format. Accepted values: `png`, `jpg`.

## Examples

The API playground examples edit one reference image in `image_urls` using a text prompt. They demonstrate different `size` values and PNG or JPG output. The `callback` example adds a top-level `callback_url`.

## Notes

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Input image URLs use HTTP(S) and point to publicly accessible image files.

Reimagine an existing image with Grok Imagine, using text to guide changes to the subject, setting, or visual style.

## Models

- **xai/grok-imagine-image/edit** - Edit images using a prompt and image references.

## Features

- Edit images using a prompt and image references.
- Accepts exactly 1 image in `image_urls`.

## Required parameters

- `prompt` (string): Describe the requested changes. Length: **1-5,000 characters**.

- `image_urls` (array): Provide publicly accessible image URLs. Supply exactly 1 item. Use JPEG, PNG, or WebP, up to 10 MB.

## Optional parameters

- `size` (string): See [Size](#size) for supported values and constraints.

## Size

- `size`: Optional. Accepted values: `1:1`, `2:3`, `3:2`, `9:16`, `16:9`.

## Notes

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Use the input fields listed below. Supply publicly accessible HTTP(S) URLs for reference images.

Edit one image with Nano Banana 2.1 using text instructions and reference images.

## Models

- **google/nano-banana-2.1/edit** — Edit one image with Nano Banana 2.1 using text instructions and reference images.

## Required parameters

- `prompt` (string): Supply non-blank text of up to 20,000 characters.

- `image_urls` (array): Accepts 1 to 10 reference image URLs. Use publicly accessible HTTP(S) URLs in the same order as the references in your prompt.

## Optional parameters

- `size` (string): Output aspect ratio. auto follows the reference image. Accepted values: `auto`, `1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`, `21:9`. Default: `auto`.

- `resolution` (string): Output resolution tier. Accepted values: `1K`, `2K`, `4K`. Default: `1K`.

## Notes

- Set `model` to `google/nano-banana-2.1/edit`.
- Place `model` and optional `callback_url` at the request root; place workflow parameters inside `input`.
- Each request produces one image.
- For prompt-only generation, use [Text to Image](/api-manual/image-series/nano-banana-2-1-text-to-image) with `model=google/nano-banana-2.1/text-to-image`.

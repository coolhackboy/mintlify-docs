Explore image ideas with Seedream 5.0 Lite, generating batches of visual variations from a written description.

## Models

- **bytedance/seedream/v5/lite/text-to-image** - Generate images from text prompts.

## Features

- Generate images from text prompts.
- Control the number of output images with `n`.

## Required parameters

- `prompt` (string): Describe the desired image. Length: **3-3,000 characters**.

## Optional parameters

- `n` (integer): Number of images to generate. Integer from `1` to `15`. Default: `1`.

- `enable_safety_checker` (boolean): Set `true` to enable the content safety check or `false` to disable it. Default: `true`.

- `size` (string | object): See [Size](#size) for supported values and constraints.

## Size

- `size`: Optional. Default: `1:1`.
- Presets: `2K`, `3K`, `1:1`, `4:3`, `3:4`, `16:9`, `9:16`, `3:2`, `2:3`, `21:9`.
- For custom dimensions, supply an object with integer `width` and `height`; both must be positive.
- Custom dimensions also accept a `WIDTHxHEIGHT` string, using `x` or `X` between the positive dimensions.

## Notes

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

- Length is counted after leading and trailing whitespace is trimmed.

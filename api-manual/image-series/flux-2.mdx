FLUX.2 is a 32 billion parameter image generation and editing model from Black Forest Labs. It combines text-to-image and multi-image editing in a single architecture, delivering photoreal images with clean typography at resolutions up to 2K. Supports referencing up to 8 images simultaneously with excellent character, product, and style consistency.

## Models

- **flux-2-pro** - High-fidelity text-to-image generation for production deployments
- **flux-2-pro-edit** - Advanced multi-reference image editing with up to 8 input images
- **flux-2-flex** - Adjustable speed vs. quality balance for flexible workflows
- **flux-2-flex-edit** - Flexible image editing with multi-reference support

## Input modes

- **Generation:** select `flux-2-pro`, `flux-2-flex`. Use the input options supported by the selected model.
- **Image editing:** select `flux-2-pro-edit`, `flux-2-flex-edit`. Supply reference images as required by the selected editing workflow.

## Required parameters

- `prompt` (string): Generation prompt describing the desired output Length: 0–1000 characters.

- `size` (string): Image size ratio. Use 'auto' to automatically detect based on first input image Accepted values: `1:1`, `4:3`, `3:4`, `16:9`, `9:16`, `3:2`, `2:3`, `auto`.

- `resolution` (string): Output image resolution Accepted values: `1K`, `2K`.

- `image_urls` (array): Input reference images (1-8 images). Required for edit models (flux-2-pro-edit, flux-2-flex-edit) Items: 1–8.

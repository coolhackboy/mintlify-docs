Develop new image variations with Grok Imagine Image Quality, combining text instructions and visual references in output up to 2K.

## Models

- **xai/grok-imagine-image-quality/edit** - Edit images using a prompt and image references.

## Features

- Edit images using a prompt and image references.
- Accepts 1-3 images in `image_urls`.
- Choose from `1K`, `2K` output resolutions.
- Control the number of output images with `n`.

## Output Options

### Aspect Ratio

- `aspect_ratio`: Optional. Accepted values: `1:1`, `2:3`, `3:2`, `9:16`, `16:9`. Default: `1:1`.

### Resolution

- `resolution`: Optional. Accepted values: `1K`, `2K`. Default: `1K`.

### Image Count

- `n`: Optional. Number of images to generate. Integer, at least `1`. Default: `1`. No maximum is specified; fractional numbers, strings, and booleans are rejected.

## Advanced Parameters

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before credits are deducted. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

### Prompt

- `prompt`: Required. Describe the requested changes. Minimum length: **1 character**.
- The value must be a string and must not be blank. No maximum prompt length is specified.

### Image URLs

- `image_urls`: Required. Provide publicly accessible image URLs. Supply 1-3 items. Each item must be an HTTP(S) URL.

## Billing Factors

Billing depends on output resolution (`resolution`) and output image count (`n`). Reference image count (`image_urls`) adds a separate input charge once per request; this charge is not multiplied by `n`.

Credits are deducted on submission and refunded if the task fails.

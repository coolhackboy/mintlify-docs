## Models

`alibaba/z-image/turbo` generates images from text and edits a single reference image.

## Input parameters

- `prompt`: Required string containing 1 to 1000 characters. Describe the image to generate or the edits to apply.
- `image_urls`: Optional array containing exactly one HTTP(S) image URL. Providing this field selects image editing.
- `size`: Required for text-to-image and optional for image editing. Values: `1:1`, `4:3`, `3:4`, `16:9`, `9:16`.
- `enable_safety_checker`: Optional boolean. Defaults to `true`.

## Text to image

```json
{
  "model": "alibaba/z-image/turbo",
  "input": {
    "prompt": "A ceramic vase on a wooden table in soft daylight.",
    "size": "1:1",
    "enable_safety_checker": true
  }
}
```

## Image editing

```json
{
  "model": "alibaba/z-image/turbo",
  "input": {
    "prompt": "Add soft studio lighting to this product photo.",
    "image_urls": ["https://example.com/reference.png"],
    "enable_safety_checker": true
  }
}
```

Text-to-image generation and single-image editing with Z-Image Turbo

## Models

- **alibaba/z-image/turbo** — Generate images from text or edit a single reference image.

## Input modes

- **Text-to-image:** omit `image_urls` and provide `size`.
- **Image editing:** provide exactly one URL in `image_urls`; `size` is optional.

## Required parameters

- `prompt` (string): Required string containing 1 to 1000 characters. Describe the image to generate or the edits to apply.

- `size` (string): Required for text-to-image and optional for image editing. Values: `1:1`, `4:3`, `3:4`, `16:9`, `9:16`.

## Optional parameters

- `image_urls` (array): Array containing exactly one HTTP(S) image URL. Providing this field selects image editing.

- `enable_safety_checker` (boolean): Boolean. Defaults to `true`.

## Examples

### Text to image

```json
{
  "model": "alibaba/z-image/turbo",
  "input": {
    "prompt": "A ceramic vase on a wooden table in soft daylight.",
    "size": "1:1",
    "enable_safety_checker": true
  }
}
```

### Image editing

```json
{
  "model": "alibaba/z-image/turbo",
  "input": {
    "prompt": "Add soft studio lighting to this product photo.",
    "image_urls": ["https://example.com/reference.png"],
    "enable_safety_checker": true
  }
}
```

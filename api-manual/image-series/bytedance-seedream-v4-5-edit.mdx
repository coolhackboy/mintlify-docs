# Seedream 4.5 Edit

Edit images with Seedream 4.5 using a text prompt and 1-10 reference images, generating 1-15 edited images per request.

## Available Models

- **bytedance/seedream/v4.5/edit** - Edit images using a prompt and image references.

## Output Options

### Image Size

- `size`: Optional. Default: `1:1`.
- Presets: `2K`, `4K`, `1:1`, `4:3`, `3:4`, `16:9`, `9:16`, `3:2`, `2:3`, `21:9`.
- For custom dimensions, supply an object with integer `width` and `height`; both must be positive.
- Custom dimensions also accept a `WIDTHxHEIGHT` string, using `x` or `X` between the positive dimensions.

### Image Count

- `n`: Optional. Number of images to generate. Integer from `1` to `15`. Default: `1`.

## Key Features

- Edit images using a prompt and image references.
- Accepts 1-10 images in `image_urls`.
- Control the number of output images with `n`.

## Advanced Parameters

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Input image URLs use HTTP(S) and point to publicly accessible JPEG or PNG files.

### Prompt

- `prompt`: Required. Describe the requested changes. Length: **1-3,000 characters**.
- Include at least one non-whitespace character.

### Image URLs

- `image_urls`: Required. Provide publicly accessible image URLs. Supply 1-10 items. Each item must be an HTTP(S) URL pointing to a JPEG or PNG image.

### Safety Checker

- `enable_safety_checker`: Optional. Set `true` to enable the content safety check or `false` to disable it. Default: `true`.

# Seedream 4.5 Edit

Guide Seedream 4.5 image edits with text and up to ten references, creating multiple variations from an existing visual idea.

## Available Models

- **bytedance/seedream/v4.5/edit** - Edit images using a prompt and image references.

## Output Options

### Image Size

- `size`: Optional. Default: `1:1`.
- Presets: `2K`, `4K`, `1:1`, `4:3`, `3:4`, `16:9`, `9:16`, `3:2`, `2:3`, `21:9`.
- For custom dimensions, supply an object with integer `width` and `height`; both must be positive.
- Custom dimensions also accept a `WIDTHxHEIGHT` string, using `x` or `X` between the positive dimensions.

### Image Count

- `n`: Optional. Number of images to generate. Integer from `1` to `15`. Default: `1`.

## Key Features

- Edit images using a prompt and image references.
- Accepts 1-10 images in `image_urls`.
- Control the number of output images with `n`.

## Advanced Parameters

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before credits are deducted. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

### Prompt

- `prompt`: Required. Describe the requested changes. Length: **1-3,000 characters**.
- The value must not be blank when supplied.

### Image URLs

- `image_urls`: Required. Provide publicly accessible image URLs. Supply 1-10 items. Each item must be an HTTP(S) URL.

### Safety Checker

- `enable_safety_checker`: Optional. Control safety checking. Use `true` or `false`. Default: `true`.

## Pricing

Pricing depends on the selected model and applicable output settings. Check the Vidgo dashboard for the current rate.

Credits are deducted on submission and refunded if the task fails.

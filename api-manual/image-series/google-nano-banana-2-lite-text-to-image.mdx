Turn visual ideas into images with Nano Banana 2 Lite, with framing options for portraits, landscapes, and wide compositions.

## Models

- **google/nano-banana-2-lite/text-to-image** - Generate images from text prompts.

## Features

- Generate images from text prompts.

## Required parameters

- `prompt` (string): Describe the desired image. Minimum length: **1 character**.
- The value must not be blank when supplied. No maximum prompt length is specified.

## Optional parameters

- `size` (string): See [Size](#size) for supported values and constraints.

## Size

- `size`: Optional. Accepted values: `1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`, `21:9`. If omitted, no explicit aspect ratio is specified; there is no default. `auto` is not accepted.

For image editing, use `google/nano-banana-2-lite/edit`.

## Notes

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before credits are deducted.

Develop visual concepts with Seedream 4.5, generating multiple images from a prompt to explore different styles and compositions.

## Models

- **bytedance/seedream/v4.5/text-to-image** - Generate images from text prompts.

## Features

- Generate images from text prompts.
- Control the number of output images with `n`.

## Output Options

### Image Size

- `size`: Optional. Default: `1:1`.
- Presets: `2K`, `4K`, `1:1`, `4:3`, `3:4`, `16:9`, `9:16`, `3:2`, `2:3`, `21:9`.
- For custom dimensions, supply an object with integer `width` and `height`; both must be positive.
- Custom dimensions also accept a `WIDTHxHEIGHT` string, using `x` or `X` between the positive dimensions.

### Image Count

- `n`: Optional. Number of images to generate. Integer from `1` to `15`. Default: `1`.

## Advanced Parameters

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

### Prompt

- `prompt`: Required. Describe the desired image. Length: **1-3,000 characters**.
- Include at least one non-whitespace character.

### Safety Checker

- `enable_safety_checker`: Optional. Set `true` to enable the content safety check or `false` to disable it. Default: `true`.

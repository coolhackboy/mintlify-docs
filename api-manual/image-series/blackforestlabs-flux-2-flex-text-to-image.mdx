# FLUX.2 Flex Text to Image

Explore image concepts with FLUX.2 Flex, using descriptive prompts to shape composition and style in 1K or 2K output.

## Available Models

- **blackforestlabs/flux-2-flex/text-to-image** - Generate images from text prompts.

## Output Options

### Image Size

- `size`: Required. Accepted values: `1:1`, `4:3`, `3:4`, `16:9`, `9:16`, `3:2`, `2:3`, `auto`.

### Resolution

- `resolution`: Required. Accepted values: `1K`, `2K`.

## Key Features

- Generate images from text prompts.
- Choose from `1K`, `2K` output resolutions.

## Advanced Parameters

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Send the input fields listed on this page.

### Prompt

- `prompt`: Required. Describe the desired image. Length: **3-5,000 characters**.

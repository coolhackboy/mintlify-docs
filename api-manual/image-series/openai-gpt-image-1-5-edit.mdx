Make targeted image changes with GPT Image 1.5 using text instructions, reference images, and optional masks for selected areas.

## Models

- **openai/gpt-image-1.5/edit** - Edit images using a prompt and image references.

## Features

- Edit images using a prompt and image references.
- Accepts at least 1 image in `image_urls`.
- Each editing request produces one image and is billed as one image.

## Required parameters

- `prompt` (string): Describe the requested changes. Length: **1-1,000 characters**.
- Include at least one non-whitespace character.

- `image_urls` (array): Provide publicly accessible image URLs. Supply at least 1 item. Each item must be an HTTP(S) URL.

## Optional parameters

- `n` (integer): Compatibility parameter. Accepted values: `1`, `2`, `3`, `4`. Default: `1`. Each edit request produces one image and is billed for one image; larger values do not increase the output count.

- `mask_url` (string): Publicly accessible HTTP(S) URL of a mask image that selects the area to edit.

- `size` (string): See [Size](#size) for supported values and constraints.

## Size

- `size`: Optional. Accepted values: `1024x1024`, `1024x1536`, `1536x1024`. Default: `1024x1024`.

## Notes

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

# Seedream 4 Edit

Transform images with Seedream 4 using multiple visual references, with batch variations and output up to 4K.

## Available Models

- **bytedance/seedream/v4/edit** - Edit images using a prompt and image references.

## Output Options

### Image Size

- `size`: Optional. Accepted values: `1:1`, `3:4`, `4:3`, `16:9`, `9:16`, `3:2`, `2:3`, `21:9`. Default: `1:1`.

### Resolution

- `resolution`: Optional. Accepted values: `1K`, `2K`, `4K`. Default: `2K`.

### Image Count

- `n`: Optional. Number of images to generate. Integer from `1` to `15`. Default: `1`.
- The number of `image_urls` plus `n` totals 15 or fewer.

## Key Features

- Edit images using a prompt and image references.
- Accepts 1-10 images in `image_urls`.
- Choose from `1K`, `2K`, `4K` output resolutions.
- Control the number of output images with `n`.

## Advanced Parameters

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Input image URLs use HTTP(S) and point to publicly accessible image files.

### Prompt

- `prompt`: Required. Describe the requested changes. Length: **1-5,000 characters**.
- Include at least one non-whitespace character.

### Image URLs

- `image_urls`: Required. Provide publicly accessible image URLs. Supply 1-10 items. Each item must be an HTTP(S) URL.

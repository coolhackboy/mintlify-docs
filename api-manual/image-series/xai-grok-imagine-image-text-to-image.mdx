Turn text prompts into images with Grok Imagine, exploring visual ideas in square, portrait, and landscape formats.

## Models

- **xai/grok-imagine-image/text-to-image** - Generate images from text prompts.

## Features

- Generate images from text prompts.

## Required parameters

- `prompt` (string): Describe the desired image. Length: **1-5,000 characters**.

## Optional parameters

- `size` (string): See [Size](#size) for supported values and constraints.

## Size

- `size`: Optional. Accepted values: `1:1`, `2:3`, `3:2`, `9:16`, `16:9`.

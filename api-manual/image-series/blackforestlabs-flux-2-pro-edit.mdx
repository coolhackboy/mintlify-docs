Combine visual references with text instructions in FLUX.2 Pro to edit scenes, transfer styles, and retain recognizable subjects.

## Models

- **blackforestlabs/flux-2-pro/edit** - Edit images using a prompt and image references.

## Features

- Edit images using a prompt and image references.
- Accepts 1-8 images in `image_urls`.
- Choose from `1K`, `2K` output resolutions.

## Output Options

### Image Size

- `size`: Required. Accepted values: `1:1`, `4:3`, `3:4`, `16:9`, `9:16`, `3:2`, `2:3`, `auto`. `auto` uses the aspect ratio of the first image in `image_urls`.

### Resolution

- `resolution`: Required. Accepted values: `1K`, `2K`.

## Advanced Parameters

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Send the input fields listed on this page. Each input URL is a public HTTP(S) URL.

### Prompt

- `prompt`: Required. Describe the requested changes. Length: **3-5,000 characters**.

### Image URLs

- `image_urls`: Required. Provide publicly accessible image URLs. Supply 1-8 items. Each item must be an HTTP(S) URL.

Rework images with Kling O3 using multiple references and subject elements, with output up to 4K and support for visual variations.

## Models

- **kwaivgi/kling-image-o3/edit** - Edit images using a prompt and image references.

## Features

- Edit images using a prompt and image references.
- Accepts 1-10 images in `image_urls`.
- Choose from `1K`, `2K`, `4K` output resolutions.
- Supply additional subject references through `elements`.
- Control the number of output images with `n`.

## Required parameters

- `prompt` (string): Describe the requested changes. Length: **1-2,000 characters**.
- The value must not be blank when supplied.

- `image_urls` (array): Provide publicly accessible image URLs. Supply 1-10 items. Each item must be an HTTP(S) URL.

## Optional parameters

- `n` (integer): Number of images to generate. Integer from `1` to `9`. Default: `1`. Fractional values, strings, and booleans are rejected.

- `elements` (array): Provide subject-reference objects. Supply an array. Each item is an object.

- `elements[].frontal_image_url` (string): Use a publicly accessible HTTP(S) URL.

- `elements[].reference_image_urls` (array): Supply an array. Each item must be an HTTP(S) URL.

Refer to subjects in the prompt as `@Element1`, `@Element2`, etc. Element objects may include additional fields; no element count limit is specified.

- `resolution` (string): See [Resolution](#resolution) for supported values and constraints.

- `size` (string): See [Size](#size) for supported values and constraints.

- `output_format` (string): See [Output Formats](#output-formats) for supported values and constraints.

## Size

- `size`: Optional. Accepted values: `auto`, `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `3:2`, `2:3`, `21:9`. Default: `16:9`.

## Resolution

- `resolution`: Optional. Accepted values: `1K`, `2K`, `4K`. Default: `1K`.

## Output Formats

- `output_format`: Optional. Accepted values: `jpeg`, `png`, `webp`. Default: `png`.

## Notes

Defaults apply only when an optional input field is omitted. Explicit `null` or empty-string values are rejected. An empty `elements` array is accepted.

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before credits are deducted. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

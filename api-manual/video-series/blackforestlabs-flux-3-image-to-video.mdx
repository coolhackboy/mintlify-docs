Bring a still image into motion with FLUX 3, using text to direct the scene with optional sound and output up to 1080p.

## Models

- **blackforestlabs/flux-3/image-to-video** — Generate video from image input.

## Features

- Animate a single reference image.
- Choose from `720p`, `1080p` output resolutions.
- Control audio generation with `sound`; it defaults to `true`.

## Required parameters

- `prompt` (string): Describe the scene and desired motion. The prompt must not be blank when supplied.
- `image_urls` (string[]): Provide exactly 1 image URL. Images must be publicly accessible and directly downloadable.

## Optional parameters

- `duration` (integer): 5-20 seconds. Default: 5 seconds.
- `resolution` (string): `720p`, `1080p`. Default: `720p`.
- `aspect_ratio` (string): `auto`, `21:9`, `2:1`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`. Default: `auto`.
- `sound` (boolean): Set to `true` to enable generated audio, or `false` to disable it. Default: `true`.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before task creation. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

Create a speaking avatar with Kling Avatar 2.0 Standard, combining a character image and an audio performance with optional text direction.

## Models

- **kwaivgi/kling-video/ai-avatar/v2/standard** — Animate a character image with driving audio.

## Features

- Animate a character image with driving audio.
- Accepts exactly 1 image in `image_urls`.

## Required parameters

- `image_urls` (string[]): Supply exactly 1 item. Each item may be a public HTTP(S) URL, image Data URI, or raw Base64. Image order is preserved.
- `audio_url` (string): Provide the input audio URL. Use a publicly accessible HTTP(S) URL.

## Optional parameters

- `prompt` (string): Describe the scene and desired motion. Maximum **2500 characters** after trimming. Leading and trailing whitespace is trimmed. Omitted, null, empty, and whitespace-only values are treated as omitted.

## Notes

### Duration Options

- **Driving audio: 2-60 seconds** - The service detects the duration of `audio_url`.
- The audio must be publicly reachable over HTTP(S) and no larger than **5 MiB**.

### Input requirements

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before task creation. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials. Image inputs also accept image Data URIs or raw Base64. Image conversion and media validation complete before task creation.

<Tip>
1. After submission, a `task_id` will be returned. If you provided a `callback_url`, when the task status becomes `finished` or `failed`, a POST request will be sent to the `callback_url`.
2. Regardless of whether `callback_url` is provided, you can retrieve the result through the unified [Query Task Status](/api-manual/task-management/status) endpoint.
</Tip>

## Optional parameters

- `enable_safety_checker`: boolean, defaults to `true`. Set `false` to disable it.
- `callback_url`: optional webhook URL at the request root. Query task status if you do not use a callback.

## Usage Guide

Use `minimax/h3-max/text-to-video`. Provide a prompt without media. Select the text endpoint for prompt-only generation.

Set `model` and optional `callback_url` at the request root. Place generation parameters inside `input`.

## Parameter Details

- `prompt`: required non-empty string, up to 50,000 characters.
- `duration`: integer from 5 through 15 seconds; defaults to 5. Fractional durations are rejected.
- `resolution`: `480p`, `768p` or `1080p`; defaults to `768p`.
- `aspect_ratio`: `21:9`, `16:9`, `4:3`, `1:1`, `3:4` or `9:16`; defaults to `16:9`.

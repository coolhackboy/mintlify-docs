MiniMax H3 reference to video model with fixed 2K output

## Models

- **minimax/h3/reference-to-video** — MiniMax H3 reference to video generation with 2K output

## Features

- **Reference To Video**: Guide generation with reference images, videos, and optional audio.
- **2K Output**: Output resolution is fixed at `2K`.

## Required parameters

- `prompt` (string): Prompt describing the target video. Length: 1–2,000 characters.

## Optional parameters

- `duration` (integer): Output duration in seconds. Range: 5–15. Default: `5`.
- `resolution` (string): Output resolution is fixed at 2K. Values: `2K`. Default: `2K`.
- `aspect_ratio` (string): Output aspect ratio. Supports adaptive or one of six fixed ratios. Values: `adaptive`, `21:9`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`.
- `reference_image_urls` (array of strings): Reference images. 1–9 items.
- `reference_video_urls` (array of strings): Reference videos. 1–3 items.
- `reference_audio_urls` (array of strings): Reference audio; requires a reference image or video. At most 3 items.

## Notes

- Provide at least one reference image or reference video. Reference audio cannot be used alone.
- All media URLs must be publicly accessible and directly downloadable.

- Reference input accepts up to 9 images, 3 video clips, and 3 audio clips. Reference audio requires at least one reference image or reference video.

Provide at least one of `reference_image_urls`, `reference_video_urls`.

Turn a starting image into a 768p video with Hailuo 2.3 Standard, using text and optional prompt refinement to guide the motion.

## Models

- **minimax/hailuo-2.3/standard/image-to-video** — Generate video from image input.

## Features

- Generate video from image input.
- Use `start_image_url` to supply the starting frame.
- This model ID fixes the output resolution to `768p`.

## Required parameters

- `prompt` (string): Required nonblank string, trimmed before validation. Maximum 5,000 Unicode characters.
- `start_image_url` (string): Required first-frame HTTP(S) image URL with a hostname and no embedded credentials. Data URLs and arrays are not supported.

## Optional parameters

- `duration` (integer): Output duration in seconds. 6 or 10; defaults to 6. Values: `6`, `10`.
- `resolution` (string): Fixed to 768p for this endpoint. Values: `768p`. Default: `768p`.
- `prompt_optimizer` (boolean): Optional boolean with no specified default. Omit when unused.

## Notes

Send only the input fields supported by this workflow. JSON types are validated without converting strings to numbers or booleans; `prompt` must be a string and fractional durations are rejected. Unsupported `input` fields are rejected. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

- The value must not be blank when supplied.

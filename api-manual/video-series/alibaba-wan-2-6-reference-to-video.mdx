Use reference videos to guide new scenes with Wan 2.6, with support for multiple shots and video output up to 1080p.

## Models

- **alibaba/wan-2.6/reference-to-video** — Generate video guided by reference material and a prompt.

## Features

- Generate video guided by reference material and a prompt.
- Use 1-10 video references to guide the generated scene.
- Choose from `720p`, `1080p` output resolutions.

## Required parameters

- `prompt` (string): Describe the scene and desired motion. Length: **1-5,000 characters**. The value must not be blank when supplied.
- `video_urls` (string[]): Provide reference video URLs. Supply 1-10 items. Each item must be an HTTP(S) URL. Reference videos support MP4, MOV, and MKV files up to 10 MiB each.

## Optional parameters

- `duration` (integer): 5, 10 seconds. Optional. Default: 5 seconds.
- `resolution` (string): Accepted values: `720p`, `1080p`. Default: `720p`.
- `multi_shots` (boolean): Enable multi-shot generation. Use `true` or `false`.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before task creation. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

Seedance 2.0 Fast image to video model with multimodal generation and optional audio

## Models

- **seedance-2.0-fast/image-to-video** — Seedance 2.0 Fast image to video generation

## Features

- **Image To Video**: Control the starting frame and optional ending frame with up to two images.
- **Optional Audio**: Request generated audio together with the video.

## Required parameters

- `prompt` (string): Prompt describing the target video. Length: 1–20,000 characters.
- `duration` (integer): Output duration in seconds. Range: 4–15.
- `resolution` (string): Output resolution. Values: `480p`, `720p`.
- `image_urls` (array of strings): Starting frame and optional ending frame. 1–2 items.

## Optional parameters

- `aspect_ratio` (string): Output aspect ratio. Image-to-video accepts only auto when provided. Values: `auto`, `21:9`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`.
- `generate_audio` (boolean): Whether to generate an audio track.
- `return_last_frame` (boolean): Whether to return the final generated frame.
- `web_search` (boolean): Whether to enable web-assisted generation when supported.
- `seed` (integer): Optional deterministic seed.
## Notes

- Supply one starting frame and an optional ending frame in `image_urls`.
- All media URLs must be publicly accessible and directly downloadable.

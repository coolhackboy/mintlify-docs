# Wan Animate Replace

Replace the character in a source video using a reference image with Wan Animate, adapting the original performance to a new subject.

## Available Models

- **alibaba/wan/v2.2-14b/animate/replace** - Replace a character in a source video using an image reference.

## Duration Options

- The service inspects the duration of `video_url`; this workflow does not accept a `duration` field.
- The source video must be publicly reachable over HTTP(S) and no larger than **100 MiB**.

## Key Features

- Replace a character in a source video using an image reference.
- Accepts exactly 1 image in `image_urls`.
- Choose from `480p`, `580p`, `720p` output resolutions.

## Advanced Parameters

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before credits are deducted. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

### Source Video

- `video_url`: Required. Provide the source video URL. Use a publicly accessible HTTP(S) URL.

### Image URLs

- `image_urls`: Required. Provide publicly accessible image URLs. Supply exactly 1 item. Each item must be an HTTP(S) URL.

### Resolution

- `resolution`: Optional. Accepted values: `480p`, `580p`, `720p`. Default: `480p`.

## Pricing

Pricing depends on the selected model and applicable output settings. Check the Vidgo dashboard for the current rate.

Credits are deducted on submission and refunded if the task fails.

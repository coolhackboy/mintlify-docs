Replace the character in a source video with the character from a reference image using Wan Animate Replace.

## Models

- **alibaba/wan/v2.2-14b/animate/replace** — Replace the character in a source video with the character from a reference image using Wan Animate Replace.

## Features

- Replace the character in a source video with the character from a reference image using Wan Animate Replace.
- Accepts an `image_urls` array containing exactly one image URL.
- Supports `480p`, `580p`, and `720p` output resolutions.

## Required parameters

- `video_url` (string): The source video containing the character to replace. The video must meet the source video requirements in Notes.
- `image_urls` (string[]): Containing exactly one publicly accessible HTTP(S) image URL. The reference image containing the replacement character. A single URL string instead of an array, an empty array, multiple URLs, and Base64 images are rejected.

## Optional parameters

- `resolution` (string): Accepted values: `480p`, `580p`, `720p`. Defaults to `480p` only when the field is omitted. Null, empty strings, other values, and values with surrounding whitespace are rejected.

## Notes

- If Vidgo cannot read the source video or determine its duration, the request is rejected before task creation.

### Source Video Requirements

- `video_url` must point to a publicly accessible HTTP(S) video file.
- The entire video file must be no larger than **100 MiB** (104,857,600 bytes), and its duration must be greater than zero.

### Input requirements

Unsupported `input` fields are rejected before task creation. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials or whitespace.

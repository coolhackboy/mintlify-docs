Rework existing video with Gemini Omni 1.1 Flash, using written instructions to guide changes to the scene with output up to 4K.

## Models

- **google/gemini-omni-1.1-flash/video-edit** — Edit an existing video using written instructions.

## Features

- Edit an existing video using written instructions.
- Optionally add up to five reference images to guide the edit.
- Choose from `360p`, `720p`, `1080p`, `4k` output resolutions.
- Supports landscape (`16:9`) and portrait (`9:16`) framing.

## Required parameters

- `prompt` (string): Describe the requested changes to the video. The prompt must not be blank when supplied. Maximum length: **20,000 characters**.
- `reference_video_urls` (string[]): Provide an array containing exactly one publicly accessible source video URL. The source video must be directly downloadable over HTTP(S) and no larger than **100 MiB** for duration inspection.

## Optional parameters

- `reference_image_urls` (string[]): Provide up to 5 images. Omit `reference_image_urls` or send an empty array when no reference images are needed. Minimum items: 0. Maximum items: 5.
- `resolution` (string): `360p`, `720p`, `1080p`, `4k`. Default: `720p`.
- `aspect_ratio` (string): `16:9`, `9:16`. Default: `16:9`.

## Notes

### Duration Options

- **Source video: 3-10 seconds** - Output duration follows the reference video.

### Input requirements

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before task creation. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

Generate an 8-second video with the Google Veo 3.1 Fast model.

## Models

- **veo3.1-fast/reference-to-video** — Veo 3.1 Fast reference to video generation

## Features

- Guide Veo 3.1 Fast with exactly three reference images.
- Supports up to `4k` output resolution.

## Required parameters

- `prompt` (string): Prompt describing the target video.
- `image_urls` (array of strings): Exactly three reference images.

## Optional parameters

- `duration` (integer): Veo 3.1 output duration is fixed at 8 seconds. Values: `8`. Default: `8`.
- `aspect_ratio` (string): Output aspect ratio. Values: `16:9`, `9:16`.
- `resolution` (string): Output resolution. Values: `720p`, `1080p`, `4k`. Default: `720p`.

## Notes

- The output duration is fixed at 8 seconds.
- Generated video URLs are temporary and should be downloaded promptly.

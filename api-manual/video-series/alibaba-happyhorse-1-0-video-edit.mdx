Transform existing footage with Happy Horse using text instructions and reference images to guide a new visual direction.

## Models

- **alibaba/happyhorse-1.0/video-edit** — Edit an existing video using written instructions.

## Features

- Edit an existing video using written instructions.
- Optionally add up to five reference images to guide the edit.
- Choose from `720p`, `1080p` output resolutions.
- Choose automatic audio handling or preserve the source audio.

## Required parameters

- `prompt` (string): Describe the requested changes to the video. The prompt must not be blank when supplied. Maximum length: **2,500 characters**.
- `video_url` (string): Provide one publicly accessible source video URL. The source video must be directly downloadable over HTTP(S) and no larger than **100 MiB** for duration inspection.

## Optional parameters

- `reference_image_urls` (string[]): Provide up to 5 images. Describe referenced subjects in the prompt; `character1` and `character2` markers are not required. Maximum items: 5.
- `resolution` (string): `720p`, `1080p`. Default: `1080p`.
- `audio_setting` (string): `auto` or `origin`. Default: `auto`.
- `seed` (integer): Supply an integer from `0` to `2147483647`.
- `enable_safety_checker` (boolean): Set it to `true` or `false` to control safety checking.

## Notes

### Duration Options

- **Source video: 3-60 seconds** - Duration is read from `video_url`.

### Input requirements

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before task creation. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

- `auto` lets the model determine audio handling; `origin` preserves the original audio.

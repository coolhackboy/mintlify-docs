Generate standard quality videos using OpenAI's Sora 2 model. Supports text-to-video and image-to-video generation.

## Models

- **sora-2** — Standard quality video generation
- **sora-2-private** — Private deployment for standard quality

## Input modes

- **Text-to-video**: Omit `image_urls` and describe the scene in `prompt`.
- **Image-to-video**: Supply `image_urls` to guide generation with reference imagery.

## Required parameters

- `prompt` (string): Describe the scene and desired motion. Length: up to 1,000 characters.

## Optional parameters

- `image_urls` (array of strings): Reference image URL (for image-to-video). Only one image is supported. Maximum file size: 10MB. Supported formats: .jpeg, .jpg, .png, .webp.
- `duration` (integer): Video duration in seconds (10 or 15). Values: `10`, `15`.
- `aspect_ratio` (string): Video aspect ratio. Values: `16:9`, `9:16`.
- `style` (string): Video style. Values: `thanksgiving`, `comic`, `news`, `selfie`, `nostalgic`, `anime`.
- `storyboard` (boolean): Whether to use storyboard for finer control over video generation details. true: Enable storyboard feature, false: Do not use storyboard.

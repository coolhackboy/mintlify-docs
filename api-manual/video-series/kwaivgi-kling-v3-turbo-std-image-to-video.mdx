Bring reference images into motion with Kling 3.0 Turbo Standard, using text and shot prompts to guide a video sequence.

## Models

- **kwaivgi/kling-v3-turbo-std/image-to-video** — Generate video from image input.

## Features

- Animate a single reference image.
- Direct one scene with `prompt`, or use `multi_prompt` for up to six shots.
- The input image determines the output aspect ratio.

## Input modes

- **Single shot:** use `prompt` and omit `multi_prompt`.
- **Multiple shots:** use `multi_prompt` instead of a top-level `prompt`.

## Required parameters

- `image_urls` (string[]): Provide exactly 1 image URL. Images must be publicly accessible and directly downloadable.

## Optional parameters

- `prompt` (string): Describe the scene and desired motion. Minimum length: 1 character. Maximum length: 2,500 characters.
- `multi_prompt` (object[]): Multi prompt. Minimum items: 1. Maximum items: 6.
- `duration` (integer): 3-15 seconds - Accepted range for an explicit `duration`. Without `multi_prompt`, the default is 5 seconds. Multi-shot output - Each shot accepts `1`-`15` seconds and defaults to `5`. The total must not exceed 15 seconds. With `multi_prompt`, omit `duration` to use the shot total, including totals of 1 or 2 seconds. If supplied, `duration` must equal the shot total and remain within `3`-`15` seconds.
- `aspect_ratio` (string): Ignored in image-to-video mode; the input images determine the aspect ratio.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before task creation. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

- `prompt` is optional and supports up to **2,500 characters**. Blank optional prompts are treated as omitted.
- Use either `prompt` or `multi_prompt`; do not combine them.

- `multi_prompt` accepts **1-6 shot objects** and cannot be combined with `prompt`.
- Each shot requires a nonblank `prompt` of at most **2,500 characters**.
- Each shot can include an integer `duration` from **1 to 15 seconds**; the default is **5 seconds**.
- The combined shot duration must not exceed **15 seconds**. See the `duration` parameter for the top-level duration rules.

- The output aspect ratio follows the input image.
- `aspect_ratio` is ignored by this endpoint and can be omitted.

## Usage Guide

Submit `kwaivgi/kling-v3-turbo-std/image-to-video` with `VIDGO_API_KEY`. Keep model and callback_url at the request root and place workflow parameters inside input.

The response contains a task_id. Use [Query Task Status](/api-manual/task-management/status) or [Webhook Callbacks](/api-manual/task-management/webhooks) to retrieve the files.

## Parameter Details

Required input fields: `image_urls`.

- Send only the fields shown for this workflow. Parameters from other workflows are rejected before credits are deducted.
- Blank optional prompts are treated as omitted. Input URL fields require HTTP(S) URLs with a hostname and no embedded credentials.
- aspect_ratio is ignored in image-to-video mode and is not forwarded; the input images determine the aspect ratio.
- prompt is optional and cannot be combined with multi_prompt. Supply one to six shots, each with a nonblank prompt and an optional integer duration from one to fifteen seconds (default five). The shot total must not exceed fifteen seconds. An explicit top-level duration must be three to fifteen seconds and equal the shot total. Omit it to use the shot total, including one- or two-second totals. Without multi_prompt, omitted duration defaults to five seconds. Billing uses the shot total when multi_prompt is provided.

## Developer Notes

Keep the task_id until the task reaches finished or failed. Failed tasks return charged credits through the normal refund process. Existing public IDs remain available; use the exact workflow ID shown on this page for new integrations.

## Optional parameters

Available input fields: `prompt`, `multi_prompt`, `duration`, `aspect_ratio`. See the request schema for accepted values and defaults.

`wan2.2-image-to-video-fast` animates one reference image, and optionally uses a second image as the last frame for stronger transition control.

## Models

- **wan2.2-image-to-video-fast** — Animate a reference image into a short video

## Required parameters

- `prompt` (string): Text prompt for the motion and scene.
- `image_urls` (array of strings): Reference image URLs. The first image is required; the optional second image is used as the last frame. 1–2 items.

## Optional parameters

- `resolution` (string): Output video resolution. Values: `480p`, `720p`. Default: `480p`.
- `seed` (integer): Optional random seed for reproducibility.

Seedance 2.0 Mini reference to video model optimized for fast video generation

## Models

- **seedance-2.0-mini/reference-to-video** — Fast Seedance 2.0 Mini reference to video generation

## Features

- **Reference To Video**: Guide generation with reference images, videos, and optional audio.
- **Optional Audio**: Request generated audio together with the video.

## Required parameters

- `prompt` (string): Prompt describing the target video. Length: 1–20,000 characters.
- `duration` (integer): Output duration in seconds. Range: 4–15.

## Optional parameters

- `resolution` (string): Output resolution. Values: `480p`, `720p`. Default: `720p`.
- `aspect_ratio` (string): Output aspect ratio. Values: `auto`, `21:9`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`.
- `generate_audio` (boolean): Whether to generate an audio track.
- `reference_image_urls` (array of strings): Reference images. 1–9 items.
- `reference_video_urls` (array of strings): Reference videos. 1–3 items.
- `reference_audio_urls` (array of strings): Reference audio. Requires a reference image or video. At most 3 items.
- `return_last_frame` (boolean): Whether to return the final generated frame.
- `web_search` (boolean): Whether to enable web-assisted generation when supported.
- `seed` (integer): Optional deterministic seed.
## Notes

- Provide at least one reference image or reference video. Reference audio cannot be used alone.
- Reference input supports up to 9 images, 3 videos, and 3 audio files, with at most 12 files in total.
- All media URLs must be publicly accessible and directly downloadable.

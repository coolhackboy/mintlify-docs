Generate video with Kling 2.5 Turbo Pro using a start frame, an end frame, or both, plus a text prompt.

## Models

- **kwaivgi/kling-v2.5-turbo-pro/image-to-video** — Generate video from image input.

## Features

- Generate video from image input.
- Guide generation with `start_image_url`, `end_image_url`, or both.

## Required parameters

- `prompt` (string): Describe the scene and desired motion. Length: **1-2,500 characters**. Supply a string, not a number, boolean, array, or object. Whitespace is trimmed before the 2,500 Unicode character limit is checked.

## Optional parameters

- `duration` (integer): 5, 10 seconds. Optional. Default: 5 seconds. Strings, booleans, fractional durations, and `null` are rejected.
- `start_image_url` (string): First-frame public HTTP(S) URL. Required only when `end_image_url` is omitted.
- `end_image_url` (string): Last-frame public HTTP(S) URL. Required only when `start_image_url` is omitted. Provide at least one frame: start only, end only, or both. Omit unused URL fields; empty strings and `null` are rejected.
- `aspect_ratio` (string): No preset choices or default value are specified. Omit when unused.
- `negative_prompt` (string): Describe content to avoid.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before task creation. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials or whitespace. Image fields do not accept arrays or Base64.

Turn written scenes into video with Wan 2.6, with support for multiple shots and output up to fifteen seconds at 1080p.

## Models

- **alibaba/wan-2.6/text-to-video** — Generate video scenes from text prompts.

## Features

- Generate video scenes from text prompts.
- Choose from `720p`, `1080p` output resolutions.

## Required parameters

- `prompt` (string): Describe the scene and desired motion. Length: **1-5,000 characters**. The value must not be blank when supplied.

## Optional parameters

- `duration` (integer): 5, 10, 15 seconds. Optional. Default: 5 seconds.
- `resolution` (string): Accepted values: `720p`, `1080p`. Default: `720p`.
- `multi_shots` (boolean): Enable multi-shot generation. Use `true` or `false`.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before task creation.

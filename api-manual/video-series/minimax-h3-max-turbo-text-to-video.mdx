1. Submit the request with `VIDGO_API_KEY`. A `task_id` is returned. Keep it until the task reaches `finished` or `failed`.
2. Use [Query Task Status](/api-manual/task-management/status) to retrieve the result. If you provide a `callback_url`, Vidgo sends the result to your webhook when the task finishes or fails.
</Tip>

## Usage Guide

Use `minimax/h3-max-turbo/text-to-video`. Provide a prompt without media. Select the text endpoint for prompt-only generation.

Set `model` and optional `callback_url` at the request root. Place generation parameters inside `input`.

## Parameter Details

- `prompt`: required non-empty string, up to 50,000 characters.
- `duration`: integer from 5 through 15 seconds; defaults to 5. Fractional durations are rejected.
- `resolution`: `480p`, `768p` or `1080p`; defaults to `768p`. Uppercase `P` is also accepted.
- `aspect_ratio`: `21:9`, `16:9`, `4:3`, `1:1`, `3:4` or `9:16`; defaults to `16:9`.

## Optional parameters

- `enable_safety_checker`: boolean, defaults to `true`. Set `false` to disable it.
- `callback_url`: optional webhook URL at the request root. Query task status if you do not use a callback.

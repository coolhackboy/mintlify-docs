Rework existing video with Gemini Omni Flash, using written instructions to guide changes to the scene with output up to 4K.

## Models

- **google/gemini-omni-flash/video-edit** — Edit an existing video using written instructions.

## Features

- Edit an existing video using written instructions.
- Choose from `720p`, `1080p`, `4k` output resolutions.
- Supports landscape (`16:9`) and portrait (`9:16`) framing.

## Required parameters

- `prompt` (string): Describe the requested changes to the video. The prompt must not be blank when supplied. Maximum length: **20,000 characters**.
- `video_urls` (string[]): Provide an array containing exactly one publicly accessible source video URL.

## Optional parameters

- `resolution` (string): `720p`, `1080p`, `4k`. Default: `720p`.
- `aspect_ratio` (string): `16:9`, `9:16`. Default: `16:9`.

## Notes

### Duration Options

- Provide one source video in `video_urls`. This workflow does not impose a source-video duration limit.

### Input requirements

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before task creation. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

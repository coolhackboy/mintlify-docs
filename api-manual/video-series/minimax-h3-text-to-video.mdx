MiniMax H3 text to video model with fixed 2K output

## Models

- **minimax/h3/text-to-video** — MiniMax H3 text to video generation with 2K output

## Features

- **Text To Video**: Generate a video directly from a prompt.
- **2K Output**: Output resolution is fixed at `2K`.

## Required parameters

- `prompt` (string): Prompt describing the target video. Length: 1–2,000 characters.

## Optional parameters

- `duration` (integer): Output duration in seconds. Range: 5–15. Default: `5`.
- `resolution` (string): Output resolution is fixed at 2K. Values: `2K`. Default: `2K`.
- `aspect_ratio` (string): Output aspect ratio. Supports six fixed ratios; adaptive is not accepted. Values: `21:9`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`.

## Notes

- All media URLs must be publicly accessible and directly downloadable.

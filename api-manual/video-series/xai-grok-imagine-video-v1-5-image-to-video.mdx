## Grok Imagine Video 1.5 Image to Video

Animate a single image using a prompt that describes subject motion, camera movement, and sound. The image supplies the first frame and determines the video's aspect ratio.

## Request

Set `model` to `xai/grok-imagine-video-v1.5/image-to-video`. Place the following parameters inside `input`. Set optional `callback_url` at the request root.

### prompt

Required string. Describe the scene and desired motion in **1–4,096 characters**, including at least one non-whitespace character.

### image_urls

Required array containing **exactly one** publicly accessible HTTP(S) image URL. Use a URL with a hostname and credential-free access.

### resolution

Optional string: `480p`, `720p`, or `1080p`. Default: `720p`.

### duration

Optional integer from **1 to 15** seconds. Default: **6**.

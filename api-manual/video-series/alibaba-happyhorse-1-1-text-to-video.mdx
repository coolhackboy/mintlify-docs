Generate short video scenes with Happy Horse 1.1, with output up to 1080p and framing from wide cinematic layouts to tall vertical video.

## Models

- **alibaba/happyhorse-1.1/text-to-video** — Generate video scenes from text prompts.

## Features

- Generate video scenes from text prompts.
- Choose from `720p`, `1080p` output resolutions.

## Required parameters

- `prompt` (string): Describe the scene and desired motion. Maximum: **2,500 Unicode characters**. Leading and trailing whitespace is trimmed. A nonblank prompt is required.

## Optional parameters

- `aspect_ratio` (string): Accepted values: `21:9`, `16:9`, `4:3`, `1:1`, `3:4`, `4:5`, `5:4`, `9:16`, `9:21`. Default: `16:9`.
- `resolution` (string): Accepted values: `720p`, `1080p`. Default: `1080p`.
- `duration` (integer): 3-15 seconds. Optional. Default: 5 seconds.
- `seed` (integer): Set the generation seed. Integer from `0` to `2147483647`.
- `enable_safety_checker` (boolean): Control safety checking. Use `true` or `false`.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before task creation.

`duration` and `seed` also accept integer strings such as `"5"`; decimal numbers such as `5.0` and decimal strings such as `"5.0"` are rejected. Null or empty values use the default duration or omit the seed. Supported boolean fields also accept `0`/`1` and case-insensitive strings `true`/`false`, `1`/`0`, `yes`/`no`, `y`/`n`, and `on`/`off`; null omits the field. Surrounding whitespace is trimmed, and resolution values are case-insensitive.

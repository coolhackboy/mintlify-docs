Seedance 2.5 reference to video model with native audio and precise motion control

## Models

- **seedance-2.5/reference-to-video** — Seedance 2.5 reference to video generation

## Required parameters

- `prompt` (string): Prompt describing the target video. Length: 1–20,000 characters.
- `duration` (integer): Output duration in seconds. Range: 4–30.
- `resolution` (string): Output resolution. Values: `480p`, `720p`, `1080p`.

## Optional parameters

- `aspect_ratio` (string): Output aspect ratio. Values: `auto`, `21:9`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`.
- `generate_audio` (boolean): Whether to generate an audio track.
- `reference_image_urls` (array of strings): Reference images. 1–30 items.
- `reference_video_urls` (array of strings): Reference videos. 1–10 items.
- `reference_audio_urls` (array of strings): Reference audio. Requires a reference image or video. At most 10 items.
## Notes

- Provide at least one reference image or reference video. Reference audio cannot be used alone.
- Reference input supports up to 30 images, 10 videos, and 10 audio files, with at most 50 files in total.
- All media URLs must be publicly accessible and directly downloadable.

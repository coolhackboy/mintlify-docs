Animate still images with Hailuo 02 Pro, with text guidance, prompt refinement, and an optional closing frame to shape the shot.

## Models

- **minimax/hailuo-02/pro/image-to-video** — Generate video from image input.

## Features

- Generate video from image input.
- Accepts exactly 1 image in `image_urls`.
- Optionally supply an ending frame with `end_image_url`.

## Required parameters

- `prompt` (string): Required nonblank prompt, trimmed before validation. No maximum prompt length is specified.
- `image_urls` (array of strings): Reference image URLs for image-to-video generation (required for image-to-video). Exactly 1 item.

## Optional parameters

- `end_image_url` (string): Optional last-frame image URL; requires image_urls.
- `prompt_optimizer` (boolean): Enable AI-powered prompt optimization.
- `resolution` (string): Output resolution. Defaults to `768P`. Values: `512P`, `768P`.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

The ending frame in `end_image_url` is supported at both resolutions.

`sora-2-pro-official` supports text-to-video generation and optional single-image guided generation with fixed 4s, 8s, 12s, 16s, and 20s durations.

## Models

- **sora-2-pro-official** — Pro text-to-video and image-guided video generation

## Input modes

- **Text-to-video**: Omit `image_urls` and describe the scene in `prompt`.
- **Image-to-video**: Supply `image_urls` to guide generation with reference imagery.

## Required parameters

- `prompt` (string): Describe the scene and desired motion.

## Optional parameters

- `image_urls` (array of strings): Optional reference image URLs. Only one image is supported.
- `duration` (integer): Output duration in seconds. Values: `4`, `8`, `12`, `16`, `20`. Default: `4`.
- `aspect_ratio` (string): Video aspect ratio. `auto` is only supported when `image_urls` is provided. Values: `auto`, `16:9`, `9:16`. Default: `16:9`.
- `resolution` (string): Output resolution. Values: `720p`, `1024p`, `1080p`. Default: `1024p`.

## Notes

- `image_urls` is optional. If provided, only one image is supported.
- `aspect_ratio=auto` is only valid when `image_urls` is provided.
- Query status through the standard task status API.

Generate high-quality videos from text prompts or reference images using Seedance 1.0 Pro by ByteDance. Create smooth, professional animations with flexible duration and resolution options.

## Models

- **seedance-1.0-pro** — Text-to-video and image-to-video generation with 3x faster rendering

## Features

- **Flexible Modes**: Supports text-to-video and image-to-video generation
- **Multiple Resolutions**: 720p and 1080p support
- **Duration Options**: 5 or 10 seconds
- **Fast Rendering**: 3x faster than standard Pro version

## Input modes

- **Text-to-video**: Omit `image_urls` and describe the scene in `prompt`.
- **Image-to-video**: Supply `image_urls` to guide generation with reference imagery.

## Required parameters

- `prompt` (string): Describe the scene and desired motion. Length: up to 10,000 characters.

## Optional parameters

- `image_urls` (array of strings): Optional reference image URL for image-to-video generation. At most 1 items.
- `resolution` (string): Output video resolution. Values: `720p`, `1080p`.
- `duration` (integer): Video duration in seconds. Values: `5`, `10`.

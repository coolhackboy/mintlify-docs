Bring a still image into motion with Wan 2.6, creating video sequences with optional multiple shots at up to 1080p.

## Models

- **alibaba/wan-2.6/image-to-video** — Generate video from image input.

## Features

- Generate video from image input.
- Accepts exactly 1 image in `image_urls`.
- Choose from `720p`, `1080p` output resolutions.

## Required parameters

- `prompt` (string): Describe the scene and desired motion. Length: **1-5,000 characters**. The value must not be blank when supplied.
- `image_urls` (string[]): Provide publicly accessible image URLs. Supply exactly 1 item. Each item must be an HTTP(S) URL. The playground accepts JPG, PNG, and WebP uploads up to 10 MiB.

## Optional parameters

- `duration` (integer): 5, 10, 15 seconds. Optional. Default: 5 seconds.
- `resolution` (string): Accepted values: `720p`, `1080p`. Default: `720p`.
- `multi_shots` (boolean): Enable multi-shot generation. Use `true` or `false`.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before task creation. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

Create five- or ten-second scenes with Kling 2.5 Turbo Pro, using text to direct subjects, action, and visual style.

## Models

- **kwaivgi/kling-v2.5-turbo-pro/text-to-video** — Generate video scenes from text prompts.
- For frame guidance, use the [image-to-video endpoint](/api-manual/video-series/kwaivgi-kling-v2-5-turbo-pro-image-to-video).

## Features

- Generate video scenes from text prompts.
- Use `negative_prompt` to describe content to avoid.

## Required parameters

- `prompt` (string): Describe the scene and desired motion. Length: **1-2,500 characters**. Supply a string, not a number, boolean, array, or object. Whitespace is trimmed before the 2,500 Unicode character limit is checked.

## Optional parameters

- `duration` (integer): 5, 10 seconds. Optional. Default: 5 seconds. Strings, booleans, fractional durations, and `null` are rejected.
- `aspect_ratio` (string): No preset choices or default value are specified. Omit when unused.
- `negative_prompt` (string): Describe content to avoid.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before task creation.

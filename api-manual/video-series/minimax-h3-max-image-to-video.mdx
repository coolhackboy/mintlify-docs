Animate a starting frame with an optional ending frame.

## Models

- **minimax/h3-max/image-to-video** — Animate a starting frame with an optional ending frame.

## Required parameters

- `prompt` (string): Non-empty prompt describing the target video. Must contain at least one non-whitespace character. Length: 1–50,000 characters.
- `image_urls` (array of strings): Starting frame followed by an optional ending frame. Public HTTP(S) URLs only. 1–2 items.

## Optional parameters

- `duration` (integer): Requested output duration in seconds. Range: 5–15. Default: `5`.
- `resolution` (string): Output resolution. Values: `480p`, `768p`, `1080p`. Default: `768p`.
- `enable_safety_checker` (boolean): Set false to disable the safety checker. Default: `true`.

## Notes

- Supply `image_urls` in starting-frame, optional ending-frame order. The output follows the starting image; omit `aspect_ratio`.
- Use public HTTP(S) download URLs. Base64 is not supported.
- Use an integer for `duration`; fractional durations are rejected.

Create video scenes with Wan 3.0 Prime, with optional audio and output up to thirty seconds for longer visual sequences.

## Models

- **alibaba/wan-3.0-prime/text-to-video** — Generate video scenes from text prompts.

## Features

- Generate video scenes from text prompts.
- Choose from `480p`, `720p`, `1080p` output resolutions.
- Control audio generation with `audio`; it defaults to `true`.

## Required parameters

- `prompt` (string): Describe the scene and desired motion. The prompt must not be blank when supplied. Maximum length: **20,000 characters**.

## Optional parameters

- `resolution` (string): `480p`, `720p`, `1080p`. Default: `720p`.
- `aspect_ratio` (string): `adaptive`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`. Default: `adaptive`.
- `duration` (integer): 2-30 seconds. Default: 5 seconds.
- `audio` (boolean): Set to `true` to enable generated audio, or `false` to disable it. Default: `true`.
- `seed` (integer): Supply an integer from `0` to `2147483647`.
- `enable_safety_checker` (boolean): Set it to `true` or `false` to control safety checking. Default: `true`.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before task creation.

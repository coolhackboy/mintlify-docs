Animate a reference image with Sora 2 Pro, with control over framing, duration, and output resolution for scene development.

## Models

- **openai/sora-2-pro/image-to-video** — Generate video from image input.

## Features

- Animate a single reference image.
- Choose from `720p`, `1024p`, `1080p` output resolutions.

## Required parameters

- `prompt` (string): Describe the scene and desired motion. Length: at least 1 characters.
- `image_urls` (array of strings): Provide publicly accessible reference images. Exactly 1 item.

## Optional parameters

- `aspect_ratio` (string): Aspect ratio. Values: `auto`, `9:16`, `16:9`. Default: `16:9`.
- `duration` (integer): Duration. Values: `4`, `8`, `12`, `16`, `20`. Default: `4`.
- `resolution` (string): Resolution. Values: `720p`, `1024p`, `1080p`. Default: `1024p`.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

- The prompt must not be blank when supplied.

- Images must be publicly accessible and directly downloadable.

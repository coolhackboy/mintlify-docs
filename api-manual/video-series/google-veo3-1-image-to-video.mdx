Generate motion from an image or connect opening and closing frames with Veo 3.1, with optional sound and output up to 4K.

## Models

- **google/veo3.1/image-to-video** — Generate video from image input.

## Features

- Generate motion from one starting image, or connect two images as the first and last frames.
- Choose from `720p`, `1080p`, `4k` output resolutions.
- Control audio generation with `sound`; it defaults to `true`.

## Required parameters

- `prompt` (string): Describe the scene and desired motion. The prompt must not be blank when supplied.
- `image_urls` (string[]): Provide 1-2 image URLs. One image is used as the starting frame. With two images, list the starting frame first and the ending frame second. Images must be publicly accessible and directly downloadable.

## Optional parameters

- `generation_type` (string): Omit with one image. With two images, defaults to frame; explicitly specifying frame requires exactly two images.
- `duration` (integer): 4, 6, 8 seconds. Default: 8 seconds.
- `aspect_ratio` (string): `auto`, `16:9`, `9:16`. Default: `16:9`.
- `resolution` (string): `720p`, `1080p`, `4k`. Default: `720p`.
- `sound` (boolean): Set to `true` to enable generated audio, or `false` to disable it. Default: `true`.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before task creation. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

- Omit `generation_type` when supplying one image.
- With two images, `generation_type` defaults to `frame`.
- If you explicitly set `generation_type: "frame"`, exactly two images are required.

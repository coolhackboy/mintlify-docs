Generate short video scenes with Hailuo 2.3 Standard, with 768p output and optional prompt refinement for written scene concepts.

## Models

- **minimax/hailuo-2.3/standard/text-to-video** — Generate video scenes from text prompts.

## Features

- Generate video scenes from text prompts.
- This model ID fixes the output resolution to `768p`.

## Required parameters

- `prompt` (string): Required nonblank string, trimmed before validation. Maximum 5,000 Unicode characters.

## Optional parameters

- `duration` (integer): Output duration in seconds. 6 or 10; defaults to 6. Values: `6`, `10`.
- `resolution` (string): Fixed to 768p for this endpoint. Values: `768p`. Default: `768p`.
- `prompt_optimizer` (boolean): Optional boolean with no specified default. Omit when unused.

## Notes

Send only the input fields supported by this workflow. JSON types are validated without converting strings to numbers or booleans; `prompt` must be a string and fractional durations are rejected. Unsupported `input` fields are rejected.

- The value must not be blank when supplied.

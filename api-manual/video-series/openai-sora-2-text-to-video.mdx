Turn written scene descriptions into videos with Sora 2, with portrait and landscape framing for clips up to twenty seconds long.

## Models

- **openai/sora-2/text-to-video** — Generate video scenes from text prompts.

## Features

- Generate video scenes from text prompts.
- Supports landscape (`16:9`) and portrait (`9:16`) framing.

## Required parameters

- `prompt` (string): Describe the scene and desired motion. Length: at least 1 characters.

## Optional parameters

- `duration` (integer): Duration. Values: `4`, `8`, `12`, `16`, `20`. Default: `4`.
- `aspect_ratio` (string): Aspect ratio. Values: `16:9`, `9:16`. Default: `16:9`.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected.

- The prompt must not be blank when supplied.

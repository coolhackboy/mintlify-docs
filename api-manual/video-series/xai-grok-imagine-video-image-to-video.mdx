Animate a still image with Grok Imagine, using text to shape the scene in six- or ten-second video clips.

## Models

- **xai/grok-imagine-video/image-to-video** - Generate video from image input.

## Features

- Generate video from image input.
- Accepts exactly 1 image in `image_urls`.

## Duration Options

- **6, 10 seconds** - Set `duration` as an integer. Optional; defaults to `6`.

## Advanced Parameters

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Use the input fields listed below. Supply publicly accessible HTTP(S) URLs for reference images.

### Prompt

- `prompt`: Required. Describe the scene and desired motion. Length: **1-5,000 characters**.

### Image URLs

- `image_urls`: Required. Provide publicly accessible image URLs. Supply exactly 1 item. Each item must be an HTTP(S) URL.

### Mode

- `mode`: Optional. Accepted values: `fun`, `normal`, `spicy`.

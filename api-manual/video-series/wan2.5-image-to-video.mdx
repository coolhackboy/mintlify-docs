`wan2.5-image-to-video` is a higher-quality single-image animation model with broader resolution support than the Wan 2.2 fast line.

## Models

- **wan2.5-image-to-video** — Animate a single image into a video clip

## Required parameters

- `prompt` (string): Text prompt for the motion and scene.
- `image_urls` (array of strings): Reference image URLs for image-to-video. Only 1 image is supported.

## Optional parameters

- `resolution` (string): Output video resolution. Values: `480p`, `720p`, `1080p`. Default: `720p`.
- `duration` (integer): Video duration in seconds. Values: `5`, `10`. Default: `5`.
- `audio` (string): Optional audio setting string.
- `negative_prompt` (string): Optional negative prompt.
- `seed` (integer): Optional random seed for reproducibility.

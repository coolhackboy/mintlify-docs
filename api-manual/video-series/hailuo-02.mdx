Generate high-quality videos using Hailuo 02 models. Create professional content with text-to-video and image-to-video capabilities.

## Models

- **hailuo-02** — Standard video generation (768P/512P, up to 10 seconds)
- **hailuo-02-pro** — Professional video generation (1080P, 6 seconds)

## Features

- **Flexible Modes**: Text-to-video and image-to-video
- **Multiple Resolutions**: 512P, 768P (Standard) and 1080P (Pro)
- **Duration Options**: 6 or 10 seconds (Standard only)
- **Prompt Optimizer**: Optional AI-powered prompt enhancement
- **End Frame Control**: Specify ending frame for image-to-video (optional)

## Input modes

- **Text to video:** omit image fields.
- **Image to video:** supply `image_urls` as the starting image.
- **First and last frames:** provide `end_image_url` together with `image_urls`.

## Required parameters

- `prompt` (string): Generation prompt describing the desired video. Maximum length: 1,500 characters.

## Optional parameters

- `image_urls` (string[]): Reference image URLs for image-to-video generation (required for image-to-video). Maximum items: 1.
- `end_image_url` (string): URL of the image to use as the last frame (image-to-video only).
- `duration` (integer): Video duration in seconds (hailuo-02 only). Accepted values: `6`, `10`.
- `resolution` (string): Output resolution (hailuo-02 image-to-video only). Accepted values: `512P`, `768P`.
- `prompt_optimizer` (boolean): Enable AI-powered prompt optimization.

1. After submission, a `task_id` will be returned. If you provided a `callback_url`, when the task status becomes `finished` or `failed`, a POST request will be sent to the `callback_url`.
2. Regardless of whether `callback_url` is provided, you can retrieve the response result through the unified [Query Task Status](/api-manual/task-management/status) endpoint.

Submit `kwaivgi/kling-v2.6-pro/image-to-video` through `POST /api/generate/submit`. Query the returned `task_id` with [Task Status](/api-manual/task-management/status), or provide a top-level `callback_url`.

## Models

- **kwaivgi/kling-v2.6-pro/image-to-video** — Kling 2.6 Pro video generation

## Required parameters

- `prompt` (string): Nonblank string, 1 to 1,000 characters after trimming leading and trailing whitespace.
- `image_urls` (string[]): Containing at least one publicly accessible HTTP(S) image URL. URLs must not contain embedded credentials or whitespace. Minimum items: 1.
- `sound` (boolean): True for audio, false for no audio. Must be false when end_image_url is provided.
- `aspect_ratio` (string): 16:9, 9:16 or 1:1. This field must be submitted but does not control the output aspect ratio for image-to-video.
- `duration` (integer): 5 or 10 seconds. Strings and fractional durations are rejected.

## Optional parameters

- `end_image_url` (string): Publicly accessible HTTP(S) last-frame image URL, without embedded credentials or whitespace. Omit this field when not using a last frame; empty strings and null are not accepted. Requires sound=false.

## Notes

Use standard JSON types. Unknown input fields and invalid values are rejected before task creation. URLs using `example.com` or `your-domain.com` are placeholders. Replace them with your own publicly accessible image URLs and callback endpoint where applicable.

Generate motion from an image or connect opening and closing frames with Veo 3.1 Lite, with optional sound and output up to 1080p.

## Models

- **google/veo3.1-lite/image-to-video** - Generate video from image input.

## Features

- Generate motion from one starting image, or connect two images as the first and last frames.
- Choose from `720p`, `1080p` output resolutions.
- Control audio generation with `sound`; it defaults to `true`.

## Duration Options

- **4, 6, 8 seconds** - Set `duration` to one of these values. Default: **8 seconds**.
- Set `duration: 8` when using `1080p` output or two input images.

## Advanced Parameters

Set `model` and optional `callback_url` at the request root. Place the parameters below inside `input`.

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before credits are deducted. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

### Prompt

- `prompt`: Required. Describe the scene and desired motion.
- The prompt must not be blank when supplied.

### Image URLs

- `image_urls`: Required. Provide 1-2 image URLs.
- One image is used as the starting frame.
- With two images, list the starting frame first and the ending frame second.
- Images must be publicly accessible and directly downloadable.

### Generation Type

- Omit `generation_type` when supplying one image.
- With two images, `generation_type` defaults to `frame`.
- If you explicitly set `generation_type: "frame"`, exactly two images are required.

### Resolution

- `resolution`: `720p`, `1080p`. Default: `720p`.
- `1080p` requires `duration: 8`.

### Aspect Ratio

- `aspect_ratio`: `auto`, `16:9`, `9:16`. Default: `16:9`.

### Audio

- `sound`: Set to `true` to enable generated audio, or `false` to disable it. Default: `true`.

## Pricing

Credits are deducted on submission and refunded if the task fails.

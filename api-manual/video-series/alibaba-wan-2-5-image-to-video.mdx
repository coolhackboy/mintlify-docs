Animate one reference image into a 5 or 10 second video with synchronized audio and output up to 1080p.

## Models

- `alibaba/wan-2.5/image-to-video`: Animate a reference image using a motion prompt.

## Request Parameters

Set `model` and optional `callback_url` at the request root. Place the following generation parameters inside `input`.

### prompt

- `prompt` (string, required): Describe the subject, scene, and motion. Use 1–1500 characters after trimming surrounding whitespace.

### image_urls

- `image_urls` (string[], required): Provide exactly one publicly accessible HTTP(S) image URL.

### resolution

- `resolution` (string, optional): Output resolution: 480p, 720p, or 1080p. Default: 720p.

### duration

- `duration` (integer, optional): Video duration: 5 or 10 seconds. Default: 5.

### audio

- `audio` (string, optional): Optional audio file URL to supply a recording for the video.

### negative_prompt

- `negative_prompt` (string, optional): Optional description of elements to exclude from the scene.

### seed

- `seed` (integer, optional): Optional integer random seed for reusing generation settings.

## Retrieve the Video

Query the task with `task_id`. Continue polling while `status` is `not_started` or `running`. At `finished`, read the video URL from `data.files[].file_url`. At `failed`, read `data.error_message` for the error details.

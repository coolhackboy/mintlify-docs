Kling 2.1 Pro image-to-video with a required start frame and an optional end frame.

## Models

- **kwaivgi/kling-video/v2.1/pro/image-to-video** — Generate video from image input.

## Features

- Generate video from image input.
- Use `start_image_url` to supply the starting frame.
- Optionally supply an ending frame with `end_image_url`.

## Required parameters

- `prompt` (string): Describe the scene and desired motion. Length: **1-5,000 characters**. The value must be a string and must not be blank after trimming. Non-string values are rejected.
- `start_image_url` (string): Provide the starting frame URL. Use a publicly accessible HTTP(S) URL without credentials or whitespace. Empty URLs and null are rejected.

## Optional parameters

- `duration` (integer): 5, 10 seconds. Optional. Default: 5 seconds when omitted. Strings, booleans, null and fractional values are rejected.
- `end_image_url` (string): Provide the ending frame URL. Use a publicly accessible HTTP(S) URL without credentials or whitespace. Empty URLs and null are rejected.
- `negative_prompt` (string): Describe content to avoid.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before task creation. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

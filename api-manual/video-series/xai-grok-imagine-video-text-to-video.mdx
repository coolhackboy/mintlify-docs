Create six- or ten-second video scenes with Grok Imagine, using text to guide the action in square, portrait, or landscape formats.

## Models

- **xai/grok-imagine-video/text-to-video** - Generate video scenes from text prompts.

## Features

- Generate video scenes from text prompts.

## Duration Options

- **6, 10 seconds** - Set `duration` as an integer. Optional; defaults to `6`.

## Advanced Parameters

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Use the input fields listed below.

### Prompt

- `prompt`: Required. Describe the scene and desired motion. Length: **1-5,000 characters**.

### Aspect Ratio

- `aspect_ratio`: Optional. Accepted values: `1:1`, `2:3`, `3:2`, `16:9`, `9:16`.

### Mode

- `mode`: Optional. Accepted values: `fun`, `normal`, `spicy`.

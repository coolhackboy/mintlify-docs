Use reference images to shape new Happy Horse video scenes, combining visual direction with a written description at up to 1080p.

## Models

- **alibaba/happyhorse-1.0/reference-to-video** — Generate a new video guided by reference material and a prompt.

## Features

- Guide video generation with one to nine reference images.
- Choose from `720p`, `1080p` output resolutions.

## Required parameters

- `prompt` (string): Describe the scene and desired motion. The prompt must not be blank when supplied. Maximum length: **5,000 characters**.
- `reference_image_urls` (string[]): Provide up to 9 images. Describe referenced subjects in the prompt; `character1` and `character2` markers are not required. Minimum items: 1. Maximum items: 9.

## Optional parameters

- `aspect_ratio` (string): `16:9`, `9:16`, `1:1`, `4:3`, `3:4`. Default: `16:9`.
- `resolution` (string): `720p`, `1080p`. Default: `1080p`.
- `duration` (integer): 3-15 seconds. Default: 5 seconds.
- `seed` (integer): Supply an integer from `0` to `2147483647`.
- `enable_safety_checker` (boolean): Set it to `true` or `false` to control safety checking.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before task creation. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

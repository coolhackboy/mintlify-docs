MiniMax H3 image to video model with fixed 2K output

## Models

- **minimax/h3/image-to-video** — MiniMax H3 image to video generation with 2K output

## Features

- **Image To Video**: Generate from one starting frame and an optional ending frame.
- **2K Output**: Output resolution is fixed at `2K`.

## Required parameters

- `prompt` (string): Prompt describing the target video. Length: 1–2,000 characters.
- `image_urls` (array of strings): Starting frame and optional ending frame. 1–2 items.

## Optional parameters

- `duration` (integer): Output duration in seconds. Range: 5–15. Default: `5`.
- `resolution` (string): Output resolution is fixed at 2K. Values: `2K`. Default: `2K`.

## Notes

- `image_urls` is required.
- All media URLs must be publicly accessible and directly downloadable.

- The output aspect ratio follows the first image.
- `image_urls` accepts one starting frame and one optional ending frame.

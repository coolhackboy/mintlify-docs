Create short scenes from text with Hailuo 02 Standard, with optional prompt refinement to develop the visual direction of a clip.

## Models

- **minimax/hailuo-02/standard/text-to-video** — Generate video scenes from text prompts.

## Features

- Generate video scenes from text prompts.
- Accepts `512P` or `768P` resolution; defaults to `768P`.

## Required parameters

- `prompt` (string): Required nonblank prompt, trimmed before validation. Maximum 1500 Unicode characters.

## Optional parameters

- `duration` (integer): Video duration in seconds. Defaults to `6`. Values: `6`, `10`.
- `resolution` (string): Output resolution. Defaults to `768P`. Values: `512P`, `768P`.
- `prompt_optimizer` (boolean): Enable AI-powered prompt optimization.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected.

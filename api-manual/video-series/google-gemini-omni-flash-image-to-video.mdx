Animate a still image with Gemini Omni Flash, using text direction to develop a short video scene at up to 4K.

## Models

- **google/gemini-omni-flash/image-to-video** — Generate video from image input.

## Features

- Animate a single reference image.
- Choose from `720p`, `1080p`, `4k` output resolutions.
- Supports landscape (`16:9`) and portrait (`9:16`) framing.

## Required parameters

- `prompt` (string): Describe the scene and desired motion. The prompt must not be blank when supplied. Maximum length: **20,000 characters**.
- `image_urls` (string[]): Provide exactly 1 image URL. Images must be publicly accessible and directly downloadable.

## Optional parameters

- `resolution` (string): `720p`, `1080p`, `4k`. Default: `720p`.
- `duration` (integer): 4, 6, 8, 10 seconds. Default: 6 seconds.
- `aspect_ratio` (string): `16:9`, `9:16`. Default: `16:9`.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before task creation. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

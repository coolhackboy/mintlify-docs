`happy-horse` supports text-to-video, image-to-video, reference-to-video, and video-edit through one public model ID.

## Models

- **happy-horse** — Alibaba Happy Horse 1.0 video generation and editing

## Input modes

### Text to Video

Send a `prompt` without image or video input fields. Use `aspect_ratio`, `resolution`, and `duration` to control the output.

### Image to Video

Send a single-item `image_urls` array. The image is used as the first frame. A nonblank `prompt` of at most 5,000 characters is required.

### Reference to Video

Send `reference_image_urls` with 1-9 images and a required `prompt`. Reference the images in prompt text as `character1`, `character2`, and so on, matching the order of `reference_image_urls`.

Do not combine `reference_image_urls` with `image_urls`.

### Video Edit

Send `video_url` with a required edit `prompt`. Optional `reference_image_urls` can guide the edit; refer to them as `@Image1`, `@Image2`, and so on. `audio_setting` controls whether Happy Horse decides audio handling automatically or preserves the original audio.

The source video must be 3-60 seconds.

## Required parameters

- `prompt` (string): Required for text-to-video, image-to-video, and reference-to-video (maximum 5,000 characters). Required for video-edit (maximum 2,500 characters). Minimum length: 1 character.

## Optional parameters

- `image_urls` (string[]): Single-item first-frame image URL array for image-to-video. Maximum items: 1.
- `reference_image_urls` (string[]): Required for reference-to-video. 1-9 images for reference-to-video, or up to 5 optional images for video-edit.
- `video_url` (string): Required for video-edit.
- `aspect_ratio` (string): Text-to-video and reference-to-video only. `16:9`, `9:16`, `1:1`, `4:3`, or `3:4`. Default is `16:9`.
- `resolution` (string): `720p` or `1080p`. Default is `1080p`.
- `duration` (integer): Integer seconds from `3` to `15` for text-to-video, image-to-video, and reference-to-video. Ignored for video-edit. Default: `5`.
- `audio_setting` (string): Video-edit only. `auto` or `origin`. Default is `auto`.
- `seed` (integer): From `0` to `2147483647`.
- `enable_safety_checker` (boolean): Control safety checking.

## Notes

- `image_urls` must resolve to exactly one image and is only for image-to-video.
- `reference_image_urls` selects reference-to-video unless `video_url` is present, in which case it is treated as optional video-edit reference imagery.
- For text-to-video and reference-to-video, omit `video_url` and use `aspect_ratio`.
- For video-edit, omit `duration`; the source video duration is used for validation.

Animate starting and ending frames or combine character references with Kling 1.6 Pro.

## Models

- **kwaivgi/kling-video/v1.6/pro/image-to-video** — Kling 1.6 Pro video generation

## Input modes

Provide **either** `start_image_url` for first-frame animation **or** `image_urls` for Elements. The endpoint does not accept text-only requests.

- Elements accepts 1–4 reference images and cannot be combined with `start_image_url`, `end_image_url`, or `cfg_scale`.
- Pro supports an optional `end_image_url` when `start_image_url` is present; aspect ratio is supported in both workflows.

The image fields select the workflow.

## Required parameters

- `prompt` (string): Nonblank string, at most 2,500 Unicode characters after trimming.
- `duration` (integer): 5 or 10 seconds. No API default.

## Optional parameters

- `aspect_ratio` (string): 1:1, 16:9 or 9:16. No API default.
- `negative_prompt` (string): At most 2,500 Unicode characters.
- `cfg_scale` (number): Finite number from 0 to 1. Not supported with image_urls. No API default.
- `start_image_url` (string): First-frame HTTP(S) URL. Required for the first-frame workflow; mutually exclusive with image_urls.
- `end_image_url` (string): Pro last-frame HTTP(S) URL. Requires start_image_url; not supported with image_urls.
- `image_urls` (string[]): Elements: 1 to 4 HTTP(S) reference URLs. Mutually exclusive with start_image_url, end_image_url and cfg_scale.

## Notes

Image URLs must be public HTTP(S) URLs with a hostname, without embedded credentials or whitespace. Local files can be uploaded in the playground before submitting their URL. Optional parameters have no documented API defaults.

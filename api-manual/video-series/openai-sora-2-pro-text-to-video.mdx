Create video scenes with Sora 2 Pro, with a choice of output resolutions and clips up to twenty seconds long.

## Models

- **openai/sora-2-pro/text-to-video** — Generate video scenes from text prompts.

## Features

- Generate video scenes from text prompts.
- Choose from `720p`, `1024p`, `1080p` output resolutions.

## Required parameters

- `prompt` (string): Describe the scene and desired motion. Length: at least 1 characters.

## Optional parameters

- `aspect_ratio` (string): Aspect ratio. Values: `auto`, `9:16`, `16:9`. Default: `16:9`.
- `duration` (integer): Duration. Values: `4`, `8`, `12`, `16`, `20`. Default: `4`.
- `resolution` (string): Resolution. Values: `720p`, `1024p`, `1080p`. Default: `1024p`.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected.

- The prompt must not be blank when supplied.

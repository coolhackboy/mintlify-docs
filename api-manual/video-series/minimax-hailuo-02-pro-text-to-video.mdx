Create short scenes from text with Hailuo 02 Pro, with optional prompt refinement to develop the visual direction of a clip.

## Models

- **minimax/hailuo-02/pro/text-to-video** - Generate video scenes from text prompts.

## Features

- Generate video scenes from text prompts.

## Output Options

- `resolution`: Optional. Accepted values: `512P`, `768P`. Default: `768P`.

## Advanced Parameters

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before credits are deducted.

### Prompt

- `prompt`: Required. Describe the scene and desired motion. No maximum prompt length is specified.
- Whitespace is trimmed before validation; the result must not be blank.

### Prompt Optimizer

- `prompt_optimizer`: Optional. Control automatic prompt optimization. Use `true` or `false`.

## Billing Factors

Billed per generation using the Pro model tier. Both supported resolutions use the same rate.

Credits are deducted on submission and refunded if the task fails.

Create short scenes from text with Hailuo 02 Pro, with optional prompt refinement to develop the visual direction of a clip.

## Models

- **minimax/hailuo-02/pro/text-to-video** — Generate video scenes from text prompts.

## Features

- Generate video scenes from text prompts.

## Required parameters

- `prompt` (string): Required nonblank prompt, trimmed before validation. No maximum prompt length is specified.

## Optional parameters

- `prompt_optimizer` (boolean): Enable AI-powered prompt optimization.
- `resolution` (string): Output resolution. Defaults to `768P`. Values: `512P`, `768P`.

## Notes

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected.

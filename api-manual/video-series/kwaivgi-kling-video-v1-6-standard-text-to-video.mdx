Generate videos from a scene and motion prompt with Kling 1.6 Standard.

## Models

- **kwaivgi/kling-video/v1.6/standard/text-to-video** — Kling 1.6 Standard video generation

## Required parameters

- `prompt` (string): Nonblank string, at most 2,500 Unicode characters after trimming.
- `duration` (integer): 5 or 10 seconds. No API default.

## Optional parameters

- `aspect_ratio` (string): 1:1, 16:9 or 9:16. No API default.
- `negative_prompt` (string): At most 2,500 Unicode characters.
- `cfg_scale` (number): Finite number from 0 to 1. No API default.

## Notes

### Input requirements

This endpoint generates videos from text prompts.

### Input requirements

Optional parameters have no documented API defaults.

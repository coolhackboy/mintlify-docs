Animate reference images with Seedance 1.5 Pro, with optional generated audio and fixed-camera control at up to 1080p.

## Models

- **bytedance/seedance-v1.5-pro/image-to-video** — Generate video from image input.

## Features

- Generate video from image input.
- Accepts 1-2 images in `image_urls`.
- Choose from `480p`, `720p`, `1080p` output resolutions.

## Required parameters

- `prompt` (string): Describe the scene and desired motion. Length: **3-2,500 characters**. Surrounding whitespace is trimmed before counting Unicode characters. Minimum length: 3 characters.
- `image_urls` (string[]): Supply 1–2 publicly accessible HTTP(S) image URLs. The first image is the first frame; the optional second image is the last frame. Use JPEG, PNG or WebP images, up to **10 MB per image**.
- `aspect_ratio` (string): Accepted values: `1:1`, `21:9`, `4:3`, `3:4`, `16:9`, `9:16`.
- `duration` (integer): 4, 8, 12 seconds. Required.

## Optional parameters

- `resolution` (string): Accepted values: `480p`, `720p`, `1080p`. Vidgo defaults to `720p` when omitted.
- `fixed_lens` (boolean): Control fixed-camera generation. Use `true` or `false`.
- `generate_audio` (boolean): Set `true` to generate synchronized audio or `false` for a silent video. Vidgo defaults to `true` when omitted.

Animate reference images with Seedance 1.5 Pro, with optional generated audio and fixed-camera control at up to 1080p.

## Models

- **bytedance/seedance-v1.5-pro/image-to-video** - Generate video from image input.

## Features

- Generate video from image input.
- Accepts 1-2 images in `image_urls`.
- Choose from `480p`, `720p`, `1080p` output resolutions.

## Duration Options

- **4, 8, 12 seconds** - Set `duration` as an integer. Required.

## Advanced Parameters

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

### Prompt

- `prompt`: Required. Describe the scene and desired motion. Length: **3-2,500 characters**.
- Surrounding whitespace is trimmed before counting Unicode characters.

### Image URLs

- `image_urls`: Required. Supply 1–2 publicly accessible HTTP(S) image URLs. The first image is the first frame; the optional second image is the last frame.
- Use JPEG, PNG or WebP images, up to **10 MB per image**.

### Aspect Ratio

- `aspect_ratio`: Required. Accepted values: `1:1`, `21:9`, `4:3`, `3:4`, `16:9`, `9:16`.

### Resolution

- `resolution`: Optional. Accepted values: `480p`, `720p`, `1080p`. Vidgo defaults to `720p` when omitted.

### Fixed Lens

- `fixed_lens`: Optional. Control fixed-camera generation. Use `true` or `false`.

### Generate Audio

- `generate_audio`: Optional. Set `true` to generate synchronized audio or `false` for a silent video. Vidgo defaults to `true` when omitted.

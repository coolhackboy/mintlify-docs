# Meshy 6 Text to 3D

Build 3D assets from text with Meshy 6, with mesh topology, material, and texture controls plus optional rigging and animation.

## Available Models

- **meshy/v6/text-to-3d** - Generate a 3D model from a text prompt.

## Output Options

### Mode

- `mode`: Optional. Accepted values: `preview`, `full`. Default: `full`.

### Target Polycount

- `target_polycount`: Optional. Set the target polygon count. Integer, at least `1`. Default: `30000`.

### Topology

- `topology`: Optional. Select the mesh topology. Accepted values: `quad`, `triangle`. Default: `triangle`.

## Key Features

- Generate a 3D model from a text prompt.
- Retrieve model assets and available previews or supporting files from the task result.
- Optionally add textures, rigging, and animation.

## Advanced Parameters

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before credits are deducted. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

- `enable_animation: true` requires `enable_rigging: true`.
- `texture_prompt` and `texture_image_url` are mutually exclusive.

### Prompt

- `prompt`: Required. Describe the desired 3D object. Length: **1-600 characters**.
- The value must not be blank when supplied.

### Seed

- `seed`: Optional. Set the generation seed. Integer.

### Remeshing

- `should_remesh`: Optional. Control remeshing. Use `true` or `false`. Default: `true`.

### Symmetry Mode

- `symmetry_mode`: Optional. Select how symmetry is handled. Accepted values: `off`, `auto`, `on`. Default: `auto`.

### PBR

- `enable_pbr`: Optional. Control physically based rendering (PBR) materials. Use `true` or `false`.

### Pose Mode

- `pose_mode`: Optional. Select a pose, or send an empty string for no pose selection. Accepted values: `a-pose`, `t-pose`, `""`. Default: `""`.

### Enable Prompt Expansion

- `enable_prompt_expansion`: Optional. Control automatic prompt expansion. Use `true` or `false`.

### Texture Prompt

- `texture_prompt`: Optional. Describe the desired texture; do not combine with `texture_image_url`.

### Texture Image URL

- `texture_image_url`: Optional. Provide a texture reference URL; do not combine with `texture_prompt`. Use a publicly accessible HTTP(S) URL.

### Rigging

- `enable_rigging`: Optional. Request rigging for the generated model. Use `true` or `false`.

### Rigging Height

- `rigging_height_meters`: Optional. Set the rigging height in meters. Number. Default: `1.7`.

### Animation

- `enable_animation`: Optional. Request animation; rigging must also be enabled. Use `true` or `false`.

### Animation Action ID

- `animation_action_id`: Optional. Select the animation action. Integer. Default: `1001`.

### Safety Checker

- `enable_safety_checker`: Optional. Control safety checking. Use `true` or `false`. Default: `true`.

## Output Files

- Read every item in the returned `files` array.
- Model assets use `file_type: "3d"`; previews use `file_type: "image"`.
- Additional artifacts may use `file_type: "other"`. Retain available textures, animation artifacts, and optional file metadata.

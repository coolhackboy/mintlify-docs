# Hunyuan 3D v3.1 Pro Text to 3D

Generate 3D objects from text with Hunyuan 3D v3.1 Pro, with control over mesh complexity and geometry-only output.

## Available Models

- **hunyuan-3d/v3.1/pro/text-to-3d** - Generate a 3D model from a text prompt.

## Output Options

### Generate Type

- `generate_type`: Optional. Accepted values: `Normal`, `Geometry`.

### Face Count

- `face_count`: Optional. Set the target face count. Integer from `40000` to `1500000`. Default: `500000`.

## Key Features

- Generate a 3D model from a text prompt.
- Retrieve model assets and available previews or supporting files from the task result.

## Advanced Parameters

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before credits are deducted. Input URLs must use HTTP(S), include a hostname, and contain no embedded credentials.

- PBR is not available for this text-to-3D workflow.

### Prompt

- `prompt`: Required. Describe the desired 3D object. Length: **1-1,024 characters**.
- The value must not be blank when supplied.

## Output Files

- Read every item in the returned `files` array.
- Model assets use `file_type: "3d"`; previews use `file_type: "image"`.
- Additional artifacts may use `file_type: "other"`. Retain available textures, animation artifacts, and optional file metadata.

## Pricing

A custom `face_count` can affect usage.

Check the Vidgo dashboard for the current rate.

Credits are deducted on submission and refunded if the task fails.

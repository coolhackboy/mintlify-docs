Build a 3D asset from up to four reference images with Meshy 6, with texture, topology, and optional animation controls.

## Models

- **meshy/v6/multi-image-to-3d** — Generate a 3D model from multiple image references.

## Features

- Generate a 3D model from multiple image references.
- Accepts 1-4 images in `image_urls`.
- Retrieve model assets and available previews or supporting files from the task result.
- Optionally add textures, rigging, and animation.

## Required parameters

- `image_urls` (array): Provide publicly accessible image URLs. Supply 1-4 items. Each item must be an HTTP(S) URL.

## Optional parameters

- `should_remesh` (boolean): Control remeshing. Use `true` or `false`. Default: `true`.

- `symmetry_mode` (string): Select how symmetry is handled. Accepted values: `off`, `auto`, `on`. Default: `auto`.

- `should_texture` (boolean): Control texture generation. Use `true` or `false`. Default: `true`.

- `enable_pbr` (boolean): Control physically based rendering (PBR) materials. Use `true` or `false`.

- `pose_mode` (string): Select a pose, or send an empty string for no pose selection. Accepted values: `a-pose`, `t-pose`, `""`. Default: `""`.

- `texture_prompt` (string): Describe the desired texture.

- `texture_image_url` (string): Provide a texture reference URL. Use a publicly accessible HTTP(S) URL.

- `enable_rigging` (boolean): Request rigging for the generated model. Use `true` or `false`.

- `rigging_height_meters` (number): Set the rigging height in meters. Number. Default: `1.7`.

- `enable_animation` (boolean): Request animation; rigging must also be enabled. Use `true` or `false`.

- `animation_action_id` (integer): Select the animation action. Integer. Default: `1001`.

- `enable_safety_checker` (boolean): Control safety checking. Use `true` or `false`. Default: `true`.

- `target_polycount` (integer): Set the target polygon count. Integer. Default: `30000`.

- `topology` (string): Select the mesh topology. Accepted values: `quad`, `triangle`. Default: `triangle`.

## Output

- Read every item in the returned `files` array.
- Model assets use `file_type: "3d"`; previews use `file_type: "image"`.
- Read supporting files with `file_type: "other"` alongside the returned textures, animation assets, and file metadata.

## Notes

Use publicly accessible HTTP(S) URLs for images and texture references.

- `enable_animation: true` requires `enable_rigging: true`.

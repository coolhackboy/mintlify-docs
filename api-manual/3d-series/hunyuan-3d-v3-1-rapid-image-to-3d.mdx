Create a 3D model from a reference image with Hunyuan 3D v3.1 Rapid, with optional text guidance and geometry generation.

## Models

- **hunyuan-3d/v3.1/rapid/image-to-3d** — Generate a 3D model from an image.

## Features

- Generate a 3D model from an image.
- Accepts exactly 1 image in `image_urls`.
- Retrieve model assets and available previews or supporting files from the task result.

## Required parameters

- `image_urls` (array): Provide publicly accessible image URLs. Supply exactly 1 item. Each item must be an HTTP(S) URL.

## Optional parameters

- `prompt` (string): Describe the desired 3D object. Minimum length: **1 character**.
Use a nonblank string when providing this parameter.

- `enable_pbr` (boolean): Set `true` to generate PBR materials in textured mode. Geometry-only generation takes precedence over this setting.

- `enable_geometry` (boolean): Set `true` for a geometry-only white model or `false` for textured generation.

## Output

- Read every item in the returned `files` array.
- Model assets use `file_type: "3d"`; previews use `file_type: "image"`.
- Additional artifacts may use `file_type: "other"`. Retain returned textures, material files, and file metadata.

## Notes

Provide publicly accessible HTTP(S) URLs for image inputs.

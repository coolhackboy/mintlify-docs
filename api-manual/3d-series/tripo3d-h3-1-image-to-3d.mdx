Convert a reference image into a 3D model with Tripo3D H3.1, with controls for geometry detail, textures, and mesh topology.

## Models

- **tripo3d/h3.1/image-to-3d** — Generate a 3D model from an image.

## Features

- Generate a 3D model from an image.
- Accepts exactly 1 image in `image_urls`.
- Retrieve model assets and available previews or supporting files from the task result.

## Required parameters

- `image_urls` (array): Provide publicly accessible image URLs. Supply exactly 1 item. Each item must be an HTTP(S) URL.

## Optional parameters

- `texture` (boolean): Control texture generation. Use `true` or `false`. Default: `true`.

- `pbr` (boolean): Generate physically based rendering (PBR) materials when `texture` is `true`. Use `true` or `false`.

- `model_seed` (integer): Set the model-generation seed. Integer.

- `texture_seed` (integer): Set the texture-generation seed. Integer.

- `texture_quality` (string): Accepted values: `standard`, `detailed`. Default: `standard`.

- `auto_size` (boolean): Control automatic model sizing. Use `true` or `false`.

- `quad` (boolean): Request quad topology. Use `true` or `false`. Default: `false`.

- `face_limit` (integer): Set the face-count limit. Integer from `1000` to `2000000`.

- `geometry_quality` (string): Accepted values: `standard`, `detailed`. Default: `standard`.

## Output

- Read every item in the returned `files` array.
- Model assets use `file_type: "3d"`; previews use `file_type: "image"`.
- Additional artifacts may use `file_type: "other"`. Retain accompanying assets and available `label`, `format`, `content_type`, `file_name`, and `file_size` metadata.

## Notes

Use the input parameters listed below for this generation workflow. Use publicly accessible HTTP(S) image URLs with a hostname.

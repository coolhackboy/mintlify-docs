# Tripo3D P1 Text to 3D

Create 3D objects from text with Tripo3D P1, with optional textures and a compact mesh budget for props and scene assets.

## Available Models

- **tripo3d/p1/text-to-3d** - Generate a 3D model from a text prompt.

## Output Options

### Face Limit

- `face_limit`: Optional. Set the face-count limit. Integer from `48` to `20000`.

## Key Features

- Generate a 3D model from a text prompt.
- Retrieve model assets and available previews or supporting files from the task result.

## Advanced Parameters

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Use the `input` fields listed below for this workflow.

### Prompt

- `prompt`: Required. Describe the desired 3D object. Length: **1-1,024 characters**.
- Provide a non-empty string describing the object.

### Texture

- `texture`: Optional. Control texture generation. Use `true` or `false`. Default: `true`.

### Model Seed

- `model_seed`: Optional. Set the model-generation seed. Integer.

## Output Files

- Read every item in the returned `files` array.
- Model assets use `file_type: "3d"`; previews use `file_type: "image"`.
- Supporting files use `file_type: "other"`. Preserve each returned file and its `label`, `format`, `content_type`, `file_name`, and `file_size` metadata when present.
- Use the `model_glb` file for 3D preview and the `thumbnail` file as its cover image when these labels are present.

Music models are called through `POST /api/generate/submit`. Send a model ID in `model`, the parameters in `input`, and an optional `callback_url`. The request returns a `task_id` right away and the task runs asynchronously.

## Workflow

Suno and the other providers use different result endpoints:

- **Suno**: poll [Query Music Detail](/api-manual/music-series/query-music-detail), or receive the result at `callback_url` (see [Music Webhook](/api-manual/music-series/music-webhook)).
- **MiniMax, ElevenLabs**: poll the unified [Get Task Status](/api-manual/task-management/status), or receive the result at `callback_url` (see [Webhook Callbacks](/api-manual/task-management/webhooks)).

## Notes

- Each model page lists the parameters, limits, and modes for its model IDs. Parameters are not shared across models.
- Generated files are valid for 24 hours after creation. Download and store them promptly.
- URL inputs must be publicly accessible HTTP(S) URLs. To use local files, upload them first with [File Management](/api-manual/file-series/upload-url).

# MiniMax Music 2.6

Create complete songs and instrumental tracks from a style prompt. Describe genre, mood, instrumentation, tempo and vocal direction to guide the music.

## Model

Set `model` to `minimax/music-2.6`. Place music parameters inside `input` and the optional `callback_url` at the request root.

## Music Parameters

- `prompt`: Required string of **10-2000 characters** describing the musical direction.
- `lyrics`: Lyrics string of up to **3500 characters**. Supply lyrics when `is_instrumental` and `lyrics_optimizer` are both `false`. You can organize the words with section tags such as `[Verse]` and `[Chorus]`.
- `lyrics_optimizer`: Boolean, default `false`. When `true` and `lyrics` is empty, generates lyrics from `prompt`.
- `is_instrumental`: Boolean, default `false`. Set `true` for instrumental music, keep `lyrics` empty and set `lyrics_optimizer` to `false`.

## Creation Modes

### Custom Lyrics

Write the musical direction in `prompt` and the words to sing in `lyrics`. Keep `is_instrumental` set to `false`.

### Automatic Lyrics

Describe the musical style, song topic and vocal character in `prompt`. Set `lyrics_optimizer` to `true`, keep `lyrics` empty and set `is_instrumental` to `false`.

### Instrumental Music

Describe instruments, rhythm and atmosphere in `prompt`. Set `is_instrumental` to `true`, keep `lyrics` empty and set `lyrics_optimizer` to `false`.

## Audio Settings

`audio_setting` is an optional object with these fields:

- `sample_rate`: Sample rate in Hz. Values: `16000`, `24000`, `32000`, `44100`. Default: `44100`.
- `bitrate`: Bitrate in bits per second. Values: `32000`, `64000`, `128000`, `256000`. Default: `256000`.
- `format`: Audio format. Values: `mp3`, `wav`, `pcm`. Default: `mp3`.

## Retrieve the Audio

Query `GET /api/generate/status/{task_id}` using the identifier from the submission response. Continue checking while the status is `not_started` or `running`.

When the status is `finished`, read the `files` array and use `file_url` from entries with `file_type: "audio"` to retrieve the music. For a `failed` task, read `error_message` and review the request before trying again.

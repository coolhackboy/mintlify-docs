# MiniMax Music 2.6

Create songs from style prompts and lyrics with MiniMax Music 2.6, with support for instrumentals and automatic lyric refinement.

## Available Models

- **minimax/music-2.6** - Generate songs from a style prompt and lyrics, or request instrumental music.

## Output Options

### Audio Settings

- `audio_setting`: Optional. Supply an object with the fields below.

- `audio_setting.sample_rate`: Optional. Sample rate in Hz. Accepted values: `16000`, `24000`, `32000`, `44100`. Default: `44100`.
- `audio_setting.bitrate`: Optional. Bitrate in bits per second. Accepted values: `32000`, `64000`, `128000`, `256000`. Default: `256000`.
- `audio_setting.format`: Optional. Accepted values: `mp3`, `wav`, `pcm`. Default: `mp3`.

## Key Features

- Generate songs from a style prompt and lyrics, or request instrumental music.
- Supply lyrics or enable automatic lyrics generation with `lyrics_optimizer`.

## Advanced Parameters

Set `model` and optional `callback_url` at the request root. Place all workflow parameters, including output options, inside `input`.

Send only the input fields supported by this workflow. Unsupported `input` fields are rejected before credits are deducted.

- Supply `lyrics` unless `is_instrumental` or `lyrics_optimizer` is enabled.

### Prompt

- `prompt`: Required. Describe the musical style and content. Length: **10-2,000 characters**.
- The value must not be blank when supplied.

### Lyrics

- `lyrics`: Optional. Supply the lyrics to sing. Maximum length: **3,500 characters**.

### Lyrics Optimizer

- `lyrics_optimizer`: Optional. Enable automatic lyrics generation or refinement. Use `true` or `false`. Default: `false`.

### Instrumental Mode

- `is_instrumental`: Optional. Request instrumental music. Use `true` or `false`. Default: `false`.

## Output Files

- Read every item in the returned `files` array.
- Generated audio uses `file_type: "audio"`.
- Timestamp and alignment files may use `file_type: "other"`. Preserve optional file metadata when present.

## Pricing

Pricing depends on the selected model and applicable output settings. Check the Vidgo dashboard for the current rate.

Credits are deducted on submission and refunded if the task fails.

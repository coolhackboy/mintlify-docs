Create complete songs and instrumental tracks from a style prompt. Describe genre, mood, instrumentation, tempo and vocal direction to guide the music.

## Models

- **minimax/music-2.6** — Generate songs and instrumental tracks.

## Features

- Create songs with custom or automatically generated lyrics.
- Generate instrumental music.
- Configure the audio sample rate, bitrate, and format.

## Input modes

### Custom Lyrics

Write the musical direction in `prompt` and the words to sing in `lyrics`. Keep `is_instrumental` set to `false`.

### Automatic Lyrics

Describe the musical style, song topic and vocal character in `prompt`. Set `lyrics_optimizer` to `true`, keep `lyrics` empty and set `is_instrumental` to `false`.

### Instrumental Music

Describe instruments, rhythm and atmosphere in `prompt`. Set `is_instrumental` to `true`, keep `lyrics` empty and set `lyrics_optimizer` to `false`.

## Required parameters

- `prompt` (string): Describe the musical direction using **10-2000 characters**.

- `lyrics` (string): Required when `is_instrumental` and `lyrics_optimizer` are both `false`. Supply up to **3500 characters**, optionally organized with tags such as `[Verse]` and `[Chorus]`.

## Optional parameters

- `lyrics_optimizer` (boolean): Boolean, default `false`. When `true` and `lyrics` is empty, generates lyrics from `prompt`.

- `is_instrumental` (boolean): Boolean, default `false`. Set `true` for instrumental music, keep `lyrics` empty and set `lyrics_optimizer` to `false`.

- `audio_setting` (object): Audio output settings containing sample_rate, bitrate and format.

## Output Formats

`audio_setting` is an optional object with these fields:

- `audio_setting.sample_rate` (integer): Sample rate in Hz. Values: `16000`, `24000`, `32000`, `44100`. Default: `44100`.
- `audio_setting.bitrate` (integer): Bitrate in bits per second. Values: `32000`, `64000`, `128000`, `256000`. Default: `256000`.
- `audio_setting.format` (string): Audio format. Values: `mp3`, `wav`, `pcm`. Default: `mp3`.

## Output

Query `GET /api/generate/status/{task_id}` using the identifier from the submission response. Continue checking while the status is `not_started` or `running`.

When the status is `finished`, read the `files` array and use `file_url` from entries with `file_type: "audio"` to retrieve the music. For a `failed` task, read `error_message` and review the request before trying again.

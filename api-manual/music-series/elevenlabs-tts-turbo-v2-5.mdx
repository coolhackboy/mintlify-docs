Create spoken narration with ElevenLabs Turbo v2.5, shaping pacing, vocal style, and voice similarity with optional text alignment.

## Models

- **elevenlabs/tts/turbo-v2.5** — Convert text into speech.

## Features

- Convert text into speech.
- Optionally request timestamps alongside the generated audio.
- Select a voice with `voice` and specify the spoken language with `language_code`.

## Required parameters

- `text` (string): Supply the text to speak. Length: **1-40,000 Unicode characters** after trimming leading and trailing whitespace. Include at least one visible text character.

## Optional parameters

- `voice` (string): Select a voice name or compatible voice ID. String. Default: `Rachel`.

- `stability` (number): Control voice stability. Number from `0` to `1`. Default: `0.5`.

- `similarity_boost` (number): Control voice similarity. Number from `0` to `1`. Default: `0.75`.

- `style` (number): Set the voice style strength. Number from `0` to `1`. Default: `0`.

- `speed` (number): Set the speech speed. Number from `0.7` to `1.2`. Default: `1`.

- `timestamps` (boolean): Request timestamp information with the audio. Use `true` or `false`. Default: `false`.

- `previous_text` (string): Supply preceding text as speech context. String. Also accepts `null`.

- `next_text` (string): Supply following text as speech context. String. Also accepts `null`.

- `language_code` (string): Set the spoken language with an ISO 639-1 code, such as `en`, `fr`, `de`, `ja`, `vi`, `hu`, or `no`. Also accepts `null`.

- `apply_text_normalization` (string): Control how numbers, dates, and currencies are prepared for speech: `auto` selects normalization automatically, `on` enables it, and `off` reads the supplied text directly. Default: `auto`.

## Output

- Read every item in the returned `files` array.
- Generated audio uses `file_type: "audio"`.
- Timestamp and alignment files may use `file_type: "other"`. Preserve optional file metadata when present.

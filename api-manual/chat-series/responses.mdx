Use a model that supports the Responses protocol. Set `stream: true` for SSE.

```bash
curl https://api.vidgo.ai/v1/responses \
  -H "Authorization: Bearer $VIDGO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5-6-luna","input":"Explain Decimal arithmetic briefly."}'
```

{/* poyo-20260910:start */}
## Additional supported models

- `openai/gpt-6-astra`
- `xai/grok-4.6`
- `openai/gpt-5.5`
- `openai/gpt-5.4`
- `openai/gpt-5.2`

Send protocol fields at the root, without a generation input wrapper. input must not be empty.

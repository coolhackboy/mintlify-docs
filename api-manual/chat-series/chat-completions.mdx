Use a model that supports the Chat Completions protocol. Set `stream: true` for an SSE response.

```bash
curl https://api.vidgo.ai/v1/chat/completions \
  -H "Authorization: Bearer $VIDGO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"kimi-k3","messages":[{"role":"user","content":"Hello"}]}'
```

## Additional supported models

- `openai/gpt-6-astra`
- `anthropic/claude-fable-5.1`
- `xai/grok-4.6`
- `google/gemini-3.7-flash`
- `google/gemini-3.5-flash`
- `anthropic/claude-opus-4.8`
- `openai/gpt-5.5`
- `openai/gpt-5.4`
- `openai/gpt-5.2`
- `anthropic/claude-sonnet-4.6`
- `anthropic/claude-opus-4.6`

Send protocol fields at the root, without a generation input wrapper. messages must be a non-empty array.

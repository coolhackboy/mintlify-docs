Use a model that supports the Chat Completions protocol. Set `stream: true` for an SSE response.

```bash
curl https://api.vidgo.ai/v1/chat/completions \
  -H "Authorization: Bearer $VIDGO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"kimi-k3","messages":[{"role":"user","content":"Hello"}]}'
```
